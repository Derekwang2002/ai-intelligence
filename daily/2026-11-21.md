## Models

### Genie 4 API（TRIAL）

Google 通过 Gemini API Interactions API 和 AI Studio 向付费层 key 开放 Genie 4。输出为 720p、24 fps 与立体声，约每秒 0.10 美元。客户端断线不等于停止服务，必须调用 complete() 或 cancel()；这是“连接状态”和“计费生命周期”分离，工程上最容易踩坑。

来源：https://blog.google/innovation-and-ai/models-and-research/google-deepmind/genie-4-api/；https://aistudio.google.com/docs/genie

## Agent & AI Engineering

### OpenAI Performance Factory（WATCH）

系统把性能回退转成持久任务，再调度 Codex 云端会话和独立 reviewer agent。所谓 adversarial reviewer，不是安全攻击，而是专门寻找反例、质疑根因的第二个会话。最终是否合并仍由人决定。

来源：https://openai.com/index/performance-factory/

### Harness adapters（TRIAL）

Hugging Face 发布 pi、Hermes、OpenCode 三种 adapter 与合并版。发布方结果显示 harness 内提升明显，但一题一次采样、合并权重参考了 Terminal-Bench，且域外迁移弱。

来源：https://huggingface.co/blog/harness-adapters

### Watch Duty 野火无线电转录（WATCH）

合作方称嘈杂音频词错误率从 38% 降到 22.34%，志愿者满意度升到 92.3%。这不是“自动发布警报”：模型负责分流，人在发布关键消息前核验。

来源：https://blog.google/technology/ai/watch-duty-gemini-wildfire-response/
