# AI Intelligence - 2026-10-06

## Daily Executive Summary

本轮新增 2 条事件，更新 3 条既有判断。OpenAI 推出 textGrain 文本水印，但短文本、同义改写和封闭检测器仍限制独立验证。召回自检还发现 AutoTrust 决策模型下载量很高，却缺少可复现和独立评测，因此明确列为 IGNORE。vLLM 0.31 与 Qwen Code 0.25 分别推进推理服务快速恢复和 coding agent 的协作恢复能力。

## Models

- **新 · AutoTrust GEV/JEV**（IGNORE）：两款公开权重模型在 Hugging Face 出现异常高下载量，但 GEV 只有未验证的作者自测，JEV 没有 model-index 成绩。高下载量说明值得发现，不等于值得投入。

## Agent & AI Engineering

- **Qwen Code 0.25**（更新 / TRIAL）：稳定版加入本地 workspace-agent 协作、A2A 分享、私有 hosted MCP、持久 shell 结果与冷会话恢复。这里的「持久结果」是先记录工具执行结果，再恢复 agent 状态；难点是重启后既不能漏掉结果，也不能把有副作用的命令再执行一次。
- **Private Safety Processing**（更新 / WATCH）：OpenAI 确认 9 月 22 日开始分阶段向获批 API 客户开放，并补齐 AWS、Azure 与 Google Cloud 的配置指南。ZDR 不等于内容在任何地方都不存储；这里仍有客户控制的加密存储和最长 30 天留存。

## Open Source

- **AutoTrust GEV/JEV**：权重和 adapter 已公开，证据质量却没有跟上采用信号；等待可复现 benchmark 或独立评测。

## Research

本周期没有达到入库门槛的新研究事件。

## Developer Tools

- **Qwen Code 0.25**：多 agent 协作与故障恢复进入稳定版，适合在非关键仓库做一天内的恢复与重复副作用测试。

## Infrastructure

- **vLLM 0.31**（更新 / ADOPT）：`vllm preload` 扩展到 DP/MTP，并加入实验性 CRIU 初始化引擎快照；每请求多模态参数默认拒绝。CRIU 快照会把已初始化进程状态保存下来，恢复时少走一遍冷启动；难点是 GPU、驱动和进程状态必须兼容。

## Business & Policy

- **新 · textGrain**（WATCH）：OpenAI 为部分 API 模型提供 opt-in 文本水印，并在欧盟 ChatGPT 与 Codex 分阶段开放。官方实验在 200 tokens 时约有 80% 检出率、400 tokens 时约 95%，但同义改写会明显削弱信号。水印不是可见标签，而是模型选词中埋入统计模式；短文本的有效样本少，因此更难稳定判断。

## Trend Signals

- 趋势 #7「长期运行 agent 的可靠性控制进入运行时」获得 Qwen Code 恢复边界与 vLLM 安全请求边界的补充信号。
