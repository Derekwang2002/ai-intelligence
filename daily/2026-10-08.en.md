# AI Intelligence - 2026-10-08

## Daily Executive Summary

This run adds eight events and materially updates five. Claude Haiku 5.5, EmbeddingGemma 2 and Liquid d1 push low-cost generation, multimodal retrieval and structured decisions toward smaller, more local execution planes. Anthropic also expands its Cyber Verification Program, gating higher-risk cyber capabilities by use case. ScienceClaw-Eval, openTPU, EMA Lightning and OpenAI's mathematics results add persistent-learning, inspectable-hardware, open-speech and machine-checkable-research signals. Claude Code, Codex, Gemini CLI, GitHub Copilot and GPT-6 also receive meaningful availability or governance updates.

## Models

- **New · Claude Haiku 5.5** (TRIAL): Anthropic makes the new Haiku available through its API, Claude apps and three major clouds. Pricing rises fivefold beyond 100K input tokens, so long-context evaluation must include full-input cost.
- **New · EmbeddingGemma 2** (TRIAL): Google releases a 740M-parameter on-device multimodal embedding model for text, code, images, video and audio under Apache 2.0. Matryoshka embeddings let teams keep only the first 128, 256 or 512 dimensions; the hard part is renormalizing after truncation and checking that recall does not silently regress.
- **New · Liquid d1** (TRIAL): d1-3B and d1-omni-600M return typed choices or numbers in one forward pass instead of generating tokens. That single-pass design fits routing and edge review; calibration, licensing and the `trust_remote_code` execution boundary still need validation.

## Agent & AI Engineering

- **New · Anthropic Cyber Verification Program** (TRIAL): Anthropic splits advanced cyber capability into Defense, Red Team and Specialized Access, tying stronger capability to identity checks, workspace assignment and monitoring. Teams can begin with authorized Defense Access tests, but vendor controls do not replace internal audit.
- **New · ScienceClaw-Eval** (TRIAL): The benchmark tests whether a fixed model turns one repair into reusable Skills and Operators. Replay reruns the repaired task to check that the fix was not luck; the harder requirement is maintaining gains on tasks that were not part of the repair.

## Open Source

- EmbeddingGemma 2 ships Apache 2.0 weights; ScienceClaw-Eval exposes its benchmark and runner; Liquid d1 publishes weights and demos under a custom LFM license.
- **New · openTPU** (TRIAL): The Apache 2.0 project exposes a complete FPGA accelerator stack from RTL, ISA and simulator to compiler and profiler. Its October 7 update adds Hugging Face golden-model validation. It is better suited to learning and verification than replacing production accelerators.
- **New · EMA Lightning** (TRIAL): The 8.6M-parameter Turkish streaming TTS stack ships Apache 2.0 weights, code and a pip package. Author-reported latency and WER are strong, but the training corpus is private and needs independent testing on owned speech.

## Research

- **New · OpenAI model-generated mathematics** (WATCH): OpenAI publishes another set of model-generated results with Lean formalizations, revision rules and citation guidance. Lean can check whether each proof step follows the rules, but it cannot decide whether the question matters, the assumptions are appropriate or the result is genuinely novel.

## Developer Tools

- **Claude Code 2.1.292/293** (updated / ADOPT): Adds long-run auto-compaction, async hooks, git worktree isolation and more managed-policy controls. Test hooks, recovery and worktree cleanup before upgrading.
- **Codex 0.161.0** (updated / ADOPT): Improves subagent routing, MCP resource discovery and long-run summaries while fixing approval and recovery boundaries.
- **Gemini CLI 0.63.0** (updated / WATCH): Stable now strengthens memory control, authentication recovery and non-interactive plan execution. A2A compatibility commitments remain unclear.
- **GitHub Copilot** (updated / ADOPT): Local sandboxing moves from preview to GA and Ollama model discovery is added. Validate network, filesystem and repository-write permissions before enabling it.
- **GPT-6 Intelligent UI** (updated / TRIAL): OpenAI publishes a more concrete generated-interface workflow and examples. Test accessibility, state retention and failure recovery on real tasks.

## Infrastructure

EmbeddingGemma 2 and Liquid d1 move multimodal capability onto local devices. Recall audit also recovered openTPU, an inspectable path from compiler to FPGA card. All three still lack enterprise adoption, so the local-execution trend remains candidate.

## Business & Policy

Anthropic's expanded Cyber Verification Program changes how high-risk model capabilities are exposed and who carries control obligations; it is not a general API-policy change.
