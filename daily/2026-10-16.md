# AI Intelligence - 2026-10-16

## Daily Executive Summary

- **中国 AI 技术出口目录仍是草案，但临时登记已经生效**：拟新增 23 项 AI 技术，意见征集到 11 月 15 日；跨境转让与许可需要先按现行登记要求盘点，不能把草案写成全面禁令。
- **Beam 从预告变成 Apache-2.0 开放权重**：501B/23B-active 模型可通过多种运行时或托管端点测试；8×H200 参考配置约每小时 40 美元，成本与厂商 benchmark 是主要限制。
- **NVIDIA 发布 Nemotron 3.5 多模态权重**：Super VL 提供 1M 上下文，Bolt 有 24GB artifact；OpenMDW 许可、硬件兼容与厂商自测结果仍需核验。
- **Granite Switch 4.1 用共享基座承载多种适配器**：Apache-2.0 的 8B/30B 模型把 chat、decision、guardian 与 ASR 放在一个端点，适合验证是否真的减少显存与服务数量。
- **llama.cpp 0.7.0 改善 MoE 推理，也带来破坏性接口变化**：专家缓存可能提高解码速度；端口、chat 返回结构和 RPC 协议都应在升级前回归。

## Models

- **Beam**（更新 / TRIAL）：BF16、FP8 与 NVFP4 权重、model card 和多种运行时已经发布。稀疏 MoE 只激活部分参数，但不等于部署便宜；参考托管配置仍需 8 张 H200。[发布说明](https://huggingface.co/blog/reflectionai/beam)
- **Nemotron 3.5**（新 / TRIAL）：Super VL 面向长上下文多模态 agent，Bolt 提供更小的 24GB 量化路径。主要成绩来自 NVIDIA 或合作方。[公告](https://developer.nvidia.com/blog/nvidia-nemotron-3-5-super-vl-powers-specialized-agents-with-multimodal-reasoning/)
- **Granite Switch 4.1**（新 / TRIAL）：可组合适配器共享基础模型与 KV cache。ASR 是串联流水线，不是联合训练的多模态模型。[发布说明](https://huggingface.co/blog/ibm-granite/granite-switch-4-1)
- **Liquid d1-ultra**（更新 / TRIAL）：托管 API 为固定选项返回概率，输入每百万 token 0.042 美元且不收输出 token；112 项任务结果仍是厂商自报。[公告](https://www.liquid.ai/blog/d1-ultra)
- **Timestral**（新 / TRIAL）：5M–209M 开放权重降低时间序列基线成本；排行榜优势仍待独立复测。[公告](https://mistral.ai/news/timestral/)
