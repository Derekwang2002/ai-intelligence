# AI Intelligence - 2026-10-16

## Daily Executive Summary

- **Muse Spark 开放权重，但“开放”不等于轻量或宽松许可**：816B-A42B 权重、托管 endpoint 与多种运行时已可用；模型受门控，自定义许可对 MaaS 业务设有额外条件。
- **Timestral 把开放权重时间序列预测压到 5M–209M 参数**：四款模型可在 CPU 或 GPU 上试验；榜单优势由 Mistral 提交，尚无独立复测。
- **GitHub AI Scan 与 agentic autofix 进入 GA**：一个扩大 PR 漏洞发现范围，另一个生成并用 CodeQL 迭代修复；两者都消耗安全 AI Credits，结果不能直接阻断合并。
- **Claude Code 2.1.300 加固长任务恢复边界**：修复会话恢复丢失或重复、策略读取卡住、worktree 起点和后台服务退出等问题，适合优先升级回归。
- **Cloudflare 与 OpenAI 试验用“变化信号”改善网页发现**：约 1% 网络样本帮助找到数亿个未知页面；这是双方自报的研究结果，没有公开 API 或下游质量数据。

## Models

- **Muse Spark Open**（更新 / TRIAL）：816B 总参数、每 token 激活 42B，支持文本、图像、音频和视频输入与 100 万 token 上下文。MoE 只激活部分专家，并不等于模型容易自托管；BF16 参考配置仍需 32 张 H200。[发布说明](https://huggingface.co/blog/meta-muse-spark-open)
- **Timestral**（新 / TRIAL）：5M 到 209M 四款权重覆盖概率预测、历史协变量与已知未来协变量。分位数预测不是只给一个点，而是给出多个可能区间；难点是校准不好时“范围”也可能失真。[公告](https://mistral.ai/news/timestral/) · [模型卡](https://huggingface.co/mistralai/Timestral-209M)
- **Cloudflare–OpenAI Web Discovery Pilot**（新 / WATCH）：变化信号告诉 crawler 哪些页面新增或变旧，减少反复抓取不变内容；难点是规模不等于搜索质量，且试点没有公开接口。[官方结果](https://blog.cloudflare.com/cloudflare-openai-discovery-agentic-web/)

## Agent & AI Engineering

- **Claude Code 2.1.300**（更新 / ADOPT）：修复恢复后丢消息或重复运行、策略读取超时、worktree 起点错误、daemon 假停止和 hook 输入校验。[稳定版](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)
- **Qwen Code 0.25.2**（更新 / TRIAL）：加入团队消息、持久计划审批、Test Failure Explorer 和默认关闭的前台 Shell，并继续修补托管任务恢复。[稳定版](https://github.com/QwenLM/qwen-code/releases/tag/v0.25.2)

## Open Source

Muse Spark、Timestral 和 HiRO-ACEv2 都提供可检查 artifact，但开放程度不同：Muse 受门控和自定义许可约束；Timestral 是修改版 MIT。不能只看“open weights”标签。

## Research

- **HiRO-ACEv2**（新 / TRIAL）：把约 100 公里的 ACE 输出降尺度到 3 公里，并覆盖降水、风和气压。作者称极端点统计在 X-SHiELD 的 3% 内、成本约三百分之一；但模型只能用于 X-SHiELD 对齐的输入域，不能直接推演更暖未来或 ERA5 历史气候。[研究文章](https://huggingface.co/blog/allenai/hiro-acev2)
