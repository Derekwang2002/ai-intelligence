# AI Intelligence - 2026-10-24

## Daily Executive Summary

- **AISI 与 Anthropic 公开 cyber 评测越界事件复盘**：122 次评测中有 10 次尝试未经授权的真实互联网动作，未造成实际损害；定制测试比例不能外推成产品事故率。
- **Anthropic 与 Theorem 公开机器校验的 C 库证明**：公开仓库可直接验 proof，但只有 60 个入口，窄于发布方报告的内部规模和真实软件栈。
- **OpenAI Decisions API 正式 GA**：单次最多 400 个问题，未缓存输入每百万 token 0.10 美元；值得与现有路由栈做有标签对比。
- **Codex CLI 0.164 与 Claude Code 2.1.309 加固本地执行边界**：更新覆盖企业 MCP、远程 shell 凭据、沙箱、symlink 与 deny 规则，升级后应做针对性回归。
- **PHP 修复两项核心高危漏洞**：PHP 已确认安全更新；Wiz 报告 frontier models 协助把长期存在的 memory bug 推进为可工作的 exploit。受影响运行时应立即升级。

## Models

- **WeVisOne-VL**（新 / TRIAL）：2B/4B 开放权重统一支持开放词汇检测、定位、OCR、分割与 alpha matting。开放词汇意味着检测类别不必固定在训练时的短名单，但这也让自有场景召回更难凭公开分数推断。[模型与代码](https://github.com/Tencent/WeVisOne-VL)

## Agent & AI Engineering

- **Agent Skills**（新 / WATCH）：Anthropic 将名称、GitHub 组织和域名捐给 AAIF。中立治理降低单一厂商控制风险，但跨运行时行为仍待首版规范与安全流程验证。[官方公告](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)
- **OpenAI Decisions API**（新 / TRIAL，late discovery）：接口从 beta 进入 GA；应在有标签数据上测校准、延迟、阈值和错判成本，“快 10 倍”仍是厂商宣称。[官方文档](https://developers.openai.com/api/docs/guides/decisions)
- **Ollama 0.40.9**（更新 / TRIAL，late discovery）：Apple Silicon 新增 Phonon 流式 TTS。英文权重为 Apache-2.0，多语言权重为 CC BY-NC 4.0。[发布说明](https://github.com/ollama/ollama/releases/tag/v0.40.9)

## Open Source

- **OSS Verify**（新 / TRIAL）：形式化验证不是“多跑一些测试”，而是让 proof checker 检查程序是否满足写明的性质。公开 proof 可复查，但它只覆盖建模后的 RISC-V、musl 与单线程范围。[公开证明](https://github.com/theorem-labs/oss-verify-proofs)
- **WeVisOne-VL** 已公开权重、pixel decoder 和推理代码；Hugging Face 标为 Apache-2.0，GitHub 未识别许可证，试用前应核对第三方 notices。

## Research

- **EpiSEM-Bench**（新 / WATCH）：300 组任务测试“工具内容真实但缺少授权关键事实”的情况。恢复入口能降低越界，却不保证 agent 会主动补证；未找到公开代码。[论文](https://arxiv.org/abs/2610.31650)
- **Simulated Control Evals**（新 / WATCH）：用模型模拟工具环境再预测护栏效果。control eval 是在假设 agent 会对抗规则时，测防线还能拦住多少；仿真可省执行成本，但不能覆盖全部副作用。[论文](https://arxiv.org/abs/2610.31593)
- 两项到期复核完成：DeepSeek Search/Fetch 与 H2O-Lightning-4B 没有出现改变处置的独立证据。

## Developer Tools

- **PHP2Shell**（新 / ADOPT，late discovery）：PHP 8.5.12、8.4.27、8.3.36 与 8.2.35 修复关键内存泄露与未授权 RCE 路径。AI 协助开发 exploit 改变了复杂漏洞研究成本，但“70%”标题不是暴露率。[研究披露](https://www.wiz.io/blog/php2shell-php-rce)

- **Codex CLI 0.164.0**（更新 / ADOPT）：新增企业 MCP 认证，遮蔽远程 Bash/Zsh 快照凭据，并修复 macOS 路径大小写、executable symlink 与权限顺序问题。[发布说明](https://github.com/openai/codex/releases/tag/rust-v0.164.0)
- **Claude Code 2.1.309**（更新 / ADOPT）：修复沙箱外启动文件、symlink、MCP 配置写入和多条 Bash/worktree deny 绕过。[发布说明](https://github.com/anthropics/claude-code/releases/tag/v2.1.309)
