## Models

### Strands Decider 2B（TRIAL）

Strands 开源 2B decision model，用一次前向计算在类型化动作中做选择，不生成文本。这里的 decision model 可以理解为只负责“选哪个动作”的小模型；难点不在语言流畅度，而在校准、拒答和一次选错会造成多大后果。权重、训练代码、数据和评测记录齐全，适合用真实路由样本做一天对比。

### MAI Speech（TRIAL）

Microsoft 发布支持 60 种语言的流式转写，以及两款覆盖 23 种语言的语音合成模型。流式转写会在整句话结束前不断返回部分结果；难点是部分文本会反复修正，agent 必须正确处理打断和回滚。建议用中英混合真实通话测首 token 延迟、错误率、打断恢复、自然度和每轮成本。

### Index-Translate（TRIAL）

IndexTeam 公开 35B 总参数、3B 激活参数的 MoE 翻译模型，支持 150 种语言，以及术语、风格和 JSON 输出约束。“3B 激活”表示每次只调用一部分专家参数，目标是在保持容量的同时降低推理成本；难点是路由开销和显存仍需实测。当前是预览版，先用公开权重跑一天术语与低资源语言样本。

### Kolibri（TRIAL）

Aleph Alpha 开源德英双语 Kolibri：78B 总参数、3.46B 激活，支持 reasoning level、工具调用和最长 1M token。权重、vLLM plugin 与训练报告齐全，适合德语企业 RAG 和长文档试验；官方仍建议复杂任务控制在 262K 以内，作者基准也需要独立复现。

### Naive-N0.5-Flash（TRIAL）

NaiveAI 开源 309B 总参数、15.5B 激活的稀疏模型，原生上下文 1M token。模型完全不用全注意力层，但仅权重约 315 GB，需要 FP8 NVIDIA 集群。适合有对应硬件的团队定向测试，不是默认部署选择。

## Agent & AI Engineering

### MCP SDK 2.3（TRIAL，更新）

TypeScript 与 Python SDK 收紧同源重定向、token audience、连接生命周期和 SSE 负载上限。安全默认值更合理，但复用 server 或 transport 的旧实现可能直接失效。升级前要覆盖跨域重定向、超大 event 和断线重连。

### UI-Venus-2（TRIAL，评级调整）

到期复核确认 9B 权重、框架、训练与评测工具已经公开，因此从 WATCH 调整为 TRIAL。模型卡同时明确写明权重许可证仍待确认；只能在隔离环境验证，商业使用要继续等待。

## Open Source

Strands Decider、Index-Translate 与 UI-Venus-2 都有公开材料，但开放程度不同：前两者有 Apache-2.0 许可，UI-Venus-2 的权重许可证尚未确定。选择试验对象时，许可状态应和模型质量一起进入门槛。

## Research

验证器审计的 30 天复核未发现新的独立采用信号。MIT 代码和逐样本记录仍可复现，评级维持 TRIAL；它更适合作为团队自有奖励流水线的检查方法，而不是成熟工具。

## Developer Tools

### Claude Code 2.1.288（ADOPT，更新）

版本修复超大或不可解析 MCP 输出后重复调用工具的问题，并让 hook 状态无法序列化时默认拒绝。它还会拦截藏在 `bash -c` 中的危险删除，并改善自动压缩后的恢复。升级前回归危险 shell、hook、超大输出和恢复路径。

### Copilot Code Review（TRIAL，更新）

GitHub 允许从 REST 与 GraphQL API 触发 Copilot code review，并逐请求设置 effort；Balanced 成为默认 GA 档。团队可以把 review 放进 CI，但应先对同一组 PR 比较 Balanced 与 High 的时延、成本和有效发现率。

## Infrastructure

### DwarfStar ds4（TRIAL）

召回自检补录 ds4：一个用 C 编写、专门支持 DeepSeek V4、GLM 5.x 与 Qwen3.8 的本地推理栈。它提供 SSD 流式加载、持久化 KV cache、本地 API 与原生 coding agent，并已有 2.3 万多个 GitHub star。项目仍是快速变化的 beta，只适合先在目标硬件做完整性能与一致性验证。
