# AI Intelligence - 2026-10-21

## Daily Executive Summary

- **NVIDIA advances agent governance with OpenShell and Sentry**: OpenShell code is available and moves policy outside the agent; the BlueField-4 Sentry layer is only planned for early 2027.
- **OpenAI models and Codex are coming to Google Cloud**: Marketplace purchases can draw down GCP commitments, but GA is still weeks away and regions, pricing and data boundaries remain incomplete.
- **GitHub opens Package Firewall as a public preview**: organizations can proxy npm downloads and enforce cooldown, advisory and attestation-downgrade policies; coverage is npm-only and GA metering is planned.
- **RFD4-Proteina opens protein co-design code and weights**: public artifacts support reproduction, but faster sampling and design quality remain publisher results rather than biological validation.
- **FairStress shows that matching final answers can hide asymmetric decisions**: its public core split tests whether matched persuasion moves models differently across demographic groups, within one fairness definition.

## Models

- **Voxtral 3** (new / TRIAL): regional voice APIs are live with explicit pricing; quality evidence remains vendor-reported. [Release](https://mistral.ai/news/voxtral-3/)
- **Mercury 3** (new / TRIAL): the diffusion-language-model API is live; latency and quality need same-task checks. [Release](https://www.inceptionlabs.ai/blog/introducing-mercury-3)
- **Granite Speech 5** (new / TRIAL): Apache-2.0 weights cover a 2B accuracy model, 470M Turbo CTC and long-audio speaker attribution. Low WER does not establish reliable speaker labels, so measure cpWER too. [Release](https://huggingface.co/blog/ibm-granite/granite-speech-5)

## Agent & AI Engineering

- **ALTK-Evolve** (new / TRIAL): public code learns behavioral memory from prior tasks and needs bad-trajectory poisoning tests. [Research post](https://huggingface.co/blog/ibm-research/altk-evolve-bc)
- **Distributed Agents** (new / TRIAL): thousands of agents analyze mouse-brain-cell data; code, saved outputs, notebooks and a read-only MCP corpus are public. The output is experimental leads, not diagnostic conclusions. [Research post](https://openai.com/index/scaling-ai-research-for-complex-biological-data/)

## Open Source

- **MultiLangBench** (new / TRIAL): Apache-2.0 tests cover 20 lower-resource programming languages. [Repository](https://github.com/openai/MultiLangBench)
- **OpenShell** (new / TRIAL): Gateway, Supervisor, Sandbox and Policy Prover put authority outside the agent. Sentry is future availability, not a current feature. [Repository](https://github.com/NVIDIA/OpenShell)
- **RFD4-Proteina** (new / TRIAL): BSD-3-Clause code, ungated weights and test data are public. Inference-time search branches from higher-scoring partial designs, but faster sampling does not establish binding or in-vivo activity. [Release](https://developer.nvidia.com/blog/design-proteins-with-rfd4-proteina-using-reward-guided-inference-time-search/)

## Research

- **FairStress** (new / TRIAL): 300 scenarios expand to more than 13 million cases with a 50K core split. Matched prefixes test whether the same persuasion changes decisions differently across groups, adding a stability check beyond the final choice. [Research post](https://huggingface.co/blog/allenai/fairstress)
- Nine due reviews completed. OSWorld-Pro, DUMA-Bench, RRSI, trajectory sampling, agent collusion, MSI-Bench, Grok 4.7, HiRO-ACEv2 and Grok Voice 3.0 found no new independent evidence that changed disposition.
