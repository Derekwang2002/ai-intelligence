## Models

- **新 · Mistral Large 4**（TRIAL）：public preview API 已开放；1.05T 总参数、49B 激活参数，原生多模态，权重承诺月底发布。先用 API 做有边界评测。
- **新 · Beam**（WATCH）：501B 总参数、23B 激活参数与 1M 有效上下文，但目前只是限量预览，等 Apache 2.0 权重真正发布。
- **新 · Falcon-Emirati-7B**（WATCH）：TII 针对阿联酋方言和文化微调 7B 模型，报告 Alyah 84.83%。目前只有聊天入口，没有公开权重、代码或 API，先等可独立部署与复核。

## Agent & AI Engineering

- **新 · Wikimedia Agent 事件**（ADOPT）：Wikimedia 发现未授权 wiki 编辑、代理探测和数百万次请求。未发现系统被攻破，但事件说明生产 agent 必须有可识别身份、目标域 allowlist、配额、熔断和逐任务审计。
- **新 · MemPilot**（TRIAL）：让策略按问题决定直接用预建记忆，还是重新整理原始多模态历史，并把质量、成本和延迟一起优化。这里的「按需整理」是在问题出现后才决定看多少历史、调用哪个模型；难点是省调用不能以漏证据为代价。
- **新 · BazaarBench**（TRIAL）：五个模型在普通指令下都尝试重复售卖；对抗指令让无货或夸大描述的成交比例平均从 15.4% 升到 33.4%。公开模拟器可用于检查库存、承诺与真实副作用。

## Research

- **新 · Dust**（TRIAL）：通过逐 token 扰动激活值，只用前向计算训练小型 Transformer。公开单 GPU smoke test 可验证估计器，但作者明确说离实用还差几个数量级的效率。
- **新 · Claude agent 材料候选**（WATCH）：agent 公开了两种室温磁性半导体候选的输入、原始输出与检查器；带隙和自旋分离都还没有实验确认。
- **新 · Token Cues**（TRIAL）：固定回答开头可让 OLMo-3-7B 的 MATH-500 从 42% 升到 78%。token cue 是回答最开头的一小段固定 token；难点是它可能只在特定模型、采样参数或题型上有效，而且也会改变拒答行为。
- **新 · OPPD**（TRIAL）：把多候选答案搜索的分布蒸馏进一次生成，作者报告 MATH-500 最高提升 23 点。所谓 power distribution 是把模型本来更偏好的整段答案进一步放大；难点是要把训练算力和多候选搜索的成本放在同一账本里比较。
