## Models

- **MiniMax M3.1 Flash**（新 / TRIAL）：API、M Plan 与 MiniMax Code 已可用，全球价格为输入 0.15、输出 0.60、缓存输入 0.015 美元/百万 token。厂商称中位输出超过 170 token/s，DeepSWE v1.1 为 73.7%；权重与独立复现都未到位。[官方发布](https://www.minimax.io/blog/minimax-m31f)
- **DeepSeek V4.1 Flash 1017**（更新 / TRIAL）：Artificial Analysis 独立测得 hosted Max 的 Intelligence Index 45、每项任务 0.26 美元、输出 224.7 token/s 与 TTFT 1.12 秒，同时显示整套评测生成 2.1 亿输出 token。速度与价格得到外部支持，但高冗长度可能吞掉单价优势；这也不是对下载权重的复现。[独立评测](https://artificialanalysis.ai/models/deepseek-v4-1-flash-1017)

## Agent & AI Engineering

- **Qwen Code 0.25.3**（更新 / TRIAL）：托管父 agent 可启动只读子 agent，后者只能读取冻结 workspace，不能改文件或跑命令。快照隔离就是给子任务一份固定副本；难点是父任务继续变化时，子任务看到的内容可能过期，因此还要验证新鲜度与合并边界。[发布说明](https://github.com/QwenLM/qwen-code/releases/tag/v0.25.3)

## Infrastructure

- **SGLang 0.5.22**（更新 / TRIAL）：项目称 InstantTensor 加载快 10 倍，prefill/decode 分离吞吐最高增加 27%，并要求 Python 3.11。prefill/decode 分离是把读入长提示与逐 token 生成放到不同 worker；难点是 KV 与状态交接会引入新的正确性和尾延迟风险。[发布说明](https://github.com/sgl-project/sglang/releases/tag/v0.5.22)
- **TorchNeuron**（新 / WATCH）：AWS 宣布原生 PyTorch backend 支持 Trainium2/3，并称 Hugging Face 工具与 TorchTitan 已集成。backend 是 PyTorch 把同一套算子交给不同硬件执行的适配层；真正的算子覆盖与性能要等 10 月 20 日仓库开放后才能检查。[官方公告](https://www.aboutamazon.com/news/innovation-at-amazon/torchneuron-pytorch-aws-trainium-chips-ai)
