## Daily Executive Summary

- GPT-6 Sol/Luna and Claude Opus 5.5 push model selection further from “which is strongest?” toward “what does a completed task cost?” Both target long-context, tool-using agent workloads, but at very different price points. Route them with your own completion rate, step count and cache-hit data.
- Cursor extends coding agents past merge. Rollouts watches production telemetry and can prepare a pause or revert, while Security Review inspects pull requests with whole-codebase context. Approval and reversibility must expand with that authority.
- GitHub, Qwen Code and PASTABench point to the same conclusion from product, runtime and evaluation layers: broad execution needs separate sandboxing, attestation, telemetry and timely intervention. Trend #7 moves from emerging to strengthening, still at Medium confidence.

## Models

- GPT-6 Sol targets complex coding and agents; Luna targets high-volume work. They share a 1.05M-token context and built-in tools, but their standard output prices differ by 20x, making them candidates for difficulty-based routing within one harness.
- Claude Opus 5.5 lowers input/output pricing to $4/$20 per million tokens and cache reads to $0.20. METR's predeployment evaluation describes its AI-R&D gain as incremental, not a capability discontinuity.

## Agent & AI Engineering

- Cursor's production tests suggest an optimization order that other teams can reuse: shrink the stable prefix, load tool schemas lazily, stabilize cache boundaries, compress source-line context, then use subagents selectively.
- PASTABench finds that even the best safety monitor intervenes inside the optimal window only 40.74% of the time. A safety classifier must be right before the harmful state transition, not only right afterward.
