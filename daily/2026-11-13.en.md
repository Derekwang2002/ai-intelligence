# AI Intelligence - 2026-11-13

## Daily Executive Summary

1. **Jensen Huang resigns as NVIDIA CEO, effective immediately.** NVIDIA appointed CFO Colette Kress interim CEO while it searches for a permanent successor, and Harvey C. Jones became its first board chair. The announcement gives no reason and says the product roadmap and customer commitments will continue. Because the transition can affect the global AI-chip ecosystem, it appears here as exceptional general news without a fabricated technical event.
2. **Google opens Gemini Decision 1.** The beta API can process up to 1,000 closed-set decisions in one request for $0.10 per million input tokens and no output-token charge. It fits routing, moderation and ranking, but Google's 150–250 ms latency and quality claims require calibration on local labeled data.
3. **AWS makes AgentCore Web Search generally available.** `InvokeWebSearch` needs no gateway resource, uses IAM and SigV4, and costs $7 per 1,000 queries. The interface, regions and terms are verified; freshness and relevance are not independently tested.
4. **Nex-AGI publishes Nex-N2.6 weights.** Apache 2.0 ungated FP8 weights and an SGLang path create a reproducible self-hosted agent option. The roughly 321B scale is expensive, while OSWorld and Terminal-Bench scores remain publisher-run.
5. **Baidu opens the ERNIE 5.5 Flash Preview API.** The 280B-total, 14B-active, 1M-context checkpoint is callable through Qianfan, with promotional input pricing as low as RMB 0.50 per million tokens. It is unfinished, and weights promised by November 25 are not yet downloadable.

## Models

### ERNIE 5.5 Flash Preview

“14B active parameters” means each token uses only part of the model's 280B total expert capacity. Lower inference cost does not make the full model easy to self-host. The API is live; open weights remain a dated promise.

### Nex-N2.6

The public weights, license and deployment instructions are verifiable. Nex-AGI reports OSWorld 83.0 and Terminal-Bench 2.1 at 84.1, but this run found no independent reproduction and does not treat those scores as confirmed leadership.

## Agent & AI Engineering

### Gemini Decision 1

A closed-set decision chooses among predefined yes/no, multiple-choice or ordered categories instead of generating free-form text. The hard part is calibration: precise-looking confidence scores may still be wrong on your real data.

### AgentCore Web Search

The GA API covers six commercial regions and supports PrivateLink and CloudTrail data events; the direct API is not in GovCloud. AWS terms require retaining and displaying returned citations, so clients cannot discard links after extracting text.
