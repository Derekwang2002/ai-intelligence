# AI Intelligence - 2026-10-23

## Daily Executive Summary

- **OpenAI will review services that resell direct model access**: the revised Usage Policies are announced and take effect November 20; gateways, routers and model marketplaces should first determine whether they are direct-access intermediaries.
- **Recursive publishes Flint coding-model weights**: the 39.8B-total, 2.5B-active model is available under Apache-2.0 through vLLM, SGLang and macOS Ollama; benchmarks remain publisher-run.
- **Qwen Code 0.26.0 makes recovery semantics testable**: it consults durable receipts after restart and keeps unprovable outcomes UNKNOWN instead of replaying side effects.
- **Claude Code 2.1.307 adds per-tool safety telemetry**: tool calls can record approval, hook, sandbox and safety outcomes; MCP reconnection retries are limited to read-only or idempotent tools.
- **OlmoEarth v1.3 opens global 10-meter embeddings**: weights, training code, data and nine years of embeddings are public, under a custom restricted license and without independent benchmark reproduction.

## Models

- **Recursive Flint** (new / TRIAL): “active parameters per token” means each step uses only part of the MoE model. Test the 23 GB local package for memory, latency and repeated-run variance. [Model card](https://huggingface.co/RecursiveSI/flint)
- **OlmoEarth v1.3** (new / TRIAL): annual 64D and 128D global embeddings are available at 10-meter resolution. The custom license restricts military, surveillance and some extractive uses. [Announcement](https://huggingface.co/blog/allenai/olmoearth-v1-3)
- **Kumo Relational** (new / TRIAL): the model uses up to 10,000 historical rows as context for relational classification or regression. Test OpenMDW 1.1 weights on an internal temporal split. [Announcement](https://huggingface.co/blog/nvidia/kumo-relational)

## Agent & AI Engineering

- **Claude Duet** (new / WATCH): the proactive-agent research preview has a US Pro/Max waitlist. It runs on a cloud computer, uses connected apps and messages users proactively; Team/Enterprise access is absent, usage is shared with Claude, and Anthropic acknowledges possible misses and misreads. [Official introduction](https://claude.com/resources/articles/claude-duet)
- **Qwen Code 0.26.0** (updated / TRIAL): UNKNOWN means available evidence cannot prove whether a tool completed. Preserving it avoids repeating payments, messages or writes after restart. [Release](https://github.com/QwenLM/qwen-code/releases/tag/v0.26.0)
- **Flint 1.0** (new / TRIAL, late discovery): Microsoft Research's MIT chart language and MCP server express interactions as semantic events while the compiler resolves rendering dependencies. [Repository](https://github.com/microsoft/flint-chart)

## Research

- **KLS conjecture proof** (new / WATCH, late discovery): researchers combined roughly 100 AI search trajectories with human pruning; parallel proofs and a later Lean 4 formalization provide separate checks. This validates the workflow, not autonomous theorem solving. [Research note](https://www.microsoft.com/en-us/research/blog/solving-a-31-year-old-grand-challenge-in-mathematics-the-kls-conjecture/)
- **Silent Cue Loss** (new / WATCH): across 76 policy documents, micro-F1 fell from 0.690 with preserved cues to 0.150 through Docling and 0.075 as plain text. The words remain, but highlights and colour carrying policy meaning disappear before RAG. No code is public. [Paper](https://arxiv.org/abs/2610.30026)
