## Models

### WeMM-Video（TRIAL）

Tencent 微信视觉团队公开 2B、4B、9B 和 35B-A3B 权重，支持把视频画面与原声一起理解。所谓“音视频联合理解”，是让模型同时读取画面帧和声音，而不是分别转写后再拼答案；难点在于时间对齐和部署时的显存、解码开销。官方给出 Transformers 与 patched vLLM/SGLang 配方，但 benchmark 尚无独立复现。

来源：https://github.com/Tencent/WeMM-Video；https://huggingface.co/tencent/WeMM-Video-2B

### bison-1 / groundhog-1（TRIAL）

两款模型把路由、分类和 rubric scoring 做成 typed decision 请求，并同时提供 API 与权重。Brier score 用来衡量“置信度是否诚实”：预测 80% 的样本长期应约有 80% 正确；它比只看准确率更适合阈值决策。厂商报告的指数成绩不能替代自己的域内校准。

来源：https://www.baseten.co/resources/changelog/bison-1-and-groundhog-1-available-on-baseten；https://labs.baseten.co/articles/bison-1-and-groundhog-1-frontier-american-backbone-decision-models

## Agent & AI Engineering

### OpenRouter 上游数据处理事件（WATCH）

Dragos 在 prompt 中放入唯一 canary secret；若这个诱饵随后被访问，就能证明数据曾离开预期边界，但未必能指出所有隐藏路由层。OpenRouter 随后下线三家供应商、取消 125 个 endpoint 的 ZDR 资格并通知客户，同时称自身系统未被入侵。

来源：https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers；https://www.dragos.com/blog/ai-supply-chain-security-canary-tokens

### Signal AI 屏幕采集限制（WATCH）

Signal 在 iOS 27 禁止截图，并在 Android 可检测时阻止 AI assistant 捕获对话画面。它说明应用可以拒绝系统级 agent 读取敏感 UI，但 Android 用户可关闭、macOS 尚未覆盖，文件系统访问也仍是缺口。

来源：https://signal.org/blog/protecting-your-privacy

### LiteLLM 1.108.15 LTS（TRIAL）

无密钥 JSON 配置现在必须补 api_key 或 provider 专用密钥变量，否则返回 401。ResetData、Groq/Meta 转录费用与 Cohere v2 工具调用也有修复。

来源：https://github.com/BerriAI/litellm/releases/tag/v1.108.15

## Developer Tools

### Qwen Code 0.28.4（TRIAL）

稳定版新增本地 Web Shell artifact library、仅属主可访问的 runtime 状态目录、持久化工具输出恢复保护，以及对终端控制字符和双向文本覆盖符的清洗。双向文本覆盖符会让日志的视觉顺序与真实字符顺序不同，难点是它可能误导人和后续 agent 对失败证据的判断。

来源：https://github.com/QwenLM/qwen-code/releases/tag/v0.28.4
