# AI Intelligence - 2026-10-17

## Daily Executive Summary

- **DeepSeek opens low-cost Search and Fetch APIs**: each costs $0.75 per 1,000 successful non-empty calls; 5 QPS limits and vendor relevance labels constrain use as a general truth source.
- **Dory1.0-4B offers adjustable compute depth from one checkpoint**: one, two or four loops trade accuracy for latency, while stable vLLM and llama.cpp support is not ready.
- **DeepSeek V4.1-Flash-1017 updates both weights and the hosted alias**: interfaces and pricing are unchanged; vendor-reported coding gains need same-task A/B reproduction.
- **RTX Spark brings large-memory CUDA development to Windows PCs**: top configurations advertise 128 GB unified memory, but SKU-level stock, pricing and independent performance are inconsistent.
- **FDE-Gym moves agent evaluation from issue fixing to customer delivery**: 95 tasks require discovering unstated constraints; the best configuration resolved only 14, while the public harness includes three full examples.

## Models

- **Dory1.0-4B** (new / TRIAL): its shared 20-layer recurrent block runs 1/2/4 times. Recurrent depth means reusing the same layers on each token; the hard part is that higher accuracy also costs more compute and current runtimes need unmerged code. [Model card](https://huggingface.co/nvidia/NVIDIA-Nemotron-Labs-Dory1.0-4B-BF16)
- **DeepSeek V4.1-Flash-1017** (updated / TRIAL): MIT weights and the deepseek-flash hosted alias are updated with unchanged price and interface. Terminal-Bench and other results are vendor-run under different harnesses. [Release](https://api-docs.deepseek.com/news/news261017/)

## Agent & AI Engineering

- **DeepSeek Search / Fetch** (new / TRIAL): Search returns structured results and Fetch turns one page into Markdown. The authority field is retrieval metadata, not a certification of factual trust. [Guide](https://api-docs.deepseek.com/guides/search/)
- **Claude Code 2.1.302** (updated / ADOPT): fixes full routine replay after partial failure, lost config writes and MCP compatibility. Routines with external side effects need failure-injection regression. [Stable release](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)
- **Open WebUI 0.12.3** (updated / TRIAL): adds temporary MLS end-to-end encrypted chat, lighter Redis streaming and workspace search. MLS coordinates group-session keys; deployment still requires HTTPS, WebSockets and disabled server-side WebSocket logging. [Stable release](https://github.com/open-webui/open-webui/releases/tag/v0.12.3)
- **GPT-Live prompt-to-voice** (updated / TRIAL): all API customers can create voices from text descriptions. Creation is free and speech uses GPT-Live billing; the voices work only with GPT-Live and creation is incompatible with ZDR. [Documentation](https://developers.openai.com/api/docs/guides/custom-voices)

## Open Source

Dory provides four weight formats, FDE-Gym provides an Apache-2.0 harness and three examples, and DeepSeek 1017 provides an MIT checkpoint. Downloadable artifacts do not reproduce every claim: stable runtimes, full benchmark data and independent evaluation remain the main gaps.

## Research

- **FDE-Gym** (new / TRIAL): 95 tasks cover 20 scenarios and 18 sectors, scored by customer business uplift minus contact cost. An unstated constraint is a rule found only by asking the simulated customer; this is the part code benchmarks usually omit and real delivery often fails on. [Paper](https://arxiv.org/abs/2610.22350) · [Code](https://github.com/deeplethe/fde-gym)
