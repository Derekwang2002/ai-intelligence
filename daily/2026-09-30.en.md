## Models

- **Claude Sonnet 5.5 (TRIAL):** Anthropic made the model available through its API, Claude Code, and all three major clouds. Pricing remains $2 per million input tokens and $10 per million output tokens; Anthropic reports 30%+ faster generation and up to 30% lower task cost. Before migration, check `between_tools`, forced tool choice, thinking-block replay, and computer-use tool versions. Validate performance and cost on your own traces.
- **Kumo Tabular (TRIAL):** NVIDIA released 28M–215M parameter open-weight tabular foundation models that use labeled rows as context for classification or regression without task-specific training. Weights and inference code are public; the training recipe and synthetic-data generator are not. Compare held-out accuracy, calibration, latency, and GPU cost with tuned tree models.

## Agent & AI Engineering

- **MCP TypeScript SDK 2.2 (TRIAL):** Machine-to-machine OAuth providers must now declare an issuer, and mismatched authorization servers are rejected before token requests. List calls without a cursor now auto-paginate. Regression-test large inventories because request count, latency, memory use, and result size can all change.
- **OpenAI Python SDK 3.20 (WATCH):** The SDK adds Agents vault credential metadata, an `ultrafast` session tier, policy-violation results, and incremental WebSocket snapshots. It turns hosted-agent governance states into SDK contracts, but platform availability and support guarantees remain unclear.
- **Failure-Transparent Agents (TRIAL):** Across 100 deterministic tool-failure tasks, six models, and 3,600 human-annotated responses, a structured evidence contract cut false success from 22.8% to 0.8%. MIT-licensed code and data are public, so teams can add “failed step, missing evidence, next safe action” to blocked-task acceptance tests.

## Open Source

- Kumo Tabular weights are ungated, the code is Apache-2.0, and the weights use OpenMDW-1.1. The system is runnable, but training-side artifacts remain incomplete.
- Failure-Transparent Agents provides MIT-licensed code and data. Telescopic Language Models and TokenCast have repositories, but review found only documentation or placeholder files—not reproducible implementations.

## Research

- **KV-streams (WATCH):** Streams KV state across context-compaction boundaries in agentic RL; the paper reports 2.6–5× wall-clock training speedups. Hidden state can survive removal from visible context, improving memory while complicating auditability. No packaged public implementation is available.
- **Telescopic Language Models (WATCH):** Uses stochastic prefix supervision to train a nested Transformer that can exit at any depth. A 200M-parameter proxy reports a 43%–44% lower area under the quality-budget curve, but the result is far from production scale and the repository has no implementation.
- **TokenCast (WATCH):** Forecasts remaining agent tokens during execution. Offline budget replay reports 21.3% fewer tokens at matched completion, but code is not yet published, so it should not control live termination.
- Progressive Disclosure of Agent Skills and other papers were filtered because they lack public artifacts or quantitative results strong enough to change an engineering decision.

## Developer Tools

- **Codex 0.159.0 (ADOPT, updated):** Adds in-flight steering and item-level history pagination. Approved commands preserve filesystem denials, `.aws` is protected by default, and macOS network-sandbox and Windows child-process boundaries are fixed. Regression-test interruption recovery and writable-root policy before upgrading.
- **Qwen Code 0.24.7 (TRIAL, updated):** Managed Runtime now binds workspace identity, persists execution receipts, and reconciles in-flight work after takeover or reboot. It also fixes stale-worktree cleanup that could delete untracked files.
- **Claude Code 2.1.284 (ADOPT, updated):** Adds one-off external-read permission, `/mcp reconnect all`, gateway spend limits, `private_key_jwt`, direct Google Cloud OTLP export, and managed-model policy warnings. Sonnet 5.5 becomes the default Sonnet.

## Infrastructure

KV-streams replaces “flush then prefill” after compaction with continuous state transfer. Telescopic Language Models attempts to serve multiple compute budgets from one checkpoint. Both may affect serving or post-training architecture, but remain small-scale, author-reported frontier evidence. vLLM had no new stable release in this window.
