## Daily Executive Summary

This run adds five events and updates five. ThinkingBox is the most actionable: it checks terminal database state and side effects instead of trusting an agent report. DiarizationLM and Strata have public artifacts for one-day tests. Public Vault API docs move OpenAI Agents Vault from WATCH to TRIAL. Ataraxos and Figma hosted MCP now have primary evidence but remain WATCH.

## Models

### DiarizationLM (TRIAL)

Google opened a 4B speaker-label correction model with local GGUF files. Author tests improve WDER and cpWER on four corpora, but the multi-speaker meeting samples are small. Speaker drift means a long monologue is attached to the wrong identity even when the words are correct.

### Claude Sonnet 5.5 (TRIAL, review)

Artificial Analysis reports about 193k output tokens and $7.60 per task at maximum effort, roughly 50% more than Sonnet 5 in its workload. The vendor's “up to 30% lower cost per task” is not a universal discount.

## Agent & AI Engineering

### ThinkingBox (TRIAL)

ThinkingBox exposes 507 stateful workflows through OpenEnv with 20 trials per model. Terminal-state grading checks the records and side effects left behind; an agent can exit cleanly without a tool error and still write the wrong field or do extra work.

### OpenAI Agents Vault (TRIAL, rating change)

Public docs confirm that sandboxes receive placeholders and a network proxy injects secrets only for allowed hosts. The previous documentation gate is cleared.

### Figma hosted MCP (WATCH)

Figma says only MCP Catalog clients can connect to its hosted server. Protocol compatibility does not guarantee hosted access.

## Open Source

### Strata (TRIAL)

Strata distributes Qwen3.8-Flash-Next experts across GPU, RAM, CPU and SSD and exposes local OpenAI- and Anthropic-compatible APIs. Adoption is strong, but speed and low-bit quality remain author-reported.

## Research

### Ataraxos (WATCH)

Ataraxos combines damped self-play and decision-time search for Stratego. The paper and MIT code are public, but no checkpoint is available, so reproduction is not a one-day trial.

## Developer Tools
