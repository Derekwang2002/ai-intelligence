# AI Intelligence - 2026-11-28

## Daily Executive Summary

1. **Google made eight Workspace MCP servers GA and published 2027 agent-access rules.** From February 1, AI agents accessing Workspace data must use MCP; direct REST agents are limited to Standard Tier quotas. The policy is not yet effective, leaving time to migrate and model cost. [Source](https://developers.google.com/workspace/release-notes)
2. **Qwen Code 0.28.7 strengthens cross-instance recovery while removing built-in loop caps.** Recovery improves, while runaway protection depends more on external budgets and kill switches. [Source](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.7)
3. **LiteLLM 1.108.19 LTS fixes false-success streams and tool routing.** These faults can bypass fallback or strand agents, so cross-provider canaries remain necessary. [Source](https://github.com/BerriAI/litellm/releases/tag/v1.108.19)
4. **Ming-Image 0.2 Design opens 6B weights and code.** It targets text-heavy design and layer decomposition, but the 80 GiB reference setup and preliminary ranking call for real-brief testing. [Source](https://huggingface.co/inclusionAI/Ming-Image-0.2-Design)
5. **GigaChat4 opens a 708B-total, 41B-active model family.** The artifacts are complete, but validation is extremely expensive and independent evidence is limited, making WATCH appropriate. [Source](https://huggingface.co/ai-sage/GigaChat4-708B-A41B)

## Agent & AI Engineering

### LiteLLM 1.108.19 LTS (TRIAL)

The most important change turns an upstream disconnect falsely reported as success into an error that can trigger fallback. A mid-stream abort happens after response bytes have started arriving. If the client sees a clean stop, it may retain a partial answer and skip the backup provider. Tool IDs, thinking signatures, guardrails and spend records need regression tests together.

## Developer Tools

### Qwen Code 0.28.7 (TRIAL)

Cross-control-plane takeover and single-use tickets reduce managed-session interruption during instance changes. Removing loop detection means repeated model tool calls are no longer stopped by the client. Teams need separate call budgets, timeouts and operator stop paths in the gateway or runtime.
