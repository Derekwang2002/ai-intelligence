# AI Intelligence - 2026-11-13

## Daily Executive Summary

1. **Jensen Huang 辞任 NVIDIA CEO，立即生效。** NVIDIA 董事会任命 CFO Colette Kress 兼任临时 CEO，并启动永久继任者搜索；Harvey C. Jones 出任首位董事长。官方没有在公告中说明辞任原因，并称产品路线与客户承诺将继续；这项领导层变化会影响全球 AI 芯片供应与生态判断，因此作为重大综合新闻例外进入摘要，不伪造技术事件。
2. **Google 开放 Gemini Decision 1。** 这个 beta API 可在一次请求中处理最多 1,000 个封闭式判断，输入每百万 token 0.10 美元且输出不收费。它适合路由、审核与排序，但 150–250 ms 时延和质量优势都是 Google 自测，必须用本地标注集校准。
3. **AWS 将 AgentCore Web Search 正式开放。** `InvokeWebSearch` 无需 gateway 资源，使用 IAM 与 SigV4，价格为每 1,000 次查询 7 美元。接口、区域和条款已核实，检索新鲜度与相关性尚未独立测试。
4. **Nex-AGI 公开 Nex-N2.6 权重。** Apache 2.0、无门禁 FP8 权重与 SGLang 部署路径已经可用，给自托管 agent 模型提供了可复跑选项。约 321B 的体量门槛很高，OSWorld 与 Terminal-Bench 成绩仍是发布方自测。
5. **百度开放 ERNIE 5.5 Flash Preview API。** 280B 总参数、14B 激活参数与 1M 上下文已经可通过千帆测试，促销输入价格低至每百万 token 0.5 元。它仍是未完成的中间检查点，承诺 11 月 25 日前开放的权重当前不可下载。

## Models

### ERNIE 5.5 Flash Preview

所谓“14B 激活参数”，是每个 token 只调用 280B 总参数中的一部分专家；难点是低推理成本不等于整个模型容易自托管。API 已开放，开放权重仍只是带日期的承诺。

### Nex-N2.6

Nex-N2.6 的公开权重、许可证与部署说明可核实；发布方报告 OSWorld 83.0、Terminal-Bench 2.1 84.1。本轮没有找到独立复现，因此不把这些分数写成已证实的领先。

## Agent & AI Engineering

### Gemini Decision 1

封闭式判断是从预先给定的 yes/no、选项或有序等级中作答，不是生成一段自由文本。难点在于置信度看起来精确，却可能没有按你的真实数据校准；先测校准误差，再决定能否自动执行。

### AgentCore Web Search

GA 接口覆盖 6 个商业区域，支持 PrivateLink 与 CloudTrail data event；直接 API 不在 GovCloud。AWS 条款要求保留并展示返回的来源引用，因此调用结果不能只抽取文本后丢弃链接。

## Open Source

Nex-N2.6、ZONOS3-Mini、NVIDIA AICR 与 Google Cloud k8s-aibom 均有公开产物。ZONOS3-Mini 提供 Apache 2.0 权重、WebGPU、MLX、ggml 与 SGLang 运行时；43 种语言和实时性能均需独立听测与设备测试。TRELLIS.2 LoRA 指南只有一个 188 个鞋类对象的小实验，本轮保留为教程候选。

## Developer Tools

- **Qwen Code 1.0 Preview：** 合并 Qoder 与 Qwen Code，提供原生安装包、多 provider、session resume 与非交互模式；Preview.1 修复订阅模型登录并启用并行工具调用。它仍是 prerelease。
- **Codex 0.167.2：** Google Cloud Vertex AI 默认改为增量返回工具更新。变更范围较窄，但使用该后端的团队应回归流顺序、重连与恢复。
- **LiteLLM 1.109.1：** 使用 cosign 签名镜像，并默认阻止客户端凭据字段覆盖管理员的 Azure/OIDC 配置。PR 测试已核对，攻击路径与镜像验签尚未独立复现。

## Infrastructure

AI Bill of Materials（AIBOM）把模型、数据集、运行时和工作负载列成可追踪清单，类似软件供应链中的 SBOM。它解决“系统里实际出现了什么”的问题，不解决“这些东西是否安全、合规并成功执行”的问题。
