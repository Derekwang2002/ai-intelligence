# AI Intelligence - 2026-10-17

## Daily Executive Summary

- **DeepSeek 开放低价 Search 与 Fetch API**：两个接口都按成功且非空请求收费，每千次 0.75 美元；5 QPS 和供应商相关性标签限制了它作为通用搜索真值的用法。
- **Dory1.0-4B 用同一权重提供可调计算深度**：一、二、四次循环可换取不同准确率与延迟，但稳定版 vLLM/llama.cpp 支持尚未就绪。
- **DeepSeek V4.1-Flash-1017 同步更新权重与托管别名**：接口和价格不变，厂商报告 coding benchmark 改善；需要同任务 A/B 复测。
- **RTX Spark 把大内存 CUDA 本地开发带到 Windows PC**：高配宣传 128GB 统一内存，但各 SKU 的地区库存、价格和独立性能仍不统一。
- **FDE-Gym 把 agent 评测从修 issue 推到真实客户交付**：95 项任务要求发现未写明约束，最佳配置只解决 14 项；公开 harness 只有三个完整示例。

## Models

- **Dory1.0-4B**（新 / TRIAL）：共享 20 层循环块可重复 1/2/4 次。所谓“循环深度”就是让同一组层反复处理 token；难点是准确率提升会同时增加计算，且当前运行时要用未合并代码。[模型卡](https://huggingface.co/nvidia/NVIDIA-Nemotron-Labs-Dory1.0-4B-BF16)
- **DeepSeek V4.1-Flash-1017**（更新 / TRIAL）：MIT 权重与 deepseek-flash 托管别名都已更新，价格和接口不变。Terminal-Bench 等成绩由厂商在不同 harness 下运行。[发布说明](https://api-docs.deepseek.com/news/news261017/)

## Agent & AI Engineering

- **DeepSeek Search / Fetch**（新 / TRIAL）：Search 返回结构化结果，Fetch 把单个网页转为 Markdown。结果里的 authority 是检索元数据，不是事实可信度认证。[指南](https://api-docs.deepseek.com/guides/search/)
- **Claude Code 2.1.302**（更新 / ADOPT）：修复定时任务部分失败后从头重跑、配置写入丢失与 MCP 兼容问题；有外部副作用的 routine 应做故障注入回归。[稳定版](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)
- **Open WebUI 0.12.3**（更新 / TRIAL）：加入临时 MLS 端到端加密聊天、Redis 流优化与工作区搜索。MLS 是多人会话的密钥协商协议；难点是部署仍要求 HTTPS、WebSocket 且关闭服务端 WebSocket 日志。[稳定版](https://github.com/open-webui/open-webui/releases/tag/v0.12.3)
- **GPT-Live prompt-to-voice**（更新 / TRIAL）：所有 API 客户可用文字描述创建声音，创建免费、语音按 GPT-Live 计费；仅限 GPT-Live，且创建不兼容 ZDR。[文档](https://developers.openai.com/api/docs/guides/custom-voices)

## Open Source

Dory 提供四种权重格式，FDE-Gym 提供 Apache-2.0 harness 与三个示例，DeepSeek 1017 提供 MIT checkpoint。可下载不等于可复现全部结论：稳定运行时、完整 benchmark 数据与独立评测仍是主要缺口。

## Research

- **FDE-Gym**（新 / TRIAL）：95 项任务覆盖 20 个场景和 18 个行业，按客户业务指标提升减去沟通成本评分。“未写明约束”指只有向模拟客户追问才知道的规则；这正是代码 benchmark 通常省略、但实际交付最容易失败的部分。[论文](https://arxiv.org/abs/2610.22350) · [代码](https://github.com/deeplethe/fde-gym)
