## Models

- **New · Microsoft-Decision-1** (TRIAL): It scores fixed choices and returns calibrated probabilities for routing, classification and agent action control. Closed-choice scoring means the answer must come from a supplied option set. The hard part is that this cannot replace open-ended reasoning, and vendor benchmarks may not match production traffic. Foundry and OpenRouter endpoints support a one-day comparison on real routing data.

## Agent & AI Engineering

- **New · Agent Lightning v1.0** (TRIAL): An OpenAI-compatible proxy observes calls from an existing agent harness, so the deployed execution loop participates directly in RL without being rebuilt inside the trainer. Harnessed Agentic RL means training still runs the real agent shell. The hard part is that one rollout becomes a variable number of model calls, so advantage estimation and loss normalization cannot count long rollouts repeatedly. Public code, a Kubernetes control plane and a complete example support a one-day trial.
