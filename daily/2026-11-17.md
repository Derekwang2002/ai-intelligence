# AI Intelligence - 2026-11-17

## Daily Executive Summary

- **CVS 开源 CUA Agent Kit**：agent 先探索流程，再编译为可重复的 Playwright 或 pywinauto 自动化。公开代码可直接试验，但医疗效果与生产规模仍是厂商自报。
- **Qwen4-Max 进入正式 API**：稳定 SKU 提供 100 万 token 上下文，输入/输出分别为每百万 token 1.5/4.5 美元；权重未开放。
- **腾讯发布 HY4 Flash**：多模态 API 报价为每百万输入/输出 token 0.070/0.281 美元。速度与质量来自厂商评测，承诺的开放权重尚未发布。
- **OpenAI 增加潜在 CSAM 分类器**：获批组织可免费调用，但没有公开性能数据；分数不是校准概率，标记也不是法律认定。
- **GitHub 批量启动 AI Scan**：安全概览可一次为最多 20 个仓库启动默认分支扫描，仍处于 public preview。

## Models

### Qwen4-Max 从预览转为生产 API
Alibaba 公布稳定的 qwen4-max SKU、价格与访问入口。厂商给出的 benchmark 和 Work360 成本数据尚未独立复测。[来源](https://www.alibabacloud.com/blog/alibaba-unveils-qwen4-max-for-complex-agentic-workflows_602835)

### HY4 Flash 用低价切入多模态 API
HY4 Flash 有 224B 总参数、12B 激活参数和 100 万 token 上下文。Engram 是把一部分静态知识放进专门记忆参数的结构；它能减少注意力计算，但真实收益仍取决于任务和服务实现。[来源](https://www.tencent.com/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows/)

## Agent & AI Engineering

### CUA Agent Kit 把探索与执行拆开
所谓“探索后编译”，是让 agent 只在第一次找路径，之后改由确定性代码重放；难点是页面变化、权限边界和敏感轨迹仍要单独治理。HealthAdminBench 的 rubric points 是逐项得分，不等于整条流程一次成功，不能与严格端到端成功率直接比较。[代码](https://github.com/cvs-health/cua-agent-kit)
