# AI Intelligence - 2026-11-15

## Daily Executive Summary

1. **Claude Code 2.1.325 修补多条权限与沙箱缺口。** 稳定版修复复合 Bash 命令绕过询问、allow 规则运行了别的程序、重启后 deny 失效，以及 worktree 和公开 artifact 的权限边界。沙箱内 Bash 默认改走正常审批，安全性更清楚，但无人值守任务可能停下来等确认。
2. **Metal Sandbox 公开 Apple Silicon 编程 agent 的原生执行方案。** 它用 Apple App Sandbox 限制文件访问，并在多台 Mac 间调度 Metal 命令。论文和代码已公开；作者只在 4 台 M4 Mac mini 上实验，部分吞吐结果来自固定轨迹重放，不应直接外推到生产集群。
3. **United Airlines 开始阻止未授权个人 AI agent 订票。** 限制覆盖搜索、购买、修改与管理行程，真人操作浏览器和获得授权的行业系统除外。公告只给出 11 月 11 日，没有公开授权接口；这说明交易型 agent 的能力上线前还要通过服务方条款和授权门控。
4. **Haru-4B 把全双工语音 agent 缩到本地可试的 4B 模型。** Apache-2.0 权重和 PyTorch、MLX、macOS、vLLM-Omni 实现均已公开，可同时听说九种语言。它仍是研究基础模型，发布方没有给出可独立核对的对话质量、安全或真实打断评测。

## Agent & AI Engineering

### Metal Sandbox

“轨迹重放”是把已经记录好的 agent 命令序列按新的调度策略重新计算等待时间，而不是让 agent 真正再跑一遍。它适合比较调度器，但难点是新反馈可能改变 agent 后续行为，所以 2.14x 持续吞吐属于估算，不是端到端复现实测。

Metal Sandbox 支持通过 Harbor 运行 Claude Code、Codex 与 mini-SWE-agent。论文明确说明它不是恶意多租户隔离：部分应用启动路径仍可能离开沙箱边界，其他进程也可能争用 GPU。

### Haru-4B

“全双工”指双方可以同时说话和听见对方，而不是等一方说完才轮到另一方。难点在于用户插话时，模型要继续理解新音频、停止或改写自己的输出，并保持对话状态一致。Haru-4B 每 133 毫秒处理一帧，一次同时预测音频与文本，但还没有独立打断质量评测。

## Business & Policy

### United Airlines 限制个人 AI agent

United 表示，将限制未授权的第三方个人 AI agent 通过其平台或中介搜索、预订、购买和管理行程。11 月 11 日前的既有预订继续有效；新政策下的未授权 agent 预订可能被取消。这里的关键不是模型会不会点网页，而是服务方是否允许它代表用户承担交易后果。

官方页面只给出发布日期，没有时分；本条由召回自检补录为 `late_discovery`，不声称完成逐小时边界核验。NVIDIA CEO 交接已在前次日报作为重大综合新闻补充，本轮后续报道没有改变已记录的事实阶段。
