## Open Source

### Numbat 假权重

`burner22/numbat` 声称上传了 Anthropic 未发布模型的 7.72 TB checkpoint，但没有 Anthropic 认证。社区审计能用 tensor 名称作为随机种子，逐位重建 43 个完整 tensor；独立复核也重建了 9 个样本。所谓“种子噪声”，就是文件里的数值可以由一条固定随机规则重新生成，而不是训练学出来；难点是不能只看文件大小和结构自洽就判断来源。该仓库按 IGNORE 处理，并标记为 overlap 内漏检后补。

### vLLM 0.33

稳定版把 CUDA 13.0 设为唯一 CUDA 发布基线，ROCm 默认转到 10.0，同时保留 7.2 路径；还加入 AWS EFA 镜像、`/v1/decisions`、watchdog 与更多低精度 KV 路径。“投机解码”是先用较小或更便宜的路径猜多个 token，再由主模型验证；难点是加速收益取决于接受率与负载，项目 benchmark 不能直接代表生产。发布说明仍留有产物链接核验 TODO，升级前应验证 wheel、镜像、端点暴露与回滚。

## Infrastructure

### OpenAI Grid Protectors

OpenAI 宣布未来算力园区在电网紧张时降低负载，部分地点还可能用现场发电或储能供电。所谓“需求响应”，就是电网在峰值时要求大用户暂时少用电；真正难点是提前多久通知、能降多久，以及计算任务和排放会付出什么代价。Georgia 的 25 年协议已获批，规划需求约 3.2 GW，最多可削减 1 GW，但园区仍在建设。Georgia Power 所说的每年 9.5 亿美元是大型负载协议组合的预测，不是 OpenAI 单项或已实现节省。

### NVIDIA Workload Map

Workload Map 用 CRD 和 Go 库把 JobSet、PyTorchJob、Ray、KServe 等不同 Kubernetes 对象转成统一树结构。CRD 可以理解为给 Kubernetes 增加新资源类型；难点是不同框架对副本、资源和状态的表达并不一致。NVIDIA 称 Run:ai、KAI Scheduler 与 Elotl Nova 已复用这层映射，但独立的生产验证仍缺失。
