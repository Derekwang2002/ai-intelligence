# AI Intelligence - 2026-11-18

## Daily Executive Summary

- **Hugging Face moves language-model routing to OpenRouter**: the API stays familiar, but provider, billing and data paths change, and custom provider keys no longer work for language models.
- **vLLM 0.34 changes KV-cache and runner defaults**: it adds capacity and recovery controls, but the project warns of a possible 6–18% TPOT regression and changes ROCm and block-size compatibility.
- **TokenEconomizer becomes publicly testable**: publishers report 18.4–30.9% lower cost on 277 real bug-fixing tasks, while current-agent compatibility still needs validation.
- **Daybreak gains NATO field-adoption evidence**: NATO CCDCOE confirms an AI-agent training stream at Crossed Swords and OpenAI reports NCIA usage up to 300B tokens per month; effectiveness evidence remains participant-reported.
- **SciResearch-Eval exposes scientific-agent overconfidence**: most agents include truth in their claimed 95% interval only 20–62% of the time when simulators are wrong.

## Models

Plotly adds independent Inkling 2 Small evidence: 39/43 on its private DataAnalyticsBench at $1.81, but about 13 calls and 5,700 output tokens per question. The private answers and OpenRouter execution limit reproducibility, so the recommendation remains TRIAL.

## Agent & AI Engineering

TokenEconomizer micro-skills are small reusable lessons extracted from earlier work in the same repository. The hard part is keeping those lessons fresh so token savings do not preserve stale mistakes. Hugging Face and OpenRouter also require a fresh check of routing, data and billing boundaries.

## Open Source

Qwen Code 0.28 shares one agent loop across headless, TUI and subagents, with managed worktrees and cross-session messages. A one-day three-session test can check isolation and recovery.

Sage S2.1 Flash also opens 321B MIT weights and scientific projectors. Publisher benchmarks remain unreproduced, so it stays at TRIAL.

## Research

A claimed 95% interval should contain the true value about 95% of the time if uncertainty is honest. Most SciResearch-Eval agents fall far short when the simulator is wrong. Public code supports reruns, but the 38-task test set remains small.

## Developer Tools

Claude Code 2.1.326 fixes silent failures in background tasks, configuration writes and parallel MCP routing. Qwen Code 0.28 advances shared loops and managed worktrees. Both warrant unattended-flow regression tests.

## Infrastructure

vLLM extensible KV sizing uses warmup results to set cache capacity. More concurrent capacity does not guarantee faster tokens, and the release explicitly warns of a TPOT regression.
