## Models

### WeMM-Video (TRIAL)

Tencent WeChat Vision released 2B, 4B, 9B and 35B-A3B weights that can reason over video frames and the original soundtrack together. Joint audio-video understanding means processing frames and sound in one model rather than merging separate transcripts; temporal alignment, memory and decode cost are the hard parts. Official Transformers and patched vLLM/SGLang recipes are public, while benchmarks await independent reproduction.

Sources: https://github.com/Tencent/WeMM-Video; https://huggingface.co/tencent/WeMM-Video-2B

### bison-1 / groundhog-1 (TRIAL)

The models expose routing, classification and rubric scoring as typed decision requests, with both APIs and weights. Brier score measures whether confidence is calibrated: predictions made at 80% confidence should be correct about 80% of the time. Publisher index results do not replace calibration on the target domain.

Sources: https://www.baseten.co/resources/changelog/bison-1-and-groundhog-1-available-on-baseten; https://labs.baseten.co/articles/bison-1-and-groundhog-1-frontier-american-backbone-decision-models

## Agent & AI Engineering

### OpenRouter upstream data-processing incidents (WATCH)

Dragos placed unique canary secrets in prompts. Later access proves that data crossed an intended boundary, but does not always identify every hidden routing hop. OpenRouter then off-boarded three providers, revoked ZDR eligibility from 125 endpoints and notified customers, while stating that OpenRouter itself was not breached.

Sources: https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers; https://www.dragos.com/blog/ai-supply-chain-security-canary-tokens

### Signal AI screen-capture controls (WATCH)

Signal blocks screenshots on iOS 27 and, when Android exposes detection, prevents AI assistants from capturing private chats. The control shows that apps can reject OS-level agent access to sensitive UI, but Android users can disable it, macOS lacks equivalent coverage and filesystem access remains a gap.

Source: https://signal.org/blog/protecting-your-privacy

### LiteLLM 1.108.15 LTS (TRIAL)

Keyless JSON configurations must now supply api_key or a provider-specific key variable or receive HTTP 401. ResetData, Groq and Meta transcription spend, and Cohere v2 tool calls also receive fixes.

Source: https://github.com/BerriAI/litellm/releases/tag/v1.108.15

### Qwen Code 0.28.4 (TRIAL)

The stable release adds a local Web Shell artifact library, owner-private runtime state directories, protected persisted tool-output recovery, and sanitization for terminal control characters and bidirectional-text overrides. Bidi overrides can make visual log order differ from the underlying characters, potentially misleading people and downstream agents reviewing failure evidence.
