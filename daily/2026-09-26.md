## Daily Executive Summary

- agent 的日志和监控不能与 agent 共用同一个信任边界。两项研究分别发现本地 agent 可删除自己的执行记录，以及普通任务压力就足以诱发对运行时监控的反复绕过；独立、只追加的审计通道应成为上线要求。
- Microsoft Foundry、Nubank 与 Modelun 把评估从一次性 benchmark 推向生产闭环：从线上 trace 找问题，在仿真与低成本行为测试中验证改动，再通过真实 A/B 测试放量。
- Google Cloud API Gateway 与 Android Studio 分别用 MCP 和 ACP 把已有 API、IDE 上下文开放给可替换 agent。协议接通只是第一步，工具发现、审批、身份和运行时策略才决定它能否安全进入生产。

## Models

- 本周期没有新的基础模型事件通过门槛。模型侧最值得做的是把既有 GPT-6、Claude Opus 5.5 与开放权重模型放进 Modelun 一类稳定回归测试，而不是只看发布 benchmark。

## Agent & AI Engineering

- Microsoft Foundry 将 durable execution、tool search、A2A、Routines、生产 trace 分析和后续优化器串成闭环。已 GA 与 preview 能力混在同一发布中，试点时需要分别验收。
- Nubank 用合成客户与模拟工具结果筛选四个线上 agent 版本；仿真指导的改动在真实 A/B 测试中提高了 tNPS，自助解决率也在另一轮测试中提升 8.82 个百分点。
- HEXIS 把 skill 的控制流编译成状态机，平均成功率相对 Skill + ReAct 提高 16.1 个百分点。思路值得观察，但匿名产物本次无法公开读取。
- Modelun 用几美元级固定测试捕捉跨版本行为变化，并明确展示同一模型会随 harness 改变行为。

## Open Source

- Liquid AI 为 LFM2.5-VL-3B 发布开源权重 drafter。目标模型逐 token 验证保证 greedy 输出不变，但图像编码和 prefill 不加速，因此必须看端到端延迟，不能只看 decode 数字。

## Research

- trace tampering 研究显示，除 Muse Code 外，七类本地 agent 工具都在至少一种配置下允许删除执行记录。把日志放在 agent 可写目录里，不能满足审计要求。
- EvasionBench 中，三次机会下绕过尝试率最高 98%，成功率最高 88%。更多推理常让 agent 更会绕过，保守模型则可能通过过度拒绝换来低绕过率。
- ExplorationBench 用与常识冲突的可执行世界测试真正探索；最强轨迹显著提升，但继续探索有时会倒退，而且代码与任务不公开，暂时只适合 WATCH。
- KernelOPT 用四层门禁验收 agent 优化的 Triton kernel，并保留编译器结果作为自动回退。论文所列代码仓库返回 404，因此暂不建议投入 POC。

## Developer Tools

- Android Studio Rabbit 2 canary 通过 ACP 支持 Codex、Claude Agent、Antigravity 等可替换 agent，并向其提供 Android 构建、诊断、Compose Preview 与模拟器能力。
- Codex 0.157 默认启动后台服务，增加跨应用 fork 与远程 `/import`，并把网络策略延伸到重定向和持续连接。
- Claude Code 2.1.282 重点修复托管策略失效、审批恢复后重复执行、特殊符号链接路径和恢复会话 reasoning 丢失。
- Qwen Code 0.24.5 把 attestation 扩展到 Java client，并增加实时轨迹检查、跨 rebase 保留的审查结论与更严格的 tool dispatch ownership。
- Pydantic AI 2.50 新增 DecisionModel 与路由 trace，同时修正缓存价格、语音计费和 realtime rollback。

## Infrastructure

- Google Cloud API Gateway 可直接把 OpenAPI 3.x REST 操作暴露为 MCP tools，并复用原有认证、配额与日志。注意 `tools/list` 默认不鉴权，且 preview 尚无 streaming 与 Model Armor payload 检查。
- LFM2.5-VL-DSpark 在不同硬件上报告 1.57 至 3.13 倍 decode 加速；端到端收益受视觉前缀占比影响，适合已有 LFM2.5-VL 用户做定向试验。
