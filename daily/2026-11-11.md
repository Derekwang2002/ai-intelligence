# AI Intelligence - 2026-11-11

## Daily Executive Summary

1. **Claude Fable 5.2 已向所有用户开放并降价。** Artificial Analysis 给出 65 分，但 max effort 的 TTFT 为 235 秒、单任务约 44.4 分钟和 26.54 美元，领先分数不等于更快或更便宜。

3. **Gemini 4 Carbon 从受限预览进入付费 API。** 输入 $2/M、输出 $10/M 的首发价改变高精度知识工作的成本比较。
4. **Google 发布 TPU 8tx 与 TPU 8i Max。** 两套系统分别面向机密推理和大上下文；地区、配额和价格未完整披露。
5. **Google 与 Artificial Analysis 发布 MKA 多模态知识工作评测。** 统一 harness 与 10 个公开任务可复跑，但完整 200 题仍是私有闭集。

## Models

### Claude Fable 5.2 / Mythos 5.2

Fable 5.2 已向所有用户开放，Mythos 5.2 继续通过 Cyber 与 Life Sciences Verification Program 控制访问。Anthropic 报告多项 coding、科研与机器人提升，但大多是内部测试或预发布客户经验。官方页面只有 11 月 9 日日期；Claude Code 2.1.321 在 19:22Z 的稳定版记录确认模型已在本窗口内可用。

### Muse Ember

Muse Ember 已通过 Meta Model API 开放，价格为输入 $0.10/M、输出 $0.50/M token。官方将它定位为轻量 agent 与工具调用模型；没有开放权重，质量与安全需在真实工具链验收。

### Gemini 4 Carbon

Carbon 已在 Google AI Studio 与 Gemini for business 的付费 API 开放，并向 Google AI Ultra 用户逐步推出。低首发价让它值得进入真实文档和 agent 任务 canary。

## Agent & AI Engineering

### Hugging Face Decision Models

新的统一接口让模型直接对动态候选项返回 choice、score、boolean 或多选结果及概率，不必先生成文本再解析 JSON。它适合路由与审核，但概率校准、未知类别和候选项变化仍需本地测试。

### HiVe-Mem

HiVe-Mem 先沿文本与视觉关系扩展召回，再为每条记忆选择摘要、原始对话、图片或局部视觉证据。作者报告 token 用量下降约 90%，代码已按 MIT 开放。

**概念解释：** “横向扩展”解决漏召回，“纵向证据选择”决定每条记忆要带多少原文或图片；难点是召回更多会增加噪声，保留更多证据又会吃掉上下文。

## Open Source

### Agent Substrate

项目进入 CNCF Sandbox，目标是把 agent session 的内存和文件系统从 Pod 生命周期中拆出来。CNCF Sandbox 代表社区孵化入口，不代表通过生产成熟度认证。

### NVKE / NVKR

两项目以 Apache 2.0 public preview 发布：NVKR 构建固定版本的节点镜像与软件包，NVKE 通过 REST API 和控制器管理客户 Kubernetes 集群。官方明确暂不建议生产使用。

## Research

### Multimodal Knowledge Agent benchmark

MKA 的 200 个任务要求 agent 交付文档、图表、表格和演示材料，而不只是回答问题。所有模型使用同一 Stirrup harness、工具、沙箱和 turn budget；10 个公开任务可用于复跑。

**概念解释：** 闭集题库能避免模型从网上搜到答案，但外部团队无法完整下载核验；因此榜单可比较，方法透明度仍受限。

- **Claude Code 2.1.321/322：** 修复 MCP OAuth secret 跨主机跳转、沙箱外只读命令和 cp/mv deny 规则缺口；批准记录泄露真实密钥仍无公开可核实修复。

## Infrastructure

### TPU 8tx / TPU 8i Max

TPU 8tx 在硬件层保护使用中的数据和权重，TPU 8i Max 将两颗 TPU 8i 组合到同一封装以提高内存带宽与机架密度。Google 还发布或开放 TPU agent suite、TPU Sync、Cloud Pathways 与 GKE dynamic slicing；其中 preview、开源与 GA 的阶段不同。

**概念解释：** 机密计算保护“正在被计算”的数据，而不仅是磁盘或网络中的密文；难点是安全隔离不能只看功能，还要核对可验证边界和性能代价。

### NVIDIA Snapshot

Snapshot 保存已初始化的 CPU/GPU 内存状态，支持八张 GPU 和最高约 1 TB checkpoint。发布方测试使用 B200 与 VAST NFS；在普通网络存储上是否仍有同等收益未知。
