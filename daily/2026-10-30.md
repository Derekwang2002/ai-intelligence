## Models

### Mistral Large 4 开放权重

承诺的权重现已可下载。开放权重不等于无限制开源：许可证允许商业与非商业使用，但 MaaS 运营需要单独授权；1T 模型的显存与服务成本也尚未独立测量。

### Gemini 4 Carbon 受限预发布

Carbon 当前只给部分网络防御者使用，不是 GA，也没有通用 API。Google 的 benchmark 只能证明厂商报告了这些结果，不能证明外部团队能复现。

## Agent & AI Engineering

### Concordat 把协议约束放进运行时

类型状态协议（typestate protocol）把 agent 当前能做的动作写成有限状态机；难点是长任务恢复、人工确认与工具副作用必须保持同一状态。公开实验只覆盖航空任务，适合做小规模复现，不足以证明通用安全。

### Coding-agent runtime 继续收紧边界

Qwen Code 0.26.4 增加 autofix 轮次预算、独立 worktree 与快照绑定验证。Copilot 云会话则把跨端恢复、企业权限与 MCP allowlist 接到 GitHub 托管 sandbox。

## Open Source

### AnySpeechRecognizer 与 AnyDecisionModel

两个 Swift 包把 Apple 端侧语音与受约束决策封装为统一接口。受约束决策不是让模型自由生成答案，而是在给定选项里返回概率或选择；难点是后端、token 约束与依赖版本必须一致。当前 Core AI 依赖冲突是明确的集成阻塞。

### Granite Switch 4.1.1

IBM 在不改基础模型的情况下更新适配器，把 ASR 扩展到十种语言。Decision adapter 的提升来自厂商自测，承诺的 Adapter SDK 仍未发布。
