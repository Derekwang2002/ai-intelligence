# AI Intelligence - 2026-10-27

## Daily Executive Summary

- **Cloudflare confirms a cross-tenant KV-cache leak on Workers AI.** 155 GLM-5.3 responses included other customers’ data; Cloudflare remediated it and calls for SGLang upgrades plus content-level isolation tests. [Incident report](https://blog.cloudflare.com/kv-cache-exposure-remediation/)
- **GPT-6.1 Terra makes computer use available at a lower price.** It is GA in the API, ChatGPT Work and Codex at $1 input and $5 output per million tokens, while performance claims remain OpenAI-reported. [Announcement](https://openai.com/index/introducing-gpt-6-1-terra)
- **Baidu publishes Unlimited-OCR-2 weights.** MIT-licensed weights, code and inference paths are available; fixed working references target ultra-long documents, while benchmark leadership remains vendor-reported. [Model card](https://huggingface.co/baidu/Unlimited-OCR-2)
- **Qwen Code 0.26.2 tightens both permissions and recovery.** Managed session rules, token-injection hardening, snapshots and HTTP recovery expand the fault-injection surface. [Release](https://github.com/QwenLM/qwen-code/releases/tag/v0.26.2)
- **Anthropic publicly filed for an IPO, but the offering is not complete.** The SEC accepted the S-1; share count and price are unset, and the registration is not effective. [SEC filing](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/0001628280-26-067168-index.htm)

## Agent & AI Engineering

- **Qwen Code 0.26.2 (updated / TRIAL):** managed session rules and auto approval govern who can do what; snapshot, HTTP and journal recovery govern whether a crash repeats tool effects.
- **Claude Code 2.1.311 (updated / ADOPT):** fixes stale memory after compaction, duplicate skills after restart, premature background-worktree cleanup and several session-recovery failures.
- **RCAtlas Harness (new / WATCH):** the shared evaluation reports 65–77% PR@1 for simple harnesses versus 16–53% for hand-crafted RCA agents. PR@1 is whether the first root-cause judgment is correct; missing code limits transfer to incidents with different access and evidence gaps.
- **Mission Control 2.5 (new / TRIAL, late discovery):** closed-loop recovery keeps workloads running on healthy nodes while hardware diagnosis proceeds in parallel.

## Open Source

- **dSpark (new / WATCH):** training and evaluation code is public, but checkpoints, training data and license metadata are missing; the documented training setup uses four A100 GPUs.
- **InteractiveWorld (new / WATCH, late discovery):** Meta publishes a stateful 3D simulator and 120 multi-turn tasks. CC BY-NC terms, about 100 GB of assets and dependency licenses raise reproduction cost.
- **PaperPilot (new / IGNORE, late discovery):** community attention rose, but v0.6.0 remains prerelease and the benchmark table is still a placeholder.

## Research

- **Unlimited-OCR-2 (new / TRIAL, late discovery):** SR-SWA keeps a fixed working-reference set so each step need not revisit the full growing document. The hard part is validating cross-page accuracy, memory and latency on real scans.


- **OpenAI Math Results (updated / WATCH, late discovery):** Lean checks whether a formal statement follows from stated axioms; it does not by itself prove the statement captures every intended research claim. Independent acceptance remains the key limit.
- **DecisionRAG (new / WATCH):** jointly scores branches of a document tree in one forward pass without first-stage dense retrieval. Authors report 0.7–1.8 second retrieval, but publish no implementation or independent reproduction.
- **REVA (new / WATCH):** feeds a threat model, static analysis and call graph into an LLM, then probes hidden representations. Authors report about one second per function, but 60.0% accuracy is insufficient for autonomous blocking.
- **dSpark (new / WATCH):** schedule distillation learns which token reveal will help other positions, not merely which token is most certain now. Reported speedups are material, but artifacts remain incomplete.
- **LIFT-Bench (new / TRIAL, late discovery):** scoped constraints apply only to selected passages; reliance on a fixed Gemma judge limits generalization.

## Developer Tools

- **Qwen Code 0.26.2 (updated / TRIAL):** verify project environment variables cannot hijack serve-token resolution and recovery does not replay side-effecting tools.

## Infrastructure

- **NVIDIA Minerva (late discovery):** a dynamic knowledge graph connects hardware, links, schedulers and jobs; vendor effects lack independent validation and Minerva has no committed GA date.
- NVIDIA's DGX Spark MoE tuning article is useful engineering guidance but does not establish a transferable new product or independent performance result, so it was not stored as a separate event.

- **KV cache tenant leak (new / ADOPT):** Cloudflare confirms 155 GLM-5.3 responses read other customers’ cache pages. A KV cache stores intermediate model state to avoid recomputation; the hard part is preserving page ownership and lifetime across disaggregated prefill/decode machines.
