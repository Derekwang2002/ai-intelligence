# AI Intelligence - 2026-10-21

## Daily Executive Summary

- **Mistral 开放 Voxtral 3 语音 agent 栈**：转写、实时语音、TTS 与 SDK 已提供区域化 API，价格适合试验；准确率和质量比较仍是厂商数据。
- **Claude Code 2.1.304 收紧无人值守执行边界**：人工专属审批、危险 `rm` 询问和组织策略刷新修复，直接影响 coding agent 的安全升级。
- **ALTK-Evolve 让 agent 从历史任务学习指令**：公开代码在小型 held-out 客服测试上提高 10 个百分点，但还没有独立复现或真实部署证据。
- **OpenAI 公开 MultiLangBench**：20 种低资源编程语言有了 Apache-2.0 测试集；厂商模型成绩不能替代仓库级迁移验证。
- **DeepSeek 开源生产推理引擎 DeepInfer**：调度、确定性与结构化输出代码已公开，但当前只有窄硬件上的离线推理路径。

## Models

- **Voxtral 3**（新 / TRIAL）：Mistral 已开放欧洲、美国与全球 endpoint。转写起价 0.0035 美元/分钟，实时转写 0.008 美元/分钟，TTS 每百万字符 13 美元；语言覆盖与 benchmark 均来自厂商。[官方发布](https://mistral.ai/news/voxtral-3/)
- **Mercury 3**（新 / TRIAL）：Inception 的扩散语言模型已通过自有 API、OpenRouter、Baseten 与 Vercel 开放，并提供 1 亿免费 token。低延迟和效果比较仍是厂商结论，应在同一任务上测成功率、输出长度、P95 延迟与总成本。[官方发布](https://www.inceptionlabs.ai/blog/introducing-mercury-3)

## Agent & AI Engineering

- **ALTK-Evolve**（新 / TRIAL）：它把完成任务后的经验整理成可编辑的 prompt 级行为记忆，而不只是把旧文本塞进向量库。难点是错误轨迹也可能被学进去，因此要同时测收益与记忆污染。[研究说明](https://huggingface.co/blog/ibm-research/altk-evolve-bc)

## Open Source

- **MultiLangBench**（新 / TRIAL）：OpenAI 公开了 20 种编程语言的题目与测试，Apache-2.0 仓库在 10 月 19 日 20:58 UTC 创建。官方文章早于 overlap，但可运行仓库在 overlap 内出现，因此按漏检补录。[代码仓库](https://github.com/openai/MultiLangBench)

## Research

- **MultiLangBench** 报告 GPT-6 Astra 平均测试通过率 87.4%，GPT-5.6 Sol 为 26.8%，但结果由 OpenAI 自行运行。测试通过率只说明给定测试是否过关；遗留系统迁移还要验证构建、集成、数据格式和运行时行为。[研究文章](https://openai.com/index/low-resource-programming-languages/)
- Ling-3.1-flash 的第 7 天复核没有发现独立 benchmark 或可复现的 1M 上下文配方，维持 WATCH。
