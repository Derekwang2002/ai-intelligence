# AI Intelligence - 2026-10-21

## Daily Executive Summary

- **NVIDIA 把 agent 治理推进到 OpenShell 与 Sentry**：OpenShell 已开放源码，可把策略执行放到 agent 之外；Sentry 的 BlueField-4 硬件隔离层要到 2027 年初才计划开放。
- **OpenAI 模型与 Codex 将进入 Google Cloud**：可通过 Marketplace 使用 GCP 承诺额度，但 GA 仍需数周，地区、价格与数据边界尚未完整公布。
- **GitHub 把 Package Firewall 开放为 public preview**：组织可统一代理 npm 下载并执行冷却期、安全公告和证明降级策略；目前仅覆盖 npm，GA 后计划计费。
- **RFD4-Proteina 开放蛋白质联合设计代码与权重**：公开产物足以复现方法，但采样提速和设计质量仍是发布方结果，不能代替生物实验。
- **FairStress 揭示最终答案一致也可能掩盖决策不对称**：公开核心集可测试模型是否更容易被同类说辞推向某一人口群体，但只代表一种公平定义。

## Models

- **Voxtral 3**（新 / TRIAL）：区域化语音 API 已开放，价格明确；质量数据仍由厂商提供。[官方发布](https://mistral.ai/news/voxtral-3/)
- **Mercury 3**（新 / TRIAL）：扩散语言模型 API 已开放，延迟与质量需同任务复核。[官方发布](https://www.inceptionlabs.ai/blog/introducing-mercury-3)
- **Granite Speech 5**（新 / TRIAL）：Apache-2.0 权重覆盖 2B 高准确率模型、470M Turbo CTC 与长音频说话人归属。难点是 WER 低不等于会议里说话人标注可靠，需同时测 cpWER。[发布说明](https://huggingface.co/blog/ibm-granite/granite-speech-5)

## Agent & AI Engineering

- **ALTK-Evolve**（新 / TRIAL）：公开代码让 agent 从历史任务提炼行为记忆，同时要测错误轨迹污染。[研究说明](https://huggingface.co/blog/ibm-research/altk-evolve-bc)
- **Distributed Agents**（新 / TRIAL）：数千 agent 并行分析小鼠脑细胞数据，代码、保存输出、notebook 与只读 MCP 语料已公开。它提出的是待实验线索，不是诊断结论。[研究说明](https://openai.com/index/scaling-ai-research-for-complex-biological-data/)

## Open Source

- **MultiLangBench**（新 / TRIAL）：20 种低资源编程语言有了 Apache-2.0 测试集。[代码仓库](https://github.com/openai/MultiLangBench)
- **OpenShell**（新 / TRIAL）：Gateway、Supervisor、Sandbox 与 Policy Prover 把权限放到 agent 之外。Sentry 仍是未来能力，不能混为已可用。[代码仓库](https://github.com/NVIDIA/OpenShell)
- **RFD4-Proteina**（新 / TRIAL）：BSD-3-Clause 代码、免申请权重与测试数据已公开。推理时搜索会从得分更高的中间设计继续分支，但更快采样不等于蛋白质能结合或在体内有效。[发布说明](https://developer.nvidia.com/blog/design-proteins-with-rfd4-proteina-using-reward-guided-inference-time-search/)

## Research

- **FairStress**（新 / TRIAL）：300 个场景扩展为 1300 多万测试，并提供 5 万条核心集。成对前缀测试同类说辞是否让模型对不同群体改变决定；这比只看最终选择多检查了一层稳定性。[研究说明](https://huggingface.co/blog/allenai/fairstress)
- 9 项到期复核均完成：OSWorld-Pro、DUMA-Bench、RRSI、轨迹采样、agent 合谋、MSI-Bench、Grok 4.7、HiRO-ACEv2 与 Grok Voice 3.0 均未出现足以改变处置的新独立证据。
