## Daily Executive Summary

1. **Claude Code approval records put real secrets into public repositories.** Apiiro found 2,539 real secrets across 1,994 public repositories. Anthropic says it is exploring auto mode and basic secret scanning, but no shipped fix was verified. Teams should scan Claude settings, transcripts and Git history now and rotate matched credentials.
2. **Anthropic splits agent memory into context, notes and offline review.** First-party tests show gains on selected database, game and multi-agent tasks, but the samples are small, tasks narrow and results independently unreplicated.
3. **Qwen Code 0.27.0 moves concurrent questions and repository routing into stable.** Multiple questions can wait in parallel without mixing drafts. Repository allow/block filters and editing fixes reduce the error surface, but recovery still needs independent testing.
4. **LiteLLM 1.108.3 fixes large MCP results and duplicate guardrails.** Tool results above 1 MiB no longer end SSE streams silently, and post-call guardrails no longer run twice. Shared gateways should canary first.
5. **llama-modchip’s 284B CPU claim does not justify migration yet.** Code, binaries and weights are public, but the 64 GB and 9–11 token/s headline figures are maintainer-only. A custom format costs more than the current evidence supports.

## Agent & AI Engineering

- **Anthropic Agent Memory** (WATCH): the research separates active context, persistent notes and offline “dreaming.” Dreaming here means rereading experience between tasks and correcting old notes, not training the model. The hard part is avoiding the promotion of a wrong experience into persistent fact. CL-Bench and both case studies are first-party tests; wait for cross-domain reproduction.
- **LiteLLM 1.108.3** (TRIAL): fixes MCP results above 1 MiB failing since 1.103.0, duplicate model-level post-call guardrails and all Bedrock requests failing when `api_base` is empty. SSE is a server-to-client event stream; large tool results crossing proxy and streaming boundaries can look like a hang instead of a clear size error.

## Open Source

- **llama-modchip** (IGNORE): publishes Apache-2.0 code, binaries and compressed weights. The maintainer claims CPU decoding of a 284B model in about 57.6 GiB, but independent throughput, perplexity and task-quality reproduction is missing. Community attention does not replace that evidence.
- **Qwen Code 0.27.0**: the stable release and cross-platform artifacts are public; concurrency, locking and permission guarantees still come from project release notes.
- **LiteLLM 1.108.3**: the LTS image includes a cosign verification command; the three fixes have no independent regression results yet.
