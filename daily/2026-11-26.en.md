## Daily Executive Summary

1. **Humanity's First Exam separates occasional success from consistent success.** Google DeepMind uses 544 elementary text and image prompts to test whether small variations change an answer. The Kaggle sample is usable, but the full held-out set is private and tasks target known failure regions, so the score is not an everyday failure rate. [Source](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/humanitys-first-exam/)
2. **Delegent lets a strong model delegate only bounded subtasks to a local small model.** Apache-2.0 code, tests and reproduction instructions are public. The authors report 59%–67% lower frontier-model cost on two evaluations without fewer completed items, but independent reproduction and adoption evidence are absent. [Source](https://github.com/castorini/delegent)
3. **WePocketModel now runs on Apple silicon through MLX.** The 2B and 4B builds use one model for text-image generation, embeddings and structured decisions. The publisher reports a 4.25 GiB peak for 4-bit 4B on an M3 Pro. Weights and runtime are Apache-2.0, while quality and speed remain publisher-run. [Source](https://huggingface.co/tencent/WePocketModel1.0-4B-MLX)
4. **ERNIE 5.5 Flash Preview weights are now verifiably downloadable.** Baidu provides mixed FP4/FP8, FP8 and BF16 checkpoints with vLLM and SGLang recipes. This remains an unfinished intermediate checkpoint with 20 vendor-run benchmark rows. The update closes the prior evidence-access deferral; it is not a November 25 release. [Source](https://huggingface.co/baidu/ERNIE-5.5-Flash-Preview)
5. **OpenAI reports wet-lab binding evidence for GPT-6 protein designs.** GPT-6.2-derived designs showed binding across five targets, and redesigned antibodies retained binding. Specialist biology models still filtered candidates, the strongest system is private, and binding does not establish specificity, stability, safety or therapeutic effect. [Source](https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities/)

## Models

### WePocketModel MLX (TRIAL)

WePocketModel puts generation, text-image embeddings and structured decisions in one multimodal backbone. Matryoshka Representation Learning (MRL) lets applications use prefixes from 64 to 2,048 dimensions from the same embedding. Shorter vectors save index space, but teams must test whether recall survives truncation. The 2B and 4B MLX weights, runtime and 4/8-bit paths are public.

### Kolibri 1.1 (TRIAL)

Kolibri 1.1 specializes in German and English with open 75B MoE weights, tool calls and long-context paths. Sparse activation reduces per-token compute, but the full weights still need about 77.6GB of memory. Publisher quality and cost claims need testing on real bilingual RAG work.

### LingSante-3.1-air-VL (WATCH)

The 124B/5.5B-active model combines medical images, reports, evidence retrieval and GUI actions in open weights. Its card prohibits independent diagnosis, prescribing, triage and treatment decisions. Simulations and publisher benchmarks do not replace clinical validation.

### MemT-1.0-Pro (WATCH)

MemT compresses cross-turn history into a fixed-size latent state and exposes save and restore operations. Latent memory is an internal numeric state rather than retrievable source text. The hard questions are traceability, forgetting and contamination after storage savings. The Pro model totals 554B parameters, requires custom code and still trails text-retrieval memory overall, so smaller independent reproductions should come first.

### ERNIE 5.5 Flash Preview (TRIAL)

The prior run could see Hugging Face metadata but could not fully read the model card, so it deferred the lead. This run verified three checkpoint formats, Apache-2.0 licensing and deployment instructions. The repositories were created November 23 and updated November 24, before this run's overlap. The new fact is verified readability and downloadability, not a new publication date.

### Ling-3.2-air independent evaluation update (TRIAL)

Artificial Analysis scores the model 23 on a nine-evaluation Intelligence Index, above the comparable open-weight median of 5. This replaces a publisher-only evidence gap. The run produced 199M output tokens and reports neither speed nor price, so deployment economics remain unresolved.

## Agent & AI Engineering

### Delegent (TRIAL)

Delegent differs from routing an entire task: the strong model keeps planning and acceptance responsibility, while local models receive bounded search, test and code-investigation work. The hard part is whether a bad delegation omits critical evidence or adds more latency than it saves in API cost. The public repository supports a one-day comparison of pass rate, tokens, total cost and bad delegations.

### Inference-server side channels (TRIAL)

Public code shows that two models can exchange information through shared vLLM batching timing and prefix-cache hits even when tools and processes are isolated. A side channel leaks through indirect behavior such as latency or cache state rather than an allowed interface. The result uses fine-tuned cooperating models and controlled scaffolds; it does not show real-world exploitation.

### Humanity's First Exam (TRIAL)

HFE asks whether all four small variants in a prompt family are answered correctly. The family-level all-correct rate is stricter than average item accuracy because one failed variant loses the family. The public sample supports regression testing, but its targeted selection does not estimate ordinary production reliability.

## Open Source

### Songe (TRIAL)

Songe records coding-agent corrections and tool outcomes locally, trains adapters while the machine is idle, and compares versions before activation. It also creates a sensitive local behavior store. Test regressions, disk retention, deletion and rollback under an isolated account instead of equating local operation with privacy.

## Research

### TML Variable-Loop Model (TRIAL)

One open checkpoint can run its shared layers one to five times, directly testing whether more inference compute buys task quality. Training favored three passes, so differences at one or five passes also reflect the training distribution and do not prove that more loops generally help.

### PenGPT (IGNORE)

Code and checkpoints are public, but training data is withheld and the gallery shows only the best third of outputs. Community interest is high while engineering evidence is weak. This run explicitly recommends no investment outside pen-trajectory research.

### GPT-6 Protein Design (WATCH)

Binding means a candidate attaches to a target. It does not establish selective binding, stability in the body or therapeutic effect. OpenAI also says Boltz-2, OpenDDE, ESMFold2 and other specialist models filtered candidates, while complete-structure prediction remains well behind specialist systems. With no public design model, code or API, the next useful signal is independent wet-lab reproduction.

OmniAct, AIChipBench, Draft Calibration and EmbodiSafety were reviewed. Without implementation or independent evidence strong enough to justify investment, they remain WATCH leads or deferred rather than being forced into the highlights.
