## Agent & AI Engineering

### Concordat moves protocol constraints into runtime

A typestate protocol expresses legal actions as a finite-state machine. The hard part is keeping recovery, human confirmation and tool side effects in the same state. The public experiment covers only airline tasks.

### Coding-agent runtimes tighten boundaries

Qwen Code 0.26.4 adds autofix round budgets, independent worktrees and snapshot-bound verification. Copilot cloud sessions connect cross-surface recovery, enterprise permissions and MCP allowlists to GitHub-managed sandboxes.

## Open Source

### AnySpeechRecognizer and AnyDecisionModel

The Swift packages provide common interfaces for Apple on-device speech and constrained decisions. A constrained decision chooses among supplied options rather than freely generating text; backend, token and dependency constraints must align. The current Core AI dependency conflict is a documented integration blocker.

### Granite Switch 4.1.1

IBM updates adapters without changing the base model and expands ASR to ten languages. Decision gains are vendor-run and the promised Adapter SDK is still unavailable.
