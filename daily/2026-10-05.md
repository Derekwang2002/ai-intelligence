# AI Intelligence - 2026-10-05

## Daily Executive Summary

本次新增 5 条事件，更新 5 条既有事件。最值得行动的是 ThinkingBox：它不再相信 agent 的文字汇报，而是检查数据库终态和副作用。Google 的 DiarizationLM 与 Strata 都有公开材料，可做一天内验证。OpenAI Agents Vault 因公开 API 文档从 WATCH 调整为 TRIAL。Ataraxos 与 Figma hosted MCP 证据已补齐，但当前仍应 WATCH。

## Models

### DiarizationLM（TRIAL）

Google 开源 4B 说话人标签修正模型，并提供本地 GGUF。作者报告四个语料库上的 WDER 与 cpWER 都有改善，但多人会议样本较小。说话人漂移指长独白后模型把同一个人错接到另一个标签上；难点是文字可能完全正确，错的是“谁说的”。

### Claude Sonnet 5.5（TRIAL，复核）

Artificial Analysis 的结果显示，maximum effort 在其任务上约输出 19.3 万 token、成本约 7.60 美元，比 Sonnet 5 高约 50%。厂商的“单任务最多省 30%”不能当作普遍折扣，应按 effort 和自有轨迹重算。

## Agent & AI Engineering

### ThinkingBox（TRIAL）

ThinkingBox 将 507 个有状态业务工作流接入 OpenEnv，每个模型重复 20 次。数据库终态核验就是直接检查任务完成后的记录和副作用；难点在于 agent 即使正常退出、最后一个工具也没报错，仍可能写错字段或多做一步。

### OpenAI Agents Vault（TRIAL，评级调整）

公开文档确认，沙箱只看到占位符，网络代理仅向允许的 host 注入 secret。原先“等待 API 文档”的门槛已满足，建议一天内验证不可见性、白名单、轮换、撤销与日志脱敏。

### Figma hosted MCP（WATCH）

Figma 明确只有 MCP Catalog 内客户端才能连 hosted server。开放协议并不自动带来托管服务访问权；未列入目录的客户端要走受支持的 desktop 路径或加入 waitlist。

## Open Source

### Strata（TRIAL）

Strata 把 Qwen3.8-Flash-Next experts 分布到 GPU、内存、CPU 与 SSD，在 12 GB 游戏显卡起步的主机上提供兼容 OpenAI/Anthropic 的本地 API。采用增长很快，但速度与低比特量化质量仍是作者数据。

## Research

### Ataraxos（WATCH）

Ataraxos 用动态阻尼自博弈与决策时搜索处理 Stratego 的大规模隐藏信息。论文和 MIT 代码已公开，但没有 checkpoint；复现 headline 结果不是一天内任务，因此等 checkpoint 或独立复现后再评估。

## Developer Tools

### Claude Code 2.1.289（ADOPT，更新）

版本修复嵌套命令、环境变量前缀、裸变量赋值和 IDE 符号链接读取绕过策略的问题，并加入 teammate agent 生命周期 API。升级前应回归这些精确边界。

## Infrastructure

### LiteLLM 1.104（TRIAL，更新）

稳定版为 Docker image 签名，拒绝弱 master key，检测泄露密码，并修复停用用户、MCP worker 路由和 spend batch 重放。策略继承的难点是父级护栏不能因子条件未命中而消失；应在预生产环境专门测这一类边界。

### Ollama 0.35.1（TRIAL，更新）

版本保留 Modelfile CAPABILITY 声明，让客户端识别 decision-only 模型，不再误提供 chat、tools 或 thinking。
