## Agent & AI Engineering

### WebHarbor

WebHarbor packages 153 common websites as local, resettable Docker mirrors with 3,518 GUI-agent tasks, train/held-out splits and a WebHarbor-4B checkpoint. A website mirror must reproduce pages, databases and post-login workflows; the hard part is keeping carts, accounts, graders and reset state consistent, not copying screenshots. Author-reported cross-benchmark results still need independent reproduction, and mirror licensing plus egress isolation need separate review.

### Qwen Code 0.26.6

Managed recovery keeps a state unknown when child-ledger evidence is missing instead of inventing a complete history. MCP name collisions, OAuth lock ownership and hidden control characters in approval text are also fixed. The unified loop and managed deployment remain experimental, so the project stays TRIAL.

## Research

### MCP Tool Poisoning

The paper runs 9,720 live tool-execution cells across 12 frameworks, 18 models and 45 attack scenarios. Authors report 22.9% attack success, with 255 cells confirmed by canary receipts to exfiltrate secrets. Tool poisoning hides instructions in descriptions, schemas or responses; the hard part is that configuration-looking text enters model context and can steer later tool calls. This run did not locate the claimed public code repository or independent reproduction, so the reported rate is not treated as a universal deployment risk.

## Developer Tools

### Claude Code 2.1.317

Agent SDK hooks gain fail-closed behavior. Web or shell tools ask before sending the account email address, and cloud schedules warn about unrequested connectors. The gateway can report cost by developer, date and IdP group. Recovery fixes cover full disks, runner restarts, MCP state, compaction and proxy failures.

## Infrastructure

### SGLang 0.5.23

The stable release adds TPU7x, Paged Experts, quantized-MoE LoRA and file-backed L3 prefix caching. Paged Experts keeps currently needed experts on GPU and swaps others on demand; swap cost, hit rate and real concurrency determine whether it beats CPU offload. The project reports 30–58% lower first-token latency for several MoE models, but correctness, throughput and memory need reproduction on fixed traces.

### NVIDIA Attribution / Recovery

Attribution turns workload-scoped logs, metrics and scheduler state into a reproducible diagnosis; Recovery then decides whether to isolate nodes, restart or stop. Monitor mode only recommends actions and records an audit trail. Slurm is supported while Kubernetes remains on the roadmap. NVIDIA reports production scale and mean latency, but false attribution can remove healthy capacity, so test before enabling automated actions.
