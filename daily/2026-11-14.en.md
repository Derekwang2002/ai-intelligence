# AI Intelligence - 2026-11-14

## Daily Executive Summary

1. **Google made Gemini 4 Hydrogen available through its public API.** `gemini-4-hydrogen` has a 1M-token context window and a free tier; paid input and output cost $1.50 and $7.50 per million tokens. Performance claims remain Google-reported, so real coding quality, long-context cost and rate limits need local comparison.
2. **llama.cpp 1.0 establishes a stable API and ABI contract.** The major release also adds FP8 KV cache, MoE cache improvements, OpenAI-compatible TTS, and SSRF, CORS and DNS-rebinding hardening. The contract lowers long-term integration risk, but the upgrade removes old APIs and needs regression testing.
3. **OpenAI started a narrow ChatGPT Wallet rollout.** The first wave targets eligible US ChatGPT Pro users, and every purchase still requires the user to review the items, total and card and complete a security check. It reaches a real payment boundary, but it is neither autonomous spending nor broadly available.
4. **IBM published the LLMON toolkit and Granite preview weights.** LLMON uses reserved markup to separate instructions from untrusted data, and IBM reports better resistance to static prompt injection. Code and weights are reproducible, but adaptive multi-turn attacks remain unproven.
5. **XYBench published 8,115 “real goal” test cases.** It checks whether a model follows a mistaken method or recovers the user’s underlying objective. The data and code are public; English-heavy, procedural and single-turn coverage limits production generalization.

## Models

### Gemini 4 Hydrogen

The model is callable in AI Studio and the Gemini API, not merely previewed. A 1M-token context can hold large inputs, but it does not mean every part is used equally well; quality, latency and cost change with task length.

## Agent & AI Engineering

### ChatGPT Wallet

Payment tokens keep actual card numbers away from merchants, but solve only part of credential risk. Every transaction still needs user approval, so the current boundary is “agent prepares, user authorizes,” not autonomous spending.

### LLMON and CapLite

LLMON gives instructions and data an explicit structure; CapLite keeps final authority in deterministic code. Both reduce reliance on a model to interpret content and decide authority, but LLMON is preview-grade and no public CapLite implementation was verified.

## Open Source

llama.cpp 1.0, LLMON and Edge0-145B provide public artifacts. Edge0 reports that its 145B model needs only 29GB peak memory and exceeds 80 tokens/s on a compatible laptop; these unusually strong figures lack independent reproduction. Recall audit also found smolmaxxing and LibreAGI: the former lacks a stable release and controlled benchmarks, while the latter has unclear redistribution, operator and security boundaries. Both are explicitly IGNORE. llama.cpp’s semantic-version contract is closer to production dependency management. LLMON is suitable for isolated attack replay, not a security guarantee based on publisher tests alone.

## Research

### XYBench

Separating method from goal means a user may request a patch to a flawed approach while actually trying to complete a higher-level task. The hard part is deciding when to clarify or correct the premise instead of executing the literal instruction.

### CapLite

The authors report zero successful attacks across 15 open-weight models and 13,935 attacked episodes. This is an author-run result without public code or independent reproduction, so the disposition is WATCH.

## Developer Tools

- **Claude Code 2.1.323:** Adds experimental Code Mode, plugin engine ranges and strict TypeScript hook validation, while fixing fail-closed, Bash permission and symlinked-settings paths. Upgrade the stable release; regress Code Mode separately.
- **Codex 0.168.0 / 0.169.0:** Expands side conversations into persistent multi-tab side chats and adds task search, custom providers, SSH device-code sign-in and diagnostic ZIP export.
- **Qwen Code 0.27.3:** Brings the shared agent loop, ACP background runs, PR binding and durable `/loop` wakeups to stable; 0.x compatibility and recovery semantics still need testing.

## Infrastructure

llama.cpp 1.0 turns recurring interface uncertainty into an explicit major-version boundary. Server defaults still need acceptance tests, especially private URL access, CORS, DNS rebinding and the new TTS endpoint.

## Business & Policy

ChatGPT Wallet is a narrow US rolling launch, not global GA, and it does not support delegated spending. This run found no major general-news event that warranted an editorial exception.

Brave Search API also added x402 per-request payments: agents can settle in USDC on Base without an account or API key. This narrows authorization to one request while introducing wallet, stablecoin, accounting and chain-availability risks.

## Trend Signals

llama.cpp 1.0 adds compatibility and security evidence to the enterprise self-hosted execution-plane trend. LLMON, CapLite and ChatGPT Wallet add evidence from different angles to the separation of model proposals from controlled consequences. They strengthen existing evidence without creating a new trend or changing confidence.
