# AI Intelligence - 2026-10-14

## Daily Executive Summary

- **一批 GPT-4 API snapshot 已有停用期限**：OpenAI 将在 2027 年 1 月 14 日移除指定 GPT-4o、GPT-4o mini 与 GPT-4.1 snapshot 及其微调版本，并建议迁移到 gpt-6-luna。旧 snapshot 目前仍可调用；现在需要盘点精确 model ID，而不是把它误写成已经下线。
- **NVIDIA 开源完整 Run:ai 平台**：Apache-2.0 仓库覆盖控制面、调度、GPU 切分、CLI 与 MCP server。共享 GPU 集群可以验证整套栈，但社区版没有企业支持，NGC 发行版也另受 NVIDIA 条款约束。
- **LFM2.5-24B-A2B 给本地 agent 增加新选项**：Liquid AI 公开 24B 总参数、每 token 激活约 2B 的 MoE 权重，并首日接入多种运行时。性能数字来自厂商；年收入达到 1000 万美元的主体还需另行许可。
- **Claude Code 2.1.299 修补多条执行边界**：稳定版修复沙箱写入插件目录、恢复后重复执行、策略检查前启动 MCP 与第三方 gateway key 泄漏。使用 managed policy 或自定义 gateway 的团队应优先升级并回归这些路径。
- **Third Moment 披露万级长时 agent 系统**：OpenAI 客户案例称其最多并发 1 万个 agent、单次持续 36 至 48 小时，并由外层模型监督卡住的任务。这是罕见的架构信号，但没有原始遥测或独立验证，不能直接外推成本与成功率。

## Models

- **GPT-4 API snapshot 停用计划**（新 / ADOPT）：受影响 snapshot 现在仍能调用，停用日是 2027 年 1 月 14 日。官方页面只给通知日期，没有可靠的小时级公告时间；应按页面列出的精确 model ID 和微调资产迁移。[官方文档](https://developers.openai.com/api/docs/deprecations)
- **LFM2.5-24B-A2B**（新 / TRIAL）：24B MoE 每个 token 只激活约 2B 参数，并公开 base 与 post-trained 权重。MoE 是让每次推理只调用部分“专家”网络；难点是参数不全激活仍不等于低内存，许可、路由开销和真实工具成功率都要实测。[发布说明](https://huggingface.co/blog/LiquidAI/lfm25-24b-a2b) · [模型卡](https://huggingface.co/LiquidAI/LFM2.5-24B-A2B)
- **Gemini 4 Argon**（更新 / TRIAL）：从受控预览进入付费 API。统一 token 预算指输入与输出共同占用 1M 上限，而不是各有 1M；难点是长任务既可能消耗更多输出，也可能因续跑、失败恢复和人工审查增加总成本。[官方说明](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon)
- **Grok 4.7**（新 / TRIAL，late discovery）：公开 API 支持文本、图片、工具调用和 500K 上下文。prompt 超过 200K token 后输入与输出单价翻倍，美国区域 endpoint 另加 10%。[公告](https://x.ai/news/grok-4-7) · [文档](https://docs.x.ai/developers/models/grok-4-7)
- **MiniCPM-V 4.7**（新 / TRIAL，late discovery）：35B-A3B 与 1B 权重采用 Apache-2.0。专家预取只提前加载下一层可能用到的专家，不改变实际路由；难点是它缓解内存等待，却不会消除存储、带宽、温度和耗电成本。[模型卡](https://huggingface.co/openbmb/MiniCPM-V-4.7-35B-A3B)
- **GLM-Legal**（新 / WATCH）：基于 GLM-5.3-Flash 的法律模型开放申请制 beta。Harvey LAB 的 all-pass rate 为 19.2%，部分评测由 Vals 执行；没有公开权重或普遍可用 API，AutoClaw 支持也尚未推出。[官方说明](https://z.ai/blog/glm-legal)

## Agent & AI Engineering

- **Third Moment Agent System**（新 / WATCH）：客户称系统可运行 1 万个并发 agent、持续 36 至 48 小时。外层监督会终止、重试或升级卡住的 worker；难点是并发数不等于有效任务吞吐，缺少成功率、成本和恢复遥测。[客户案例](https://openai.com/index/third-moment-research/)
- **Claude Code 2.1.299**（更新 / ADOPT）：新增闲置压缩与 runner drain，并修复沙箱、恢复执行、MCP 策略和 gateway 凭据边界。[稳定版](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)
- **Gemini CLI 0.64.0**（更新 / WATCH）：原子文件操作、状态备份恢复、Ctrl+C 取消、ACP usage 更新和 A2A 设置迁移进入稳定版；A2A 仍缺正式兼容承诺。[稳定版](https://github.com/google-gemini/gemini-cli/releases/tag/v0.64.0)
- **ColGrep-Agent**（新 / TRIAL）：本地搜索模型先定位相关代码，再把更小的上下文交给 coding agent。文件定位 F1 只说明找对文件的程度；难点是它不直接回答最终补丁能否通过测试，因此试验必须测端到端成功率。[发布说明](https://huggingface.co/blog/lightonai/colgrep-agent) · [代码](https://github.com/lightonai/next-plaid)

## Open Source

Run:ai 的完整 GPU 编排栈已开源；LFM2.5、DoubtLess 与 Hybrid Agent 也提供可下载权重或代码。GitHub secret scanning 现已 GA 支持 Anthropic service/user API key，并默认用 push protection 拦截；这只是预防控制，不代表发生了泄露。[GitHub 公告](https://github.blog/changelog/2026-10-13-secret-scanning-blocks-anthropic-keys-by-default-adds-salesforce/)

ColGrep-Agent 与 StudentSim 都公开了可运行 artifact。本轮没有发现达到入库门槛的新增稳定版通用 agent runtime；Gemini CLI、Qwen Code、Codex 和 Ollama 的窗口内候选均为 nightly、alpha 或 release candidate。

召回自检另外登记 4 个高热度但证据不足的 IGNORE：Janas 只有作者性能对比；JEV-35B 的公开分数由作者自测且不是榜单正式记录；Agent37 只有发布讨论；EmbeddingGemma 2 语音转写 demo 没有公开训练代码与测试集。热度被记录，但不转化成试用建议。

## Research

- **DoubtLess**（新 / TRIAL）：小模型分别按“简短”和“详细”要求读取同一段思维链，再用两次输出的 logit 差引导大模型。作者报告推理 token 减少，但结果尚无独立复现，参考配置需要 80 GB GPU。[论文](https://arxiv.org/abs/2610.14745) · [代码](https://github.com/zhangshaowei1023/DoubtLess)
- **Hybrid Agent**（新 / TRIAL）：HybridLink 在隐藏的潜在推理和显式工具交互间切换，并跨边界保留状态。公开 8B、14B 权重与代码足以试验，但作者的 11 项 benchmark 结果仍需独立复现。[论文](https://arxiv.org/abs/2610.14744) · [代码](https://github.com/togethercomputer/HybridAgent)
- **StudentSim**（新 / TRIAL）：论文覆盖棋类、第二语言学习和数学，共 60 名学习者。held-out 评测是在训练时没给模拟器看的互动上测试；难点是对未见记录的拟合更好，仍不等于真实学生学得更好。[研究文章](https://www.microsoft.com/en-us/research/blog/studentsim-a-framework-for-evaluating-ai-tutors-with-personalized-student-simulations/) · [代码](https://github.com/microsoft/StudentSim) · [论文](https://arxiv.org/abs/2609.01591)
- **加密能力后门**（新 / WATCH，late discovery）：论文构造 digital locker，把隐藏计算加密进权重，只在秘密触发器下解锁。它证明能力引出式审计存在最坏情况盲区，但实验只在小型化学反应代理任务上进行。[论文](https://arxiv.org/abs/2610.13928)

## Developer Tools

GitHub push protection 对 Anthropic key 的默认拦截已经 GA，属于低成本的 ADOPT 项。Claude Code 与 Gemini CLI 的稳定版则分别处理执行边界和状态完整性；升级时应使用真实中断、恢复和策略失败用例回归。

本轮最实用的新工具信号是 ColGrep-Agent。它可以在本地只读搜索仓库，并提供 Codex、Claude Code 和 OpenCode 接线方式；模型名写 2B，而模型卡显示约 3B 参数，部署前应按实际包体和显存验证。
