# AI Intelligence - 2026-10-14

## Daily Executive Summary

- **Gemini 4 Argon 进入可调用阶段**：Google 已向 AI Studio 和 Gemini API 付费层开放 Argon。输入与输出共用 1M token 预算；每百万输入 2 美元、输出 10 美元的介绍价将在 11 月 30 日后翻倍。现在可以实测长时程任务，但厂商 benchmark 仍不能替代独立对照。
- **MiniCPM-V 4.7 把 35B MoE 带到手机端**：OpenBMB 公开 Apache-2.0 权重和端侧部署路径，并称 iPhone 17 Pro Max 只用 3 GB 内存可超过 13 token/s。速度、视觉质量、温度和耗电仍要在真实设备上验证。
- **能力审计存在可证明的最坏情况盲区**：NeurIPS 论文把任意隐藏计算加密进模型权重，并让它只在秘密触发器下执行。实验是小型人为构造，不代表现有模型已受影响，但提醒权重来源审查与运行时监控不能被一次能力测试替代。
- **ColGrep-Agent 把代码搜索拆成本地专门模型**：LightOn 公开权重、代码和 Codex 等集成。作者实验显示 token 用量下降，但还没有独立证据证明补丁成功率、总延迟或算力更好。
- **Maia 300 仍是 2027 年路线图**：Microsoft 公布 96 卡、167 kW 的推理机架，并称每兆瓦 token 产出比主流 GPU 系统高 40%。生产部署计划 2027 年开始，当前没有生产遥测或独立 benchmark。

## Models

- **Gemini 4 Argon**（更新 / TRIAL）：从受控预览进入付费 API。统一 token 预算指输入与输出共同占用 1M 上限，而不是各有 1M；难点是长任务既可能消耗更多输出，也可能因续跑、失败恢复和人工审查增加总成本。[官方说明](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon)
- **Grok 4.7**（新 / TRIAL，late discovery）：公开 API 支持文本、图片、工具调用和 500K 上下文。prompt 超过 200K token 后输入与输出单价翻倍，美国区域 endpoint 另加 10%。[公告](https://x.ai/news/grok-4-7) · [文档](https://docs.x.ai/developers/models/grok-4-7)
- **MiniCPM-V 4.7**（新 / TRIAL，late discovery）：35B-A3B 与 1B 权重采用 Apache-2.0。专家预取只提前加载下一层可能用到的专家，不改变实际路由；难点是它缓解内存等待，却不会消除存储、带宽、温度和耗电成本。[模型卡](https://huggingface.co/openbmb/MiniCPM-V-4.7-35B-A3B)
- **GLM-Legal**（新 / WATCH）：基于 GLM-5.3-Flash 的法律模型开放申请制 beta。Harvey LAB 的 all-pass rate 为 19.2%，部分评测由 Vals 执行；没有公开权重或普遍可用 API，AutoClaw 支持也尚未推出。[官方说明](https://z.ai/blog/glm-legal)

## Agent & AI Engineering

- **ColGrep-Agent**（新 / TRIAL）：本地搜索模型先定位相关代码，再把更小的上下文交给 coding agent。文件定位 F1 只说明找对文件的程度；难点是它不直接回答最终补丁能否通过测试，因此试验必须测端到端成功率。[发布说明](https://huggingface.co/blog/lightonai/colgrep-agent) · [代码](https://github.com/lightonai/next-plaid)

## Open Source

ColGrep-Agent 与 StudentSim 都公开了可运行 artifact。本轮没有发现达到入库门槛的新增稳定版通用 agent runtime；Gemini CLI、Qwen Code、Codex 和 Ollama 的窗口内候选均为 nightly、alpha 或 release candidate。

召回自检另外登记 4 个高热度但证据不足的 IGNORE：Janas 只有作者性能对比；JEV-35B 的公开分数由作者自测且不是榜单正式记录；Agent37 只有发布讨论；EmbeddingGemma 2 语音转写 demo 没有公开训练代码与测试集。热度被记录，但不转化成试用建议。

## Research

- **StudentSim**（新 / TRIAL）：论文覆盖棋类、第二语言学习和数学，共 60 名学习者。held-out 评测是在训练时没给模拟器看的互动上测试；难点是对未见记录的拟合更好，仍不等于真实学生学得更好。[研究文章](https://www.microsoft.com/en-us/research/blog/studentsim-a-framework-for-evaluating-ai-tutors-with-personalized-student-simulations/) · [代码](https://github.com/microsoft/StudentSim) · [论文](https://arxiv.org/abs/2609.01591)
- **加密能力后门**（新 / WATCH，late discovery）：论文构造 digital locker，把隐藏计算加密进权重，只在秘密触发器下解锁。它证明能力引出式审计存在最坏情况盲区，但实验只在小型化学反应代理任务上进行。[论文](https://arxiv.org/abs/2610.13928)

## Tech Radar

- **Gemini 4 Argon**（foundation-model / TRIAL）：公开 API 已可用，建议在价格翻倍前后用同一组长任务核对成功率、漂移、审查成本和失败恢复。
- **新 · Grok 4.7**（foundation-model / TRIAL）：公开 API 与价格可直接对照，但厂商 benchmark 和安全结论仍需独立验证。
- **新 · ColGrep-Agent**（developer-tools / TRIAL）：公开权重和集成足以做一天试验；要同时测补丁成功率、token、延迟和总算力。
- **新 · StudentSim**（research / TRIAL）：公开棋类路径可复跑；模拟器结果不能替代真实学生与教师试验。
- **新 · Maia 300**（infrastructure / WATCH）：路线图影响推理基础设施判断，但 2027 年生产部署前缺少可采购性和真实负载证据。
- **新 · MiniCPM-V 4.7**（foundation-model / TRIAL）：开放权重和部署代码足以在目标手机上比较质量、持续速度、内存、温度与耗电。
- **新 · 加密能力后门**（agent-security / WATCH）：最坏情况构造改变审计边界，但要等更大模型上的独立复现。
- **新 · GLM-Legal**（foundation-model / WATCH）：申请制 beta 与部分独立评测构成信号；普遍 API、权重和错误复测仍缺席。
- **新 · Janas**（open-source / IGNORE）：社区热度高，但缺少独立同硬件质量和稳定性对比。
- **新 · JEV-35B**（foundation-model / IGNORE）：开放权重可验证，公开分数却是作者自测且不是正式榜单结果。
- **新 · Agent37**（developer-tools / IGNORE）：只有创始人发布帖，隔离、可靠性与采用证据不足。
- **新 · EmbeddingGemma 2 STT**（open-source / IGNORE）：demo 思路新颖，但没有可复现训练材料或独立词错率对比。
