# AI Intelligence - 2026-10-27

## Daily Executive Summary

- **NVIDIA 把 AI factory 自动恢复扩展到 Kubernetes。** Mission Control 2.5 已向现有客户开放；Minerva 仍是定向限量 beta。[发布说明](https://developer.nvidia.com/blog/how-nvidia-mission-control-2-5-brings-autonomous-recovery-to-kubernetes/)
- **Cline 同步补强改动可见性与失败恢复。** Desktop 0.0.49 和 extension 4.1.26 让用户更容易核对改动，并限制重试、断线和反复压缩造成的重复工作。[Release](https://github.com/cline/cline/releases/tag/desktop-v0.0.49)
- **AI21 开放 LIFT-Bench。** 公开数据与代码让团队可以复测长文局部指令遵循，但结果依赖固定的 Gemma judge，不能外推成通用能力提升。[项目](https://github.com/AI21Labs/lift-bench)
- **GitHub Agentic Workflows 开始追踪跨步骤 secret 流。** 0.93.5 是稳定版；同日 1.0.0 明确为 prerelease，不按 GA 处理。[Release](https://github.com/github/gh-aw/releases/tag/v0.93.5)
- **Anthropic 公开提交 IPO 注册文件，但尚未完成上市。** SEC 已接受 S-1，发行数量与价格未定，注册文件尚未生效。[SEC 文件](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/0001628280-26-067168-index.htm)

## Models

- 本轮未发现达到门槛的新模型。Gemini CLI 与 Qwen Code 的 nightly 和 prerelease 不作为稳定版本入库。

## Agent & AI Engineering

- **Mission Control 2.5（新 / TRIAL，late discovery）**：闭环恢复会让作业先在健康节点继续跑，硬件诊断并行进行，而不是串行等待全部修复。
- **GitHub Agentic Workflows 0.93.5（新 / TRIAL）**：静态分析会沿 step output 追踪凭据传递，并把网络凭据限制在受控 safe-output job；项目仍未到稳定 1.0。

## Open Source

- **InteractiveWorld（新 / WATCH，late discovery）**：Meta 公开有状态 3D 模拟器和 120 个多轮任务。仓库是 CC BY-NC，约 100 GB 资产与额外依赖许可使复现成本偏高。
- **PaperPilot（新 / IGNORE，late discovery）**：社区热度上升，但 v0.6.0 仍是 prerelease，README 的 benchmark 表还是占位内容。等稳定版和可复现实测出现后再投入。
- Qwen Code TypeScript SDK 0.1.23 只重新打包已入库的 CLI 0.26.1，没有独立的新能力。

## Research

- **LIFT-Bench（新 / TRIAL，late discovery）**：局部约束是只要求长文的指定段落遵守某条规则；难点是 judge 必须识别规则作用范围，不能拿全文统一判分。公开集含 784 个测试任务和 34,258 个训练任务。
- **InteractiveWorld（新 / WATCH，late discovery）**：世界状态验证会检查模拟器里的对象是否真的变化，而不是接受 agent 的文字自述；评分仍需要人工裁定。

## Developer Tools

- **Cline 4.1.26 / Desktop 0.0.49（新 / TRIAL）**：增加 changed-files、项目树、查看器和终端，并修复 reasoning 后断线、Gemini API key 丢工具、未知上下文反复压缩等故障路径。

## Infrastructure

- **NVIDIA Minerva（late discovery）**：动态知识图谱把硬件、链路、调度器和作业连成实时关系图；难点是将跨层告警合并成一个可行动根因。厂商报告的改善尚无独立验证，Minerva 也没有承诺 GA 日期。
