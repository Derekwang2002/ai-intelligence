- **GPT-6.1 Terra 已以更低价格开放 computer use。** API、ChatGPT Work 与 Codex 已 GA；标准 input / output 价格为每百万 token 1 / 5 美元，但性能结论仍由 OpenAI 自报。[公告](https://openai.com/index/introducing-gpt-6-1-terra)
- **百度公开 Unlimited-OCR-2 权重。** MIT 许可、代码与推理路径已可用；它尝试用固定工作引用处理超长文档，但 benchmark 领先仍是厂商自报。[模型卡](https://huggingface.co/baidu/Unlimited-OCR-2)
- **Qwen Code 0.26.2 同时收紧权限和恢复链路。** 新版加入 managed session 权限规则、token 注入防护、snapshot 与 HTTP 恢复，值得用故障注入重新验收。[Release](https://github.com/QwenLM/qwen-code/releases/tag/v0.26.2)
- **Anthropic 已公开提交 IPO 注册文件，但尚未完成上市。** SEC 已接受 S-1，发行数量与价格未定，注册文件尚未生效。[SEC 文件](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/0001628280-26-067168-index.htm)

## Agent & AI Engineering

- **Qwen Code 0.26.2（更新 / TRIAL）**：managed session 权限规则与自动审批决定“谁能执行什么”；snapshot、HTTP 和 journal 恢复决定崩溃后是否会重复工具副作用。
- **Claude Code 2.1.311（更新 / ADOPT）**：修复压缩后读取旧 memory、重启后重复执行 skill、后台 worktree 提前清理和多条会话恢复问题。
- **RCAtlas Harness（新 / WATCH）**：统一评测报告简单 harness 的 PR@1 为 65–77%，手工编排 RCA agent 为 16–53%。PR@1 指第一个根因判断正确的比例；难点是论文没有公开实现，无法确认真实事故中的日志权限与数据缺口是否相同。
- **Mission Control 2.5（新 / TRIAL，late discovery）**：闭环恢复会让作业先在健康节点继续跑，硬件诊断并行进行，而不是串行等待全部修复。

## Open Source

- **dSpark（新 / WATCH）**：训练与评测代码公开，但 checkpoint、训练数据和许可证尚未补齐；仓库说明训练需要 4 张 A100。
- **InteractiveWorld（新 / WATCH，late discovery）**：Meta 公开有状态 3D 模拟器和 120 个多轮任务。仓库是 CC BY-NC，约 100 GB 资产与额外依赖许可使复现成本偏高。
- **PaperPilot（新 / IGNORE，late discovery）**：社区热度上升，但 v0.6.0 仍是 prerelease，README 的 benchmark 表还是占位内容。

## Research

- **Unlimited-OCR-2（新 / TRIAL，late discovery）**：SR-SWA 只保留固定数量的工作引用，让长文档继续增长时每一步不用回看全部历史。难点是跨页准确率、显存和延迟仍需在真实扫描件上验证。


- **OpenAI 数学成果（更新 / WATCH，late discovery）**：Lean 能检查形式化命题是否由公理推出，但不能自动证明形式化命题完整表达了研究者想说的结论；独立学界验收仍是关键限制。
- **DecisionRAG（新 / WATCH）**：用一次前向计算共同判断文档树的候选分支，不先做 dense retrieval。作者报告 0.7–1.8 秒检索，但没有公开实现或独立复现。
- **REVA（新 / WATCH）**：把 threat model、静态分析与调用图送进模型，再用 probe 读取内部表示。作者报告约一秒筛查一个函数，但 60.0% 准确率不足以自动阻断。
- **dSpark（新 / WATCH）**：schedule distillation 学的是“先揭示哪个 token 最能帮助其他位置”，而不是“哪个 token 当前最确定”。作者报告明显减少前向计算次数，公开产物仍不完整。
- **LIFT-Bench（新 / TRIAL，late discovery）**：局部约束只要求长文指定段落遵守规则；固定 Gemma judge 限制结果外推。

## Infrastructure

- **NVIDIA Minerva（late discovery）**：动态知识图谱把硬件、链路、调度器和作业连成实时关系图；厂商效果数据尚无独立验证，Minerva 也没有承诺 GA 日期。
- NVIDIA 的 DGX Spark MoE 调优文章提供工程方法，但没有形成可迁移的新产品或独立性能证据，本轮未单独入库。

- **KV cache 租户泄露（新 / ADOPT）**：Cloudflare 确认 155 条 GLM-5.3 响应读到其他客户的 cache page。KV cache 是模型为避免重复计算而保留的中间状态；难点是分离式 prefill/decode 跨机器传递时，页面所有权和生命周期必须始终一致。
