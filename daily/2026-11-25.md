# AI Intelligence - 2026-11-25

## Daily Executive Summary

1. **OpenAI 与 Cisco 开源 Shirudo。** 这套 pre-release 运行时可在 Linux 上加载签名 eBPF 与 Java 临时缓解措施，并用 TPM 留下可核验记录。它提供正式补丁上线前的缓冲层，但生产使用需要补丁内核，当前只适合隔离 VM 试验。[来源](https://openai.com/index/introducing-shirudo/)
2. **GPT-6.2 进入 ChatGPT 普通对话。** Plus、Pro、Business 与 Enterprise 正在全球逐步获得 GPT-6.2 Sol 变体；Enterprise 仍受管理员设置控制。系统卡同时披露 Critical 网络能力和一项 steerability 回退，扩大可用范围不等于可以跳过受控测试。[来源](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)
3. **Gemini API 可以只读取文件中需要的部分。** PDF 页码、表格区域、音视频区间和内容层可在服务端切片，只对实际检查的内容计费。合作方节省数字仍是发布方材料，需要用自己的多模态 RAG 任务复测。[来源](https://blog.google/innovation-and-ai/technology/developers-tools/file-slicing-controls/)
4. **Tencent 开放 OmniEVIE-4B。** 这个 Apache-2.0 多模态 retriever 同时处理文本、图像、视觉文档与视频，并能定位命中的页面区域或视频片段。权重和代码已公开，质量与延迟仍缺少独立复现。[来源](https://huggingface.co/tencent/OmniEVIE-4B)
5. **Ai2 发布 RoboTrack。** 公开工件包括真实操作 benchmark、1,500 万条合成轨迹、代码与两个 checkpoint。最强 checkpoint 仅限非商业用途，发布方结果也不能直接证明机器人闭环控制安全。[来源](https://huggingface.co/blog/allenai/robotrack)

## Models

- **InclusionAI 开放 Ling-3.2-air 权重**（foundation-model / TRIAL）：124B 总参数、5.5B 激活的多模态 MoE 提供 MIT 权重、SGLang 与 vLLM 配方，覆盖文档、视频和工具调用。发布方配方至少需要 4 张 141GB 级 GPU 或 8 张 80GB GPU，且 benchmark 尚无独立复现，因此更适合集群内的一天 POC。

### GPT-6.2 Chat 更新（TRIAL）

GPT-6.2 从 Work、Codex 与 API 扩展到普通 ChatGPT 对话。新版系统卡把网络能力评为 Critical、生化能力评为 High，并保守地把 AI 自我改进能力评为 High。OpenAI 的内部 steerability 测试也出现回退，因此团队应同时测任务质量与指令服从，不要只看综合能力分数。

### OmniEVIE-4B（TRIAL）

OmniEVIE 用 late interaction 保存一组局部向量，而不是把整份文档压成一个向量；这样可以指出命中的页面区域或视频时间段。难点是索引会更大，压缩后是否仍保留定位质量需要用自己的语料验证。Tencent 自报百万级 CPU 检索延迟与 MMEB 分数，本轮没有找到独立复现。

## Agent & AI Engineering

### Shirudo（TRIAL）

eBPF 是在 Linux 内核受限执行环境中运行的小程序，可观察或拦截特定系统行为。Shirudo 把这些临时缓解措施做成签名、审批和 TPM 可验证的流程；难点是它本身位于高权限路径，错误 shield 可能破坏正常工作负载。官方仓库明确标为 pre-release，生产目标还需要补丁内核和 TPM 2.0。

### Gemini Tool Retrieval（TRIAL）

Google 在 Gemini Interactions API preview 中允许延后加载工具 schema，并在单次请求中按需取回；远程 MCP server 也支持。该功能 11 月 19 日已公开，本轮从固定入口补录。它不单独收费，但选择准确率、授权和额外检索步骤仍应在真实工具库中验证。

### Gemini 文件切片（TRIAL）

Gemini 4 API 现在可选择文档页码、表格区域、音视频区间、内容层与分辨率。页面元数据为 2026-11-23T16:12:00Z，处于 overlap 且早于上次 checkpoint，因此按漏检事件补录，而不是把页面后续变化当成新发布。

## Research

### RoboTrack（TRIAL）

点追踪是在连续视频帧中持续定位同一个位置，并判断它何时被遮挡、何时重新出现。RoboTrack-Bench 用 307 段真实操作视频和 2,522 条人工核验轨迹检验这件事；难点是长遮挡、小物体和杂乱背景仍会让 tracker 失败。官方只给发布日期，仓库与 Hugging Face 工件时间不完全一致，因此不声称已完成逐小时筛选。

两个到期复核没有找到会改变判断的独立证据：SciResearch-Eval 与 Sage S2.1 Flash 保持原建议，并且没有刷新雷达活跃时间。
