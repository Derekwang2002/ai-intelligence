## Models

### Genie 4 API (TRIAL)

Google opened Genie 4 through the Gemini API Interactions API and AI Studio for paid-tier keys. Output is 720p at 24 fps with stereo audio at about $0.10 per second. A client disconnect does not end the service; complete() or cancel() is required because connection state and billing lifecycle are separate.

Sources: https://blog.google/innovation-and-ai/models-and-research/google-deepmind/genie-4-api/; https://aistudio.google.com/docs/genie

## Agent & AI Engineering

### OpenAI Performance Factory (WATCH)

The system turns regressions into durable tasks, then dispatches Codex cloud sessions and an independent reviewer agent. An adversarial reviewer here is a second session tasked with finding counterexamples and challenging the proposed cause, not a security attack. Humans retain merge authority.

Source: https://openai.com/index/performance-factory/

### Harness adapters (TRIAL)

Hugging Face released adapters for pi, Hermes and OpenCode plus a merged version. Publisher runs show strong in-harness gains, but use one attempt per task, tune the merge with Terminal-Bench and show weak out-of-domain transfer.

Source: https://huggingface.co/blog/harness-adapters

### Watch Duty wildfire-radio transcription (WATCH)

The partners report word error rate falling from 38% to 22.34% on degraded audio and volunteer satisfaction reaching 92.3%. This is not automatic alert publication: the model triages and humans verify critical messages.

Source: https://blog.google/technology/ai/watch-duty-gemini-wildfire-response/
