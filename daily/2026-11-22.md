# AI Intelligence - 2026-11-22

## Daily Executive Summary

- **Inkling 2 Mini 可在开发者硬件上试跑**：Thinking Machines Lab 公开 Apache 2.0 权重，约 20GB checkpoint 可在 32GB Apple silicon 或单 GPU 上运行；100 万 token 上下文与多运行时支持有实用价值，但独立质量和延迟证据仍少。[来源](https://huggingface.co/thinkingmachines/Inkling-2-Mini)
- **模型提取防御从限流走向分层对抗**：OpenAI 自报 GPT-6.2 Astra 的受保护推理提取成功率在内部自适应评测中降至 0.2%。数字来自发布方，尚无公开评测工件或独立复现。[来源](https://openai.com/index/combatting-adversarial-distillation/)
- **MiniMax 把模型辅助密码分析变成可检查产物**：四项结果同时开放论文和代码，覆盖 COLM、McEliece、ARADI 与 SBC-VOLE；在密码学团队复现前，不能把发布方主张当成已确认的攻击突破。[来源](https://github.com/MiniMax-AI/Research)
- **Coding agent 的稳定性继续落在执行边界**：Claude Code 2.1.330 修复长会话、并发 worktree 和调度问题；Qwen Code 0.28.3 增加托管 channels 与持久证据。两者都值得在测试仓库回归，而不是仅看功能清单。
- **Gemini 4 Hydrogen 获得独立但较低的 benchmark 结果**：独立 MKA 测试为 49.52%，低于 Google 自报 53.4%，同时测得约 198.2 tokens/s。单一榜单仍不能替代用户自己的质量、延迟与成本测试。[来源](https://artificialanalysis.ai/models/gemini-4-hydrogen)

## Models

### Inkling 2 Mini — TRIAL

Thinking Machines Lab 发布约 260 亿总参数、每 token 激活约 30 亿参数的多模态 MoE。所谓“循环层”是让同一组中间层重复执行，以减少需要存储的权重；它能省内存，却不等于推理只算一遍。建议在 32GB 机器上测首 token 延迟、内存峰值、长上下文退化与图像任务质量。

### Gemini 4 Hydrogen — TRIAL（更新）

独立 MKA 结果给出了比厂商自报更低的分数，同时确认较高输出速度。这改变了证据结构，但不足以改变 TRIAL：用相同真实任务同时测质量、延迟和总成本。

## Agent & AI Engineering

OpenAI 的“对抗式蒸馏”指攻击者反复查询强模型，再用输出训练或强化自己的模型。难点在于单个请求看起来可能正常，风险往往要跨账户、跨时间聚合才能看见。当前内部结果支持分层防护方向，但不支持独立比较不同厂商的防御强弱。

## Research

### MedChemBench — WATCH

99 道药物化学题来自 117 篇论文和专利，覆盖 761 个分子结构。OpenAI 自报 GPT-6.2 Astra 获得 84.5% 可得分，但这只是发布方 benchmark，不能改写成临床能力或药物发现成功率。

### MiniMax 自动密码分析 — WATCH

密码分析的关键不是模型是否给出一个答案，而是攻击能否由专家按明确复杂度与条件复现。四组公开代码让复核成为可能；本轮尚未核实到独立验证。
