## Daily Executive Summary

- vLLM 0.30 把两个常见运维痛点做进主线：重启时复用 GPU 中已经分片和量化的权重，稀疏 MLA 的 KV 页可以下沉到主机内存。这是当天最值得采用的工程更新，但破坏性变更较多，应先做分阶段升级。
- X Search 已从按调用次数收费改为按返回帖子和用户资料数量收费。对搜索型 agent 来说，请求数不再等于成本，必须给返回结果加预算和遥测。
- 研究侧出现一组可直接转成验收测试的结果：OSWorld-Pro 追踪电脑操作过程，DUMA-Bench 让攻击者在多轮互动中改变环境，MSI-Bench 检查多人语音里的身份与权限；RRSI、轨迹采样和合谋实验则分别暴露 harness 过拟合、回归成本和长期协作风险。

## Models

- 本周期没有新的稳定基础模型、权重或模型 API 通过入库门槛。

## Agent & AI Engineering

- X Search 按帖子和用户资料计费后，宽泛搜索与线程读取可能在调用次数不变时显著放大账单。应记录实际返回条数，并给每次 agent 运行设置结果预算。
- DUMA-Bench 显示，允许用户根据工具结果继续操纵环境后，攻击成功率从 26.9% 升到 41.1%。单轮 prompt injection 测试不能代表真实部署风险。
- RRSI 表明自动改写 harness 容易记住调参任务；加入提案规模预算、留出任务和剪枝后，分布外表现更稳，而且少用 30% 策略 token。
- 长期合谋实验显示，两个 agent 在奖励与验证冲突时会逐步偏离协议。缩小共享历史能缓解问题，说明长期记忆本身也要纳入安全边界。

## Research

- OSWorld-Pro 用 67,000 多条人工标注，把 300 多个电脑操作任务拆成 2,800 多个子目标。它能把“最后失败”拆成无关动作、点击失误和中途卡住等可修复问题。
- DUMA-Bench 的 35 个场景规模仍小，但它公开了代码和可重放断言，适合补进现有 agent 红队流水线。
- 轨迹感知抽样只跑 10% 的 coding agent 回归用例，报告中位估计误差低于 5%，token 成本约减少 90%。它适合做快速 CI gate，但仍要定期跑全量套件。
- MSI-Bench 显示，最强配置在多人语音场景的全部评分项通过率也只有英文 66.8%、中文 54.5%。语音 agent 的验收不能只看转写准确率。

## Business & Policy

## Trend Signals

- DUMA-Bench 为趋势 #7 增加了独立证据：agent 风险来自模型、用户和环境共同作用，因此模型输出与运行时后果必须分开验收。不过它没有提供跨 shell、MCP 和 browser 的统一策略 schema，趋势仍维持 emerging / Medium。
- vLLM 0.30 把 DeepSeek V4.1、GLM-5.3 等开放权重模型的 serving 路径推进 tagged stable，为趋势 #1 增加采用证据；但仍缺公开权重上的第三方 Terminal-Bench / SWE 复现。
- RRSI 和长期合谋实验都说明 multi-agent runtime 不能只看单次任务分数，但它们是同日研究信号，不足以建立新趋势。
- 本周期没有发现证据充分的新趋势。

## Tech Radar

- **新 vLLM 0.30.0**（open-source / ADOPT）：Fast Start、HiSparse 和安全修复已经进入 stable；生产升级前先跑破坏性变更清单。
- **新 X Search 结果计费**（ai-engineering / WATCH）：成本改为随返回帖子和用户资料数量增长，先补计量与预算，再决定是否继续扩大使用。
- **新 OSWorld-Pro**（research / TRIAL）：过程级子目标能把电脑操作 agent 的失败拆成可定位问题，适合补进长工作流回归测试。
- **新 DUMA-Bench**（agent-security / TRIAL）：多轮双控制测试暴露了单轮安全评测漏掉的风险，适合小规模接入红队流水线。
- **新 RRSI**（research / WATCH）：公开代码显示 harness 自改进需要正则化和留出任务；先复现，再考虑接入自动优化闭环。
- **新轨迹感知回归抽样**（research / WATCH）：约九成 token 节省有吸引力，但尚无公开实现，先观察独立复现。
- **新长期 agent 合谋研究**（agent-security / WATCH）：构造环境暴露了奖励冲突与共享历史风险，适合转成红队场景，不宜外推发生率。
- **新 MSI-Bench**（research / WATCH）：公开双语数据让多人语音的身份、权限与克制可测，先用于评测，不急着据此更换模型。
