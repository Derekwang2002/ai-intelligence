# AI Intelligence - 2026-11-26

## Daily Executive Summary

1. **Humanity's First Exam 把“偶尔答对”与“稳定答对”分开。** Google DeepMind 用 544 道基础文本与图像题检查同一问题的轻微改写是否改变答案。Kaggle 公开样本可直接试验，但完整保留集不公开，题目也刻意选自模型容易失败的区域，不能把分数写成日常故障率。[来源](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/humanitys-first-exam/)
2. **Delegent 让强模型只把边界清楚的子任务交给本地小模型。** Apache-2.0 代码、测试与复现说明已经公开；作者自报在两个任务集上减少 59%–67% 的前沿模型成本，没有减少完成量。结果尚无独立复现，仓库采用信号也很弱。[来源](https://github.com/castorini/delegent)
3. **WePocketModel 现在可以在 Apple silicon 上用 MLX 运行。** 2B 与 4B 版本用同一套权重处理图文生成、嵌入和结构化决策；发布方称 4-bit 4B 在 M3 Pro 上峰值占用 4.25 GiB。权重与 runtime 采用 Apache-2.0，但质量和速度仍是发布方结果。[来源](https://huggingface.co/tencent/WePocketModel1.0-4B-MLX)
4. **ERNIE 5.5 Flash Preview 的开放权重已可核验下载。** 百度提供混合 FP4/FP8、FP8 与 BF16 checkpoint，并给出 vLLM、SGLang 部署配方。它仍是未完成的中间检查点，20 项 benchmark 都是厂商自测；这次是关闭上轮证据读取延期，不是 11 月 25 日新发布。[来源](https://huggingface.co/baidu/ERNIE-5.5-Flash-Preview)
5. **OpenAI 报告 GPT-6 的蛋白质设计出现湿实验结合证据。** GPT-6.2 相关设计在五个靶点上出现结合，重设计抗体也保留结合能力。候选筛选仍依赖专用生物模型，最强系统未公开；结合成功也不等于特异性、稳定性、安全性或治疗效果成立。[来源](https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities/)

## Models

### WePocketModel MLX（TRIAL）

WePocketModel 把生成、图文嵌入和结构化决策放进同一个多模态骨干。这里的 Matryoshka Representation Learning（MRL）是把同一个嵌入向量的前 64、128、256 到 2,048 维分别拿来用；难点是缩短向量后能省索引空间，但召回是否保持必须用自己的数据测。2B 与 4B MLX 权重、runtime 和 4/8-bit 量化路径均已公开。

### Kolibri 1.1（TRIAL）

Kolibri 1.1 专攻德语与英语，开放 75B MoE 权重、工具调用和长上下文路径。稀疏激活只减少每个 token 的计算，完整权重仍需约 77.6GB 内存；厂商给出的质量和成本需要在实际德英 RAG 上复测。

### LingSante-3.1-air-VL（WATCH）

该 124B/5.5B-active 模型把医疗图像、报告、证据检索和 GUI 操作放进一套开放权重。模型卡明确禁止独立诊断、开药、分诊和治疗决策；模拟任务与厂商 benchmark 不能替代临床验证。

### MemT-1.0-Pro（WATCH）

MemT 把跨轮历史压进固定大小的潜在状态，并公开保存和恢复接口。潜在记忆不是可直接检索的原文，而是模型内部更新后的数值状态；难点是节省存储后，细节是否可追溯、遗忘和污染是否可控。Pro 版总参数 554B、需自定义代码，且文本检索型记忆总体仍更强，因此先观察小型号复现。

### ERNIE 5.5 Flash Preview（TRIAL）

上轮只能看到 Hugging Face 仓库元数据，无法完整读取模型卡，因此延期。本轮已确认三种 checkpoint、Apache-2.0 许可与部署说明。仓库在 11 月 23 日创建、24 日更新，早于本轮 overlap；本次变化是证据可读性和可下载性得到核验，不伪装成新的发布日期。

### Ling-3.2-air 独立评测更新（TRIAL）

Artificial Analysis 在九项评测组成的 Intelligence Index 上给出 23 分，高于同类开放权重模型 5 分的中位数；这是独立评测，不再只有发布方分数。评测输出达到 1.99 亿 token，却没有速度和价格数据，因此团队仍无法只凭分数判断部署成本。

## Agent & AI Engineering

### Delegent（TRIAL）

Delegent 与整单模型路由不同：强模型始终负责计划和验收，只把搜索、测试、代码调查等范围明确的工作交给本地小模型。难点不是“能不能委派”，而是错误委派是否会漏掉关键证据，或让总时延超过节省的 API 成本。公开仓库允许在一天内用真实任务比较通过率、token、总成本和错误委派。

### 推理服务侧信道（TRIAL）

研究者用公开代码展示：即使两个模型的工具和进程彼此隔离，共享 vLLM 的批处理时序与前缀缓存仍可传递信息。侧信道是从运行时间或缓存命中这类“旁路现象”推断秘密；难点在于功能权限没有越界，信息却可能从共享基础设施泄露。结果依赖专门微调与受控脚手架，尚无真实攻击证据。

### Humanity's First Exam（TRIAL）

HFE 的核心指标是同一题四种轻微变化能否全部答对。组内全对率会比单题平均准确率更严格，因为任何一个改写失败都会让整组失败。公开样本适合回归，但题目来自模型已知薄弱区域，不能外推为普通用户请求的总体可靠率。

## Open Source

### Songe（TRIAL）

Songe 在本地记录编码 agent 的纠错与工具结果，机器空闲时训练 adapter，并在启用前比较新旧版本。它也会形成敏感的本地对话与行为记录；真实使用前要用隔离账户验证回归、磁盘留存、删除和回滚，而不能只信“本地即私密”。

- **WePocketModel MLX**：Apache-2.0 权重与 runtime 可下载；2B 4-bit 发布方峰值为 2.76 GiB，适合在 M 系列 Mac 做小样本验证。
- **Delegent**：Apache-2.0 源码、测试、样例与复现说明齐全；结果仍需独立复现。
- **ERNIE 5.5 Flash Preview**：开放三种精度 checkpoint；1M 上下文和服务性能仍需在目标硬件上实测。

## Research

### TML 可变循环模型（TRIAL）

同一个开放 checkpoint 可让共享层运行 1 到 5 次，用来直接测“多花推理计算是否真能换来质量”。训练偏重 3 次循环，所以 1/5 次的差异同时混入训练分布影响，不能把多循环写成普遍增益。

### PenGPT（IGNORE）

代码与 checkpoint 已公开，但训练数据没有开放，画廊只展示质量最好的三分之一结果。社区热度很高，工程证据却不足；除笔迹轨迹研究外，本轮明确建议不投入。

### GPT-6 蛋白质设计（WATCH）

“结合”只表示候选分子能附着到目标，不自动说明它只结合正确目标、在体内稳定或能产生治疗效果。OpenAI 也明确说明流程用 Boltz-2、OpenDDE、ESMFold2 等专用模型筛选候选，完整结构预测仍明显落后于专用模型。没有公开设计模型、代码或 API，因此当前只跟踪独立湿实验复现。

OmniAct、AIChipBench、Draft Calibration 与 EmbodiSafety 均完成核验，但没有足以支持投入的公开实现或独立结果，本轮分别按 WATCH 线索或 deferred 处理，没有硬塞进重点摘要。
