# AI Intelligence - 2026-10-16

## Daily Executive Summary

- **China's AI export catalogue remains a draft, but temporary registration is live**: 23 AI technologies are proposed for addition and comments run through November 15. Teams should inventory cross-border transfers now without misreporting the draft as a blanket ban.
- **Beam moves from preview to Apache-2.0 open weights**: the 501B/23B-active model is testable through several runtimes or a hosted endpoint; an 8×H200 reference setup at about $40 per hour and vendor-run benchmarks remain key constraints.
- **NVIDIA releases Nemotron 3.5 multimodal weights**: Super VL offers 1M context and Bolt has a 24GB artifact; OpenMDW terms, hardware compatibility and vendor-reported results still need validation.
- **Granite Switch 4.1 uses one base for several adapters**: Apache-2.0 8B/30B models put chat, decision, guardian and ASR behind one endpoint, making memory and service-consolidation claims testable.
- **llama.cpp 0.7.0 improves MoE inference and changes interfaces**: expert caching may speed decoding, while the port, chat response shape and RPC protocol all require regression testing.

## Models

- **Beam** (updated / TRIAL): BF16, FP8 and NVFP4 weights, a model card and several runtimes are available. Sparse MoE activation does not make deployment cheap; the reference hosted setup still uses eight H200s. [Release](https://huggingface.co/blog/reflectionai/beam)
- **Nemotron 3.5** (new / TRIAL): Super VL targets long-context multimodal agents, while Bolt provides a smaller 24GB quantized path. Most results come from NVIDIA or partners. [Announcement](https://developer.nvidia.com/blog/nvidia-nemotron-3-5-super-vl-powers-specialized-agents-with-multimodal-reasoning/)
- **Granite Switch 4.1** (new / TRIAL): composable adapters share a base model and KV cache. ASR is a cascade, not jointly trained multimodality. [Release](https://huggingface.co/blog/ibm-granite/granite-switch-4-1)
- **Liquid d1-ultra** (updated / TRIAL): the hosted API returns fixed-choice probabilities at $0.042 per million input tokens with no output-token charge; its 112-task results are vendor-run. [Announcement](https://www.liquid.ai/blog/d1-ultra)
- **Timestral** (new / TRIAL): 5M–209M open weights lower the cost of time-series baselines; leaderboard advantages need independent reproduction. [Announcement](https://mistral.ai/news/timestral/)

## Agent & AI Engineering
