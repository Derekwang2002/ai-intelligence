# AI Intelligence - 2026-10-16

## Daily Executive Summary

- **Muse Spark now has open weights, but open does not mean small or permissively licensed**: 816B-A42B weights, a hosted endpoint and multiple runtimes are available; access is gated and the custom license adds MaaS conditions.
- **Timestral compresses open-weight time-series forecasting into 5M–209M parameters**: four models can be trialed on CPU or GPU; Mistral submitted the leaderboard results and independent reproduction is absent.
- **GitHub AI Scan and agentic autofix reach GA**: one broadens PR vulnerability detection and the other generates and iterates CodeQL-checked patches; both consume security AI Credits, and neither output can directly block merges.
- **Claude Code 2.1.300 hardens long-running recovery boundaries**: it fixes lost or duplicated resumed work, policy-read hangs, worktree bases and background-service shutdown, making it a priority regression upgrade.
- **Cloudflare and OpenAI test change signals for web discovery**: a cohort covering about 1% of the network helped find hundreds of millions of unknown pages; this is a jointly reported pilot without a public API or downstream quality data.

## Models

- **Muse Spark Open** (updated / TRIAL): 816B total and 42B active parameters, multimodal input and one-million context. Sparse activation does not make self-hosting easy; the BF16 reference still uses 32 H200 GPUs. [Release](https://huggingface.co/blog/meta-muse-spark-open)
- **Timestral** (new / TRIAL): four 5M–209M weights cover probabilistic forecasting with past and known-future covariates. Quantiles provide ranges instead of one point estimate, but poor calibration can still make the ranges misleading. [Announcement](https://mistral.ai/news/timestral/) · [Model card](https://huggingface.co/mistralai/Timestral-209M)
- **Cloudflare–OpenAI Web Discovery Pilot** (new / WATCH): change signals tell a crawler which pages are new or stale, reducing repeated fetches of unchanged content. Scale does not establish search quality, and the pilot has no public interface. [Official results](https://blog.cloudflare.com/cloudflare-openai-discovery-agentic-web/)

## Agent & AI Engineering

- **Claude Code 2.1.300** (updated / ADOPT): fixes lost or duplicated resumed messages, policy-read timeouts, wrong worktree bases, false daemon stops and hook-input validation. [Stable release](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)
- **Qwen Code 0.25.2** (updated / TRIAL): adds team messaging, durable plan approval, Test Failure Explorer and default-off foreground Shell while hardening managed recovery. [Stable release](https://github.com/QwenLM/qwen-code/releases/tag/v0.25.2)

## Open Source

Muse Spark, Timestral and HiRO-ACEv2 all provide inspectable artifacts, but with different openness: Muse is gated and custom-licensed, Timestral uses modified MIT terms. The open-weights label alone is insufficient.

## Research

- **HiRO-ACEv2** (new / TRIAL): downsamples roughly 100 km ACE output to 3 km fields across precipitation, wind and pressure. The authors report X-SHiELD statistics within 3% even at extreme points and roughly 1/300th cost, but the model is limited to X-SHiELD-aligned inputs and cannot directly model warmer futures or ERA5 history. [Research post](https://huggingface.co/blog/allenai/hiro-acev2)
