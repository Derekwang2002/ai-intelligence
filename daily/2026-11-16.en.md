# AI Intelligence - 2026-11-16

## Daily Executive Summary

1. **Qwen Code 0.27.4 opens controlled local access and tightens Auto Mode authorization.** The stable release adds temporary directory grants, an authenticated managed web terminal, and Feishu and WeCom webhooks. Remote execution and enterprise messaging are easier to connect, but grant lifetime, destructive-action approval and message delivery still need regression tests.
2. **Qwen Concept 27B turns disputed weight-space programming into a downloadable controlled experiment.** The publisher released weights, code, evaluation data and a norm-matched random control, and reports improvements on GPQA, LiveCodeBench and thinking-token use. With no independent replication, the disposition moves from IGNORE to a bounded TRIAL rather than a training-strategy conclusion.
3. **Sophon-Realtime v1 releases full-duplex voice weights, code and a trial API.** The 32B model can run on one 80 GB GPU and offers a three-hour OpenAI Realtime-compatible trial. The 0.25-second first-audio latency and benchmarks are publisher-reported; real interruption quality still needs replay.
4. **Inkling 2 Small opens a 1M-token multimodal MoE model.** The Apache-2.0 model has 594B total and 17B active parameters and is available through Tinker and third-party APIs. Native NVFP4 self-hosting needs at least 500 GB of aggregate VRAM.
5. **LiteLLM 1.108.9 backports reasoning and gateway fixes to LTS.** The update covers mixed reasoning, Responses caching, Vertex caller identity and several provider routes. LTS teams can narrow the gap to mainline, but cross-provider translations still require a canary replay.

## Models

### Inkling 2 Small

A mixture-of-experts model does not run every parameter for every token; it activates only a small set of experts. The hard part is that 594B total parameters are not the same as per-token compute: Inkling activates about 17B parameters per token, while all weights still consume memory.

### Sophon-Realtime v1

Full duplex means the model keeps listening while speaking and must stop or revise its response when the user interrupts. The hard part is not only fast first audio, but also barge-in detection, state recovery and transcript consistency. Publisher benchmarks cannot replace real conversation replay.

## Research

### Qwen Concept 27B

Weight-space programming edits model matrices directly instead of continuing gradient training on task data. The hard part is separating a real method from effects caused by edit magnitude, evaluation choice or random perturbation. The released random control and preregistered subset make that question testable, but independent replication is still missing.

The publisher edited nine down-projection matrices in Qwen3.5-27B and released BF16, FP8, NVFP4 and GGUF artifacts. Reported results include +4.3 points on GPQA, +13 on LiveCodeBench and 27% to 54% fewer thinking tokens on selected tasks.
