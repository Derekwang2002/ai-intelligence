## Models

### AstaBrief-8B (TRIAL)

Ai2 opened AstaBrief-8B, a Qwen3-8B-based model that produces cited research reports in one pass. The model, data and local ScholarQA workflow are public, but most quality evidence is author-reported and the human study covered only 14 questions. Run a one-day test on a local paper corpus, measuring citation precision, recall, latency and unsupported conclusions.

### PixelUMM (WATCH)

PixelUMM released a 15.2B checkpoint and code for one model that directly handles image and video understanding and generation in pixel space. A “unified pixel-space model” removes the separate vision encoder and generation VAE; the hard part is making one backbone both read accurately and generate stably. The checkpoint is noncommercial and the training example is incomplete, so wait for independent reproduction and a commercial license.

### Clef (TRIAL)

Cloudflare opened Clef and Clef-flash for bounded typed routing and classification in agent workflows. They are Jev-API compatible and available as open weights or through Workers AI. Compare latency, calibration, abstention and cost on real routing samples rather than accepting vendor rankings directly.

## Agent & AI Engineering

### GitHub Copilot (TRIAL, updated)

GitHub Copilot previewed desktop computer use and code-defined dynamic workflows. Computer use can click, type, scroll and drag after requesting approval. Workflows support serial and parallel agents, structured results, verification and checkpoints. Test reversible tasks in a disposable profile and record approval coverage, unintended actions and recovery.

### Codex 0.160.0 (ADOPT, updated)

Codex adds optional Guardian retrieval of prior instructions and handoff context, plus better resume, reconnect, permission preservation and SQLite-stall recovery. Before enabling it, test unwanted historical recall and whether recovered long-running jobs keep their original permission boundaries.

### Claude Code 2.1.287 (ADOPT, updated)

Claude Code adds Mods and a built-in observer side-agent, while fixing dangerous `rm`, symlink writes, MCP permission ceilings and duplicate calls after protocol changes. The new OTel `prompt_text` field can carry prompt contents, so confirm telemetry redaction before rollout.

### DeepSeek Harness (TRIAL)

DeepSeek Harness entered worldwide public preview under MIT, with desktop apps and a local web UI built around composable plugins. Agent teams, auto-approval review and scheduled tasks remain experimental, and the repository warns of breaking changes. Test it only with an isolated directory and disposable account.

## Research

### KaliBench (TRIAL)

KaliBench releases 8,504 natural-language-to-Kali-command pairs across 1,642 subtools, plus Docker evaluation and training recipes. Runtime-free verifiable reward canonicalizes a command and checks its arguments and composition without executing it against a real target. The hard part is accounting for aliases and equivalent forms without granting unsafe access. Verify reuse terms, then run a one-day sandboxed baseline.

### Argo-Bench (TRIAL)

Argo-Bench releases 210 enterprise data tasks and a synthetic warehouse with 7.5 billion rows. It grades the resulting filings and business actions, not whether SQL or prose sounds plausible. The hard part is reconstructing hidden business state across many tables and then taking the right consequential action. Run 5–10 representative tasks and compare outcome accuracy, cost and recovery.

## Developer Tools

The Copilot, Codex and Claude Code updates point to the same engineering shift: agents are becoming programmable, resumable runtimes that can operate external interfaces. That expansion also increases approval, telemetry and stale-context risks.

## Infrastructure

### SGLang 0.5.21 (TRIAL, updated)

SGLang can switch workers between prefill and decode roles at runtime and now defaults to its Rust unified radix-tree cache core. It adds decision and score APIs and tightens chat-template and unpickling boundaries. Reproduce vendor performance claims on a representative workload and complete the breaking-change checklist before rollout.
