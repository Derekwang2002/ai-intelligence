# AI Intelligence - 2026-11-19

## Daily Executive Summary

1. **GPT-6.2 Astra / Sol 正式开放。** OpenAI 把两款模型带到 ChatGPT Work、Codex 与 API；Astra 输入和输出降价 20%，缓存输入降价 60%。两者有 105 万 token 上下文，但超过 27.2 万输入后会进入更高计价档，厂商 benchmark 与高能力安全分类都需要本地验证。[来源](https://openai.com/index/introducing-gpt-6-2-astra-sol/)
2. **MAI Code 2 进入 Copilot，Flash 仍是限量 preview。** Microsoft 的性价比数字来自最高推理强度、内部 harness 和五折促销价，适合先做真实仓库 POC，不宜直接当作与前沿模型等价的独立证据。[来源](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)
3. **BIS 准备把部分远程算力访问纳入出口许可。** 预发布 IFR 覆盖向澳门或 Country Group D:5 实体提供的大规模算力，并增加五个目的地管制；PDF 仍有《联邦公报》日期占位符，所以目前不能写成已经生效。[来源](https://www.bis.gov/media/documents/rin-0694-ak50.pdf)
4. **真实合并产出没有随 coding benchmark 明显上升。** 一项自然实验覆盖 297 名受影响开发者和 8,908 名对照者，结果区间跨过零；它提醒团队把 PR 周期、返工和缺陷率纳入选型，但不能证明更强模型没有节省时间或改善质量。[来源](https://arxiv.org/abs/2611.23216)
5. **Agent Substrate 的成熟度需要上调。** 本次复核找到更早的 Google 一手来源：1.0 已在 GKE GA，而不只是后来进入 CNCF Sandbox；恢复、密度与吞吐仍是发布方数据。[来源](https://cloud.google.com/blog/products/containers-kubernetes/open-infrastructure-for-autonomous-agents-comes-to-cncf)

## Models

### GPT-6.2 Astra / Sol

现在可在 ChatGPT Work、Codex 和 API 使用，Enterprise/Edu 需要管理员启用。Astra 每百万输入、缓存输入和输出 token 为 8、0.40 和 40 美元；Sol 为 2、0.10 和 10 美元。**长上下文计价档**是指请求超过某个输入长度后，单价会跳升，而不是只按原价线性增加；本次阈值为 27.2 万输入 token。

### MAI Code 2 / Flash

MAI Code 2 已进入 GitHub Copilot，Flash 只对 Foundry 限量开放。Microsoft 报告的对比把多个 benchmark 求平均，且三项使用内部 MSBench、Copilot CLI、禁用 subagent；后续生态集成尚未开放。

### Rumble 2 Flash

Reson8 公开了 0.5B、Apache-2.0 的多语 ASR 权重，可原生使用 Transformers 与 vLLM。7,000 RTFx 与错误率来自发布方，适合用真实音频测 WER、尾延迟和领域词。 [来源](https://huggingface.co/blog/rumble-2-flash)

### Microsoft Decision 1.1

Decision 1.1 已 GA 并加入多模态输入；Microsoft 自报 4,000+ 客户，以及最高 50 倍速度、79 倍成本优势。闭集决策只在固定候选中选择，不能替代开放式推理。 [来源](https://commandline.microsoft.com/microsoft-decision-model-ga/)

### HY4 Flash 开放权重

腾讯已经发布 HY4 Flash 的指令版与 base 权重，并提供 vLLM、SGLang、量化和微调资料；此前“权重尚未开放”的判断已更新。模型使用自定义 Tencent Hy License，约 220B 总参数、每个 token 激活约 12B，试验前要先核对许可与硬件成本。[来源](https://huggingface.co/tencent/Hy4-flash)

### Qwen3.8 pi adapter

harness-hub 发布 Apache-2.0 LoRA，把 Qwen3.8-27B 适配到 pi coding agent。发布方称关闭 thinking 后可用约 1/4.5 的生成 token 达到基础模型 xhigh 的准确率；checkpoint 选择看过部分评测任务，因此先用真实仓库复现。[来源](https://huggingface.co/harness-hub/Qwen3.8-27B-pi-adapted)

### Apple FastFrames

FastFrames 公开 1.3B 与 14B 视频生成模型和论文。发布方在 B200 级硬件上报告 36–45ms 单帧延迟，达到其定义的交互区间；权重采用 Apple AMLR 许可，硬件与独立画质复测仍是采用门槛。[来源](https://arxiv.org/abs/2611.23226)

## Agent & AI Engineering

### Agent Substrate 1.0

Google 的 11 月 5 日一手来源确认它已在 GKE GA，并可部署到其他 Kubernetes 环境。检查点恢复会在 agent 空闲时保存内存和文件系统，之后恢复会话；难点是既要快，又要保证状态一致和租户隔离。

### LiteLLM 1.108.11 LTS

LTS 修复 Bedrock 护栏字段丢失、客户端中止后上游仍继续生成，以及 Gemini 工具参数截断。对网关团队，这些分别影响安全行为、隐藏费用和工具可靠性。 [来源](https://github.com/BerriAI/litellm/releases/tag/v1.108.11)

### FrontierHarness Eval v1.1

Runta 与 Baseten 用 27,280 次运行比较 22 种 harness 配置和 5 个开放模型。同一模型在不同 harness 下的任务成本相差 1.8–5 倍，模型变化后 harness 的成本排名中位数移动 11 位。**单次通过成本**把平均任务成本除以通过率，避免只选便宜但经常失败的组合；限制是评测由发布方运行，并只覆盖 62 个终端任务。[来源](https://runta.com/blog/introducing-frontierharness-eval-v1-1/)

### KORMo-Web-11B

KAIST MLP Lab 公开从头训练的韩英双语多模态 web agent，提供 Apache-2.0 权重、browser harness、Chrome extension 与 vLLM 路径。发布方在韩语 Online-Mind2Web 报告 30.1% 成功率；不同模型使用不同 prompt 与动作格式，仍需本地任务验证。[来源](https://huggingface.co/KORMo-VL/KORMo-Web-11B)

### PostHog 的 decision-model gate

PostHog 披露 production pipeline：两个窄问题让 98.7% 的 session summary 跳过 Gemini 重写，并用 decision model 做模型路由与重排。关键不是追求一个通用阈值，而是按误判代价、任务和模型分别校准，并先运行 shadow mode。[来源](https://newsletter.posthog.com/p/decision-models)
