# AI Intelligence - 2026-11-17

## Daily Executive Summary

- **CVS opens CUA Agent Kit**: an agent discovers a workflow, then compiles it into repeatable Playwright or pywinauto automation. Public code is testable; healthcare outcomes and production scale remain vendor-reported.
- **Qwen4-Max reaches a production API**: the stable SKU offers a 1M-token context at $1.50/$4.50 per million input/output tokens; weights remain closed.
- **Tencent launches HY4 Flash**: the multimodal API costs $0.070/$0.281 per million input/output tokens. Speed and quality are vendor-tested, and promised open weights have not shipped.
- **OpenAI adds a potential-CSAM classifier**: approved organizations can call it at no charge, but no public performance data exists; scores are not calibrated probabilities or legal findings.
- **GitHub bulk-starts AI Scan**: the security overview can start default-branch scans for up to 20 repositories; the control remains a public preview.

## Models

### Qwen4-Max moves from preview to production API
Alibaba documented a stable qwen4-max SKU, price and access. Vendor benchmark and Work360 cost claims remain independently unreplayed. [Source](https://www.alibabacloud.com/blog/alibaba-unveils-qwen4-max-for-complex-agentic-workflows_602835)

### HY4 Flash targets low-cost multimodal APIs
HY4 Flash has 224B total parameters, 12B active parameters and a 1M-token context. Engram places some static knowledge in dedicated memory parameters; it may reduce attention work, but real gains depend on workload and serving. [Source](https://www.tencent.com/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows/)

## Agent & AI Engineering

### CUA Agent Kit separates discovery from execution
“Discover then compile” uses an agent to find the route once and deterministic code to replay it; page drift, permissions and sensitive traces remain the hard parts. HealthAdminBench rubric points grade individual criteria and are not the same as strict end-to-end task success. [Code](https://github.com/cvs-health/cua-agent-kit)
