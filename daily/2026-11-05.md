# AI Intelligence - 2026-11-05

## Daily Executive Summary

1. **Kimi K3.1 Pro 同时开放权重与 API。** 2.8 万亿总参数、1040 亿激活参数和 100 万 token 上下文让它成为重要开源权重选项；自托管成本和定制许可是主要限制。

4. **Claude Code 2.1.318 集中修复长会话恢复。** 续接、压缩、无头运行、共享主目录和配置写入都在修复范围，升级价值主要在可靠性。
5. **LiteLLM 1.108 加固 gateway 边界。** 签名镜像、凭据修复、MCP OAuth/session、流式护栏和预算控制一起变化，生产环境应先 canary。
