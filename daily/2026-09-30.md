# AI Intelligence - 2026-09-30

## Daily Executive Summary

本次增量窗口新增 8 个事件，更新 3 个已有工具事件，并完成 5 项到期复核。最值得动手验证的是 Claude Sonnet 5.5、Kumo Tabular、MCP TypeScript SDK 2.2 和 Failure-Transparent Agents：前两项可能改变模型路由与表格冷启动的成本账，后两项直接影响 agent 的安全边界与失败汇报。Codex、Qwen Code 与 Claude Code 的稳定版继续把运行中控制、恢复和权限约束下沉到 runtime。4 篇新论文提供了有用但仍需复现的系统信号；本周期没有出现证据充分的新趋势。

## Models

- **Claude Sonnet 5.5（TRIAL）**：Anthropic 在 API、Claude Code 与三大云同步提供新模型。单价仍为每百万输入 token 2 美元、输出 token 10 美元，厂商称生成速度快 30% 以上、单任务成本最多低 30%。迁移前要检查 `between_tools`、forced tool choice、thinking block 重放和 computer-use tool 版本；性能与成本结论仍需用自有轨迹复核。
- **Kumo Tabular（TRIAL）**：NVIDIA 发布 28M–215M 参数的开放权重表格基础模型，用带标签的行作为上下文，无需任务级训练即可做分类或回归。权重与推理代码已公开，训练配方和合成数据生成器尚未发布。先在留出表格上与调优后的树模型比较准确率、校准、延迟和 GPU 成本。

## Agent & AI Engineering

- **MCP TypeScript SDK 2.2（TRIAL）**：机器间 OAuth 现在必须明确 issuer，并会在 token 请求前拒绝授权服务器不匹配。不传 cursor 的列表调用改为自动翻页。升级前要回归大清单，因为请求数、延迟、内存和返回规模都可能变化。
- **OpenAI Python SDK 3.20（WATCH）**：SDK 新增 Agents vault 凭据元数据、`ultrafast` 会话档位、策略违规结果和 WebSocket 增量快照。它把托管 agent 的治理状态写进了 SDK contract，但平台可用范围与支持承诺还不够清楚。
- **Failure-Transparent Agents（TRIAL）**：在 100 个确定性工具失败任务、6 个模型和 3,600 条人工标注回答中，结构化证据契约把错误报喜从 22.8% 降到 0.8%。MIT 许可的代码与数据已经公开，可以把“失败步骤、缺失证据、下一步安全动作”直接加入阻塞任务验收。

## Open Source

- Kumo Tabular 的权重无需申请，代码为 Apache-2.0；权重使用 OpenMDW-1.1。它已经可运行，但训练侧产物不完整。
- Failure-Transparent Agents 提供 MIT 许可的代码与数据。Telescopic Language Models 与 TokenCast 虽有仓库，复核时仍只有说明或占位文件，不能当作可复现实装。

## Research

- **KV-streams（WATCH）**：让 KV 状态跨过 agent RL 的上下文压缩边界继续流动，论文报告墙钟训练加速 2.6–5 倍。隐式状态在可见上下文删除后仍可能保留，既改善记忆，也增加审计难度；目前没有可直接复现的公开实现。
- **Telescopic Language Models（WATCH）**：用随机前缀监督训练一个可在任意深度退出的嵌套 Transformer。200M 参数代理实验报告质量—算力曲线面积降低 43%–44%，但距离生产规模很远，相关仓库也没有实现。
- **TokenCast（WATCH）**：运行途中预测 agent 剩余 token。论文在离线预算回放中报告相同完成率下少用 21.3% token，但仓库代码尚未发布，不能据此直接控制线上任务终止。
- 另有 Progressive Disclosure of Agent Skills 等论文被过滤：当前缺少公开产物或足以改变工程决策的定量结果。

## Developer Tools

- **Codex 0.159.0（ADOPT，更新）**：加入运行中即时转向和 item 级历史分页；获批命令继续保留文件系统拒绝规则，`.aws` 默认受保护，并修复 macOS 网络沙箱与 Windows 子进程边界。升级前重点回归中断恢复和写入白名单。
- **Qwen Code 0.24.7（TRIAL，更新）**：Managed Runtime 现在绑定 workspace identity，持久化执行凭据，并在接管或重启后核对进行中的工作。该版也修复了过期 worktree 清理可能误删未跟踪文件的问题。
- **Claude Code 2.1.284（ADOPT，更新）**：加入工作区外单次读取许可、`/mcp reconnect all`、gateway 花费上限、`private_key_jwt`、Google Cloud OTLP 直传和托管模型策略告警。Sonnet 5.5 成为默认 Sonnet。

## Infrastructure

KV-streams 把上下文压缩从“清空再 prefill”改成状态连续传递；Telescopic Language Models 则尝试用单一 checkpoint 覆盖不同算力档位。两者都可能影响 serving 或后训练架构，但目前仍是小规模、作者报告的 frontier evidence。vLLM 本窗口没有新的 stable release。

- **趋势 #2：MCP 进入企业安全与强制管控阶段**：MCP TypeScript SDK 2.2 的 issuer 校验和 Claude Code 的 `private_key_jwt`、批量重连构成新支持信号。跨厂商 schema 与公开生产遥测仍缺，维持 emerging / Medium。
