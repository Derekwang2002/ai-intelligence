## Agent & AI Engineering

- **New · SciExam for ENSO** (TRIAL): Instead of giving an agent a known answer, SciExam asks it to build a climate model from real observations, then uses hidden tests for statistics, unobserved variables and held-out years. A hidden grader is an acceptance program the agent cannot inspect. The hard part is preventing answer-targeting while proving that held-out data did not leak. Public Docker, grader and examples make a one-day regrade feasible.
- **New · RunningTab** (WATCH): It places requirements, provenance-bearing excerpts and unopened-file candidates in a runtime-maintained tab, then blocks finishing while obligations remain unresolved. An environment-side record means the runtime preserves state instead of relying on model context. The paper has no public code, so its claimed reduction in omissions cannot yet be verified.

## Open Source

- ExpDis publishes Apache-2.0 code and checkpoints. SciExam publishes MIT-licensed code, Docker and a grader. Both have runnable artifacts, but their results remain primarily author-reported.
- **New · Whistle** (TRIAL): A 16.9 MB Apache-2.0 model provides seven-language transcription, word timestamps and speech embeddings on CPUs. Its author benchmarks need replication, but the public runtime supports target-device tests of WER, latency, memory and thermals.
- **New · GLM-5.3 E224** (IGNORE): A community derivative targets two DGX Spark systems with a 141 GiB pruned and quantized model, but accuracy and throughput were measured only on B200. Target-hardware claims remain estimates, so popularity does not justify investment.

## Research

- **New · ExpDis** (TRIAL): Novelty-rewarded explorers search for different solutions, then correct trajectories are distilled into a separate student. This avoids letting sparse rewards distort the production policy. `pass@k` measures the chance that at least one of k samples is correct. It depends on both correctness and diversity, so single-sample accuracy is not enough.
- SciExam moves research-agent acceptance from matching a known answer to passing unseen scientific tests. RunningTab moves completion state outside model context. They are independent signals, but not enough for a new trend.
- **OpenAI Math Results** (update / WATCH): A sign error invalidated one construction and two dependent manuscripts, leading to three withdrawals. Fourteen other manuscripts were repaired and thirteen updated dependency citations. Lean coverage reached 300/719, but roughly 42% coverage also shows that formal verification remains incomplete.
