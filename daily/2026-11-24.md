## Models

### GLM-5.4（WATCH）

GLM-5.4 把 28 个共享中间层运行两遍，用同一组参数增加计算深度。所谓循环架构，是让中间表示再经过同一批层继续修正；难点是它会增加推理计算与缓存设计复杂度，而且可能陷入过长思考。全部 Coding Plan 档位、ZCode 与 Z.ai Chat 已可用，但标准 API 与权重尚未开放。

来源：https://z.ai/blog/glm-5.4；https://zcode.z.ai/cn/docs/qa

### WeMM-Ecom（TRIAL）

Tencent 上传 0.8B、2B、4B、9B 与 35B-A3B 权重，并提供 GGUF、GPTQ 和本地服务说明。模型面向商品 OCR、属性提取、审核与多模态理解。厂商覆盖 92 项 benchmark 的汇总结果尚未独立复现。

来源：https://huggingface.co/tencent/WeMM-Ecom-35B-A3B；https://huggingface.co/collections/tencent/wemm-ecom

### GPT-Live-1.1（TRIAL）

OpenAI 在 11 月 19 日开放 GPT-Live-1.1。活跃会话每分钟 0.05 美元；WebRTC 暂停推理时待机为每分钟 0.02 美元。多语言转写与口音提升来自厂商陈述，发布日期只有日期精度，作为定向补漏入库。

来源：https://developers.openai.com/api/docs/changelog；https://developers.openai.com/api/docs/models/gpt-live-1.1

### LingSante-3.1-flash（WATCH）

InclusionAI 公开面向医疗推理、证据研究和长流程任务的 MIT 权重。医疗 agent 是把检索、判断和工具调用串成一段工作流；难点是一次错误会沿后续步骤放大。官方配方需要 8×H200 或 4×GB300，benchmark 与模拟任务都来自发布方，不能当作临床有效性。

来源：https://huggingface.co/inclusionAI/LingSante-3.1-flash
