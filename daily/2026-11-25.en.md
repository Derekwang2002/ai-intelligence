## Daily Executive Summary

1. **OpenAI and Cisco open-source Shirudo.** The pre-release runtime loads signed eBPF and Java mitigations on running Linux systems and records attestable state with a TPM. It can bridge disclosure and permanent patching, but production requires a patched kernel; use only an isolated VM today. [Source](https://openai.com/index/introducing-shirudo/)
2. **GPT-6.2 reaches the regular ChatGPT chat tab.** Plus, Pro, Business and Enterprise users are receiving a GPT-6.2 Sol variant globally, while Enterprise remains subject to admin settings. [Source](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)
3. **The Gemini API can inspect only the needed parts of files.** Server-side slicing targets PDF pages, spreadsheet ranges, media intervals and content layers, billing only inspected content. Partner savings remain publisher material and need reproduction on real multimodal-RAG work. [Source](https://blog.google/innovation-and-ai/technology/developers-tools/file-slicing-controls/)
4. **Tencent opens OmniEVIE-4B.** The Apache-2.0 multimodal retriever handles text, images, visual documents and video while localizing matching page regions or video intervals. Weights and code are public; quality and latency lack independent reproduction. [Source](https://huggingface.co/tencent/OmniEVIE-4B)
5. **Ai2 releases RoboTrack.** Public artifacts include a real-manipulation benchmark, 15 million synthetic tracks, code and two checkpoints. The strongest checkpoint is noncommercial, and publisher results do not establish safe closed-loop robot control. [Source](https://huggingface.co/blog/allenai/robotrack)

## Agent & AI Engineering

### Shirudo (TRIAL)

eBPF programs run in a restricted Linux-kernel environment to observe or block selected system behavior. Shirudo wraps temporary mitigations in signing, approval and TPM-backed evidence. The hard part is that a bad shield sits on a privileged path and can break legitimate workloads. The repository is explicitly pre-release and production targets need kernel changes plus TPM 2.0.

### Gemini Tool Retrieval (TRIAL)

The Gemini Interactions API preview can defer tool schemas and load them on demand inside one request, including remote MCP servers. The feature was published on November 19 and is included as an older omission recovered from the fixed source. It has no separate charge, but selection accuracy, authorization and retrieval overhead need real-catalog tests.
