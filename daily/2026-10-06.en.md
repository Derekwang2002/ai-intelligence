# AI Intelligence - 2026-10-06

## Daily Executive Summary

This run adds two events and materially updates three existing judgments. OpenAI launched textGrain text watermarking, but short text, synonym edits and a restricted detector still limit independent validation. The recall audit also surfaced AutoTrust decision models with high downloads but weak reproducible and independent evaluation, so they are explicitly rated IGNORE. vLLM 0.31 and Qwen Code 0.25 advance fast inference recovery and collaborative coding-agent recovery.

## Models

- **New · AutoTrust GEV/JEV** (IGNORE): two public-weight models show unusually high Hugging Face downloads, but GEV has only an unverified author-run result and JEV lists no model-index score. High downloads justify discovery, not investment.

## Agent & AI Engineering

- **Qwen Code 0.25** (update / TRIAL): the stable release adds local workspace-agent collaboration, A2A sharing, private hosted MCP, durable shell results and cold-session restore. “Durable results” means recording tool output before restoring agent state; the hard part is neither losing the result nor repeating a side-effecting command after restart.
- **Private Safety Processing** (update / WATCH): OpenAI says phased rollout for approved API customers began on September 22 and now documents AWS, Azure and Google Cloud setup. ZDR does not mean content is stored nowhere; customer-controlled encrypted storage and retention of up to 30 days still apply.

## Open Source

- **AutoTrust GEV/JEV**: weights and adapters are public, but evidence quality has not kept pace with the adoption signal; wait for a reproducible benchmark or independent evaluation.

## Developer Tools

- **Qwen Code 0.25**: multi-agent collaboration and failure recovery reached stable, making a one-day recovery and duplicate-side-effect test worthwhile in a non-critical repository.

## Infrastructure

- **vLLM 0.31** (update / ADOPT): `vllm preload` now covers DP/MTP, experimental CRIU initialized-engine snapshots arrive, and per-request multimodal arguments are rejected by default. CRIU snapshots preserve initialized process state to skip part of cold startup; GPU, driver and process-state compatibility make recovery difficult.

## Business & Policy

- **New · textGrain** (WATCH): OpenAI offers opt-in text watermarking for selected API models and a phased rollout in EU ChatGPT and Codex. Official tests report about 80% detection at 200 tokens and 95% at 400 tokens, but synonym edits weaken the signal sharply. The watermark is a statistical pattern in token choices, not a visible label; short text provides fewer observations and is harder to classify reliably.
