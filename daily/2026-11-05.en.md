# AI Intelligence - 2026-11-05

## Daily Executive Summary

1. **Kimi K3.1 Pro releases weights and an API.** With 2.8 trillion total parameters, 104 billion active parameters and 1 million tokens of context, it is a major open-weight option; hosting cost and its custom license are the main constraints.
2. **Mage-VL-Cowork compresses GUI/terminal routing into a 4B model.** Microsoft released Apache-2.0 weights, code and a training recipe; the 66.0% OSWorld-Verified score remains author-run.
3. **StateBench exposes a dynamic-state tracking gap.** The public benchmark asks assistants to keep “what is true now” updated; authors report at most 13% on the hardest setting, but the tasks remain synthetic.
4. **Claude Code 2.1.318 focuses on long-session recovery.** Resume, compaction, headless operation, shared homes and configuration writes are all in scope; the value is reliability.
5. **LiteLLM 1.108 hardens the gateway boundary.** Signed images, credential repairs, MCP OAuth/sessions, streaming guardrails and budget controls change together, so production gateways should canary it.

- **LiteLLM 1.108** (TRIAL): hardens credentials, MCP sessions, streaming guardrails and budget admission; canary first.
