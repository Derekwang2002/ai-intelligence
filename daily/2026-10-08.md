# AI Intelligence - 2026-10-08

## Daily Executive Summary

本轮新增 8 条事件，更新 5 条既有事件。Claude Haiku 5.5、EmbeddingGemma 2 与 Liquid d1 分别把低成本生成、多模态检索和结构化决策推向更小、更本地的执行面。Anthropic 同时扩大 Cyber Verification Program，把高风险 cyber 能力按用途分层开放。ScienceClaw-Eval、openTPU、EMA Lightning 和 OpenAI 的数学成果分别补充了持续学习、可审计硬件、开放语音与可机检研究信号。开发工具侧，Claude Code、Codex、Gemini CLI、GitHub Copilot 和 GPT-6 均出现可用性或治理更新。

## Models

- **新 · Claude Haiku 5.5**（TRIAL）：Anthropic 已在 API、Claude 应用和三家主要云平台开放新一代 Haiku。价格在 10 万 token 后提高 5 倍，评估长上下文任务时要按完整输入成本计算。
- **新 · EmbeddingGemma 2**（TRIAL）：Google 发布 740M 参数的端侧多模态嵌入模型，覆盖文本、代码、图像、视频和音频，并开放 Apache 2.0 权重。Matryoshka 嵌入允许只保留向量前 128、256 或 512 维来节省存储；难点是截断后必须重新归一化，并确认召回率没有悄悄下降。
- **新 · Liquid d1**（TRIAL）：d1-3B 与 d1-omni-600M 不逐 token 生成文本，而是一次前向计算返回带类型的选择或数值。这样的单次决策适合路由和边缘审核；难点是要同时验证校准、许可和 `trust_remote_code` 的执行边界。

## Agent & AI Engineering

- **新 · Anthropic Cyber Verification Program**（TRIAL）：Anthropic 把高级 cyber 能力分成 Defense、Red Team 与 Specialized Access 三档，并将更强能力绑定到身份核验、workspace 分配和持续监测。团队可以从 Defense Access 开始做已授权漏洞复测，但不能把厂商访问控制当成自己的审计替代品。
- **新 · ScienceClaw-Eval**（TRIAL）：benchmark 检验固定模型能否把一次任务修复沉淀为后续可复用的 Skill 与 Operator。它的 replay 是把同一任务重跑，确认修复不是偶然；难点是还要在没参与修复的任务上保持提升，才能说明知识真正迁移。

## Open Source

- EmbeddingGemma 2 以 Apache 2.0 发布权重；ScienceClaw-Eval 公开 benchmark 与运行代码；Liquid d1 公开权重和 demo，但使用自定义 LFM 许可。
- **新 · openTPU**（TRIAL）：项目以 Apache 2.0 公开从 RTL、指令集、模拟器、编译器到 profiler 的完整 FPGA 加速器栈。10 月 7 日更新加入 Hugging Face golden model 校验；它更适合学习和验证，而不是替代生产加速器。
- **新 · EMA Lightning**（TRIAL）：8.6M 参数的土耳其语流式 TTS 开放了 Apache 2.0 权重、代码和 pip 包。作者报告延迟与 WER 很强，但训练语料不公开，必须用自有语音独立复测。

## Research

- **新 · OpenAI 模型生成数学成果**（WATCH）：OpenAI 公布新一批模型生成的数学结果，并提供 Lean 形式化、修订和引用规则。形式化证明可以由 Lean 检查每一步是否符合规则，但它不能替代专家判断问题是否重要、假设是否合适或结果是否真正新颖。

## Developer Tools

- **Claude Code 2.1.292/293**（更新 / ADOPT）：新增长任务自动压缩、async hook、git worktree 隔离和更多 managed policy 控制；升级前应回归 hook、恢复与 worktree 清理。
- **Codex 0.161.0**（更新 / ADOPT）：改进 subagent 路由、MCP 资源发现和长任务摘要，并修复审批与恢复边界。
- **Gemini CLI 0.63.0**（更新 / WATCH）：稳定版强化内存控制、认证恢复和非交互计划执行；A2A 兼容承诺仍不明确。
- **GitHub Copilot**（更新 / ADOPT）：本地 sandbox 从 preview 转为 GA，并加入 Ollama 模型发现。启用前仍要校验网络、文件系统和仓库写权限。
- **GPT-6 Intelligent UI**（更新 / TRIAL）：OpenAI 公开更具体的生成式界面工作流与示例，适合用真实任务测试可访问性、状态保持和失败恢复。

## Infrastructure

EmbeddingGemma 2 与 Liquid d1 都把多模态能力压到本地设备。召回自检还补出 openTPU：它公开一套从编译器到 FPGA 板卡的可审计实现。三者仍缺企业采用，尚不足以把「企业本地执行面」趋势提升出 candidate。

## Business & Policy

Anthropic 的 Cyber Verification Program 扩大了高风险模型能力的分层访问。它改变的是能力开放方式和控制责任，不是通用 API 政策。

## Worth Trying

- 用 EmbeddingGemma 2 的公开权重，在目标设备上比较 128、256、512 和 768 维向量的召回率、延迟、内存与索引大小。
- 在隔离环境让 Liquid d1 与现有生成模型处理同一组路由任务，比较校准、尾延迟和单次成本。
- 用 ScienceClaw-Eval 复现一次 repair → replay → held-out transfer 流程，确认改进不是只记住单题。
- 用 openTPU 的 ISA simulator 跑一个小模型，对照 Hugging Face golden model 检查 token、KL divergence 和量化误差。
- 用自有土耳其语语音对 EMA Lightning 做盲听与 WER 复测，并记录冷启动、首段音频和 64 路并发的实际延迟。
