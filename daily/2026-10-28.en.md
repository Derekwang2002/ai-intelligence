## Agent & AI Engineering

### GitHub previews Copilot workload identity

GitHub added server-to-server authentication in public preview for the Copilot coding agent, allowing background services to avoid personal tokens. Workload identity assigns an identity to a machine workload rather than a developer; the hard part is preserving tenant isolation, revocation and auditability across the whole call chain.

### OpenHands 1.34 binds conversations to runtimes

OpenHands 1.34 binds runtime lifecycle to conversations and expands recovery and cleanup paths. The release fell inside overlap and was absent from the previous manifest, so it is recorded as a late discovery. Fault injection in an isolated repository should verify that recovery does not repeat tools.

## Research

### Ai2 releases Novelty Judge Bench

Novelty Judge Bench provides public code, data and baselines for research-agent deduplication and novelty checks. Its weak labels come from observable relationships rather than complete expert annotation, making it useful for screening and comparison, not as a sole novelty verdict.

### FeatureArc studies inherited defects in evolving features

FeatureArc reports that software features can inherit early design defects as they evolve, so inspecting only the latest version can miss the root cause. The paper was first found inside overlap and is recorded as a late discovery. It offers no directly usable repair tool, so it stays WATCH.

## Developer Tools

## Infrastructure

### Run:ai adds memory-enforced GPU fractioning

NVIDIA added CUDA 13.4 memory enforcement for request, limit and burst allocation. A failure domain identifies workloads affected together by one failure; time-slicing and SM sharing use different failure domains, so correct quotas do not automatically prove correct isolation.
