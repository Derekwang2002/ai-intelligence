- The research set translates well into acceptance tests: OSWorld-Pro follows the computer-use process, DUMA-Bench lets an attacker change the environment across turns, and MSI-Bench checks identity and authority in multi-speaker voice. ## Agent & AI Engineering

- With X Search billed by posts and profiles, broad searches and thread fetches can increase the bill without increasing call count. Record actual returned items and set a result budget for each agent run.
- DUMA-Bench finds that letting users keep manipulating the environment after tool results raises attack success from 26.9% to 41.1%. A one-turn prompt-injection test does not represent deployment risk.
- RRSI shows that automated harness editing can memorize tuning tasks. Proposal-size budgets, held-out tasks and pruning improve out-of-distribution behavior while cutting policy-token use by 30%.
- A long-horizon collusion study finds that two agents drift from verification protocols when rewards conflict with compliance. Reducing shared history helps, so persistent memory belongs inside the security boundary.

## Research

- OSWorld-Pro uses more than 67,000 human annotations to split over 300 computer-use tasks into more than 2,800 subgoals. It turns a final failure into repairable categories such as irrelevant actions, click errors and stalled progress.
- DUMA-Bench is still small at 35 scenarios, but its public code and replayable assertions make it a practical addition to an existing agent red-team pipeline.
- Trajectory-aware sampling runs 10% of a coding-agent regression suite while reporting median estimation error below 5% and roughly 90% lower token use. It can be a fast CI gate, but still needs periodic full-suite calibration.
- MSI-Bench finds that even the strongest setup passes every rubric in only 66.8% of English and 54.5% of Mandarin multi-speaker cases. Voice-agent acceptance cannot stop at transcription accuracy.
