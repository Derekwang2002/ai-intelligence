## Models

### Claude Fable 5.2 / Mythos 5.2

Fable 5.2 is available to all users, while Mythos 5.2 remains gated by Cyber and Life Sciences Verification Programs. Anthropic reports gains across coding, science and robotics, mostly from internal tests or prerelease customers. The official page provides date-only precision; the timestamped Claude Code 2.1.321 release confirms in-window availability.

### Muse Ember

Muse Ember is available through the Meta Model API at $0.10/M input and $0.50/M output tokens. Meta positions it for lightweight agents and tool use; there are no open weights, and quality and safety need real tool-chain acceptance tests.

### Gemini 4 Carbon

Carbon is available through the paid Gemini API in AI Studio and Gemini for business, with rollout to Google AI Ultra subscribers. Its introductory price justifies a real document and agent-task canary.

## Agent & AI Engineering

### Hugging Face Decision Models

The common interface returns choices, scores, booleans or multi-select results with probabilities over dynamic options instead of generating and parsing JSON. It fits routing and review, but calibration, unknown categories and changing options require local tests.

### HiVe-Mem

HiVe-Mem expands recall through textual and visual relationships, then chooses summaries, raw interactions, images or grounded views for each memory. The authors report about 90% lower token use and released MIT code.

**Concept:** horizontal expansion addresses missed recall, while vertical evidence selection controls how much source evidence each memory carries. More recall adds noise; more evidence consumes context.

## Open Source

### Agent Substrate

The CNCF Sandbox project separates agent memory and filesystem state from Pod lifetime. Sandbox status is an incubation route, not production certification.

### NVKE / NVKR

The Apache 2.0 public previews split reproducible node/package builds from REST-driven cluster management. NVIDIA explicitly advises against production use.

## Research

### Multimodal Knowledge Agent benchmark

MKA asks agents to produce documents, charts, spreadsheets and decks rather than answer questions. Models use the same Stirrup harness, tools, sandbox and turn budget; 10 public tasks support reproduction.

**Concept:** a private held-out set reduces answer leakage but blocks full external inspection. Rankings are comparable, while methodological transparency remains limited.

## Developer Tools

- **Claude Code 2.1.321/322:** fixes cross-host MCP OAuth-secret redirects, read-only commands outside the sandbox and cp/mv deny gaps; approval-record secret exposure still lacks a public verifiable fix.
- **LiteLLM 1.108.4:** fixes cross-provider reasoning, team BYOK wildcard routing, Bedrock guardrail precedence and base-install tool calls.
- **Ollama 0.40.16:** reports about 27 GiB lower Apple-silicon memory for Qwen3.8 Flash Next and stops silent default Responses truncation.

## Infrastructure

### TPU 8tx / TPU 8i Max

TPU 8tx protects data and weights while in use, while TPU 8i Max combines two TPU 8i chips for more memory bandwidth and rack density. Google also announced or released the TPU agent suite, TPU Sync, Cloud Pathways and GKE dynamic slicing at different preview, open-source and GA stages.

**Concept:** confidential computing protects data while it is being processed, not only at rest or in transit. The hard part is validating both the isolation boundary and its performance cost.

### NVIDIA Snapshot

Snapshot preserves initialized CPU/GPU state, supporting eight GPUs and checkpoints around 1 TB. Publisher tests used B200 and VAST NFS; benefits on ordinary network storage are unknown.
