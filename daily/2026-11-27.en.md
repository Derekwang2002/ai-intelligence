# AI Intelligence - 2026-11-27

## Daily Executive Summary

1. **Qwen Code 0.28.6 adds parking and cold recovery for managed sessions.** Sessions can park for approvals, questions or background work and resume after a cold harness restart; the event bus is now the default path. Evidence is limited to release notes, so teams still need crash injection on real repositories to rule out duplicate shell and tool side effects. [Source](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.6)
2. **Nemotron 3.5 Parse opens training data, a fine-tuning recipe and DFlash2.** Three synthetic datasets total about 18.88 million samples, with downloadable weights and recipes. NVIDIA reports 7.62x single-request throughput and 1.52x at concurrency 512 on H200, but the release team ran both speed and quality comparisons. [Source](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin)
3. **FlashInfer's NVFP4 attention path now has deployment evidence.** The code is merged, and Reactor reports up to 15.34% lower end-to-end latency on selected world-model calls. Tests cover one RTX Blackwell GPU family and use manual quality review, so the result does not generalize to every shape or model. [Source](https://developer.nvidia.com/blog/how-to-optimize-nvfp4-attention-on-nvidia-rtx-blackwell-through-register-recycling/)
4. **A 7,660-trajectory study finds removable coding-agent changes even after tests pass.** Reverting patch units and rerunning tests labeled 11% of code units unnecessary; 89% of automatically pruned patches still resolved. The study covers one Copilot CLI harness, relies on task tests and LLM judges, and provides neither public code nor human validation. [Source](https://arxiv.org/abs/2611.34875)
5. **llama.cpp launches reproducible AMD performance tracking.** Weekly jobs publish raw results and workflows, with ten repetitions for prompt processing, token generation and context scaling. Initial coverage is only Radeon 8060S and AI Pro R9700S, making this a regression baseline rather than an AMD-wide ranking. [Source](https://huggingface.co/blog/ggml-org/llamacpp-amd-bench)

## Models

### Raon-1 mini (TRIAL)

KRAFTON released final 30B-A4B weights under Apache-2.0, with MXFP8, NVFP4, GGUF and DFlash2 options. The model targets Korean chat, search and tool use. Publisher benchmarks lack broad independent reproduction, and the hosted API is free only for a limited period. Recall audit recovered this item with its actual November 24 repository timestamp rather than presenting it as today's release.

### Nemotron 3.5 Parse assets (TRIAL)

The release includes 9.98 million chart samples, 1 million table samples, 7.9 million multilingual OCR samples, a fine-tuning recipe, Parse v1.1 weights and a DFlash2 speculator. Speculative decoding lets a smaller model draft tokens for the main model to verify in batches. Its real speed depends on acceptance rate, concurrency and verification overhead, so teams should retest document quality, page throughput and memory.

## Agent & AI Engineering

### Qwen Code 0.28.6 (TRIAL)

This update changes long-run failure paths rather than adding a model. Parking stops an execution loop while external input is pending; cold recovery resumes persistent state in a new harness process. The hard part is preventing repeat tools, side effects and queued shell commands, so release notes cannot replace fault injection.

### Swarm training recipe (TRIAL)

Hugging Face published a TRL example where four agents share a Qwen3-0.6B policy and learn from group outcomes. The demo takes about five hours on two H200 GPUs at an estimated $50. Its number-ordering task makes it a runnable research baseline, not evidence of better production multi-agent systems.

## Open Source

### llm.asm (IGNORE)

This MIT project implements Qwen3-0.6B inference, a bare-metal runtime and a miniature GPT trainer in 17,252 lines of x86-64 assembly. Code and parity tests are useful for low-level study, but one small model, a custom weight format, author benchmarks and no production support do not justify product investment. Community heat is not treated as adoption evidence.

### llama.cpp AMD dashboard (TRIAL)

The dashboard exposes raw data, workflows and repetition counts for regression checks. Two systems cannot represent AMD's whole product line, and target-host quality and power still require local tests.

## Research

### Short GRH Lean proof (WATCH)

Researchers published a roughly 300,000-line readable edition and 76,000-line compact edition formalizing the Riemann Hypothesis and GRH for Dirichlet L-functions. Machine checking proves that the Lean project type-checks under specified axioms and dependencies. It does not settle whether the formal statement and modeling match the intended mathematics without expert review. The repository explicitly says no mathematician has read it through and no paper accompanies it.

### Agent over-edit study (WATCH)

Dynamic Relevance Analysis reverts patch units and reruns task tests to ask whether each change is necessary. Incomplete tests and LLM judges are not human code review, so the 11% result belongs to this evaluation setup rather than every real repository.

### Monitor attack-policy study (WATCH)

The study finds that attack-generation methods and optimization strength materially change one agent monitor's false-negative rate. Attacks are optimized on proxy monitors and transferred to a held-out GPT-5.4 target. Proxy-trajectory realism remains open, and no code is public.
