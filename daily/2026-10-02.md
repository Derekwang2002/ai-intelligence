# AI Intelligence - 2026-10-02

## Daily Executive Summary

本次补齐两天增量窗口，新增 6 个事件并更新 3 个既有事件。GPT-6.1 Sol 已开放 API，以 Sol 价格接近 Astra 能力；Gemini 4 Argon 展示 1M 输出 token，但仍是受控预览。OpenAI Agents API 把托管浏览器、来源审批与登录交接做成可恢复 contract。Olmo-core 3 开放万亿参数 MoE 训练栈，cua-speedrun 则提供可复现的 computer-use 速度与成本评测。Ollama 0.35.0 的稳定版上一轮被误判为预发布，本次按 late discovery 补录。没有证据充分的新趋势。

## Models

- **GPT-6.1 Sol（TRIAL）**：API、ChatGPT Work 与 Codex 已可用，标准价为每百万输入 token 2 美元、缓存输入 0.10 美元、输出 10 美元。OpenAI 报告它在 coding、computer use 和专业任务上接近 Astra。先按完成任务成本和事实错误率做路由实验。
- **Gemini 4 Argon（WATCH）**：Google 把单次输出上限提高到 1M token，并报告 DeepSWE v1.1 77.9%。目前只向可信网络防御团队开放，介绍价后还会翻倍；公开 API 前不值得投入迁移。

## Agent & AI Engineering

- **OpenAI Dots（WATCH）**：每个 Dot 都有独立云端电脑，可连接应用并跨对话继续工作。产品已开始向部分 Pro 与 Business Premium 用户开放，但后续计价和企业治理仍未定，先观察真实任务完成率、撤权与审计能力。
- **OpenAI Agents API Browser（TRIAL）**：浏览器在 OpenAI 托管环境运行，应用处理网站来源审批和登录字段，断线后可恢复同一 session。来源审批是“允许 agent 访问哪个网站”的显式门，难点在于登录凭据和副作用操作仍由应用兜底。
- **Ollama Decision Models（TRIAL，late discovery）**：`/v1/systemone` 返回选项、概率与分数。概率校准就是检查 80% 置信度的结果是否真的约有 80% 正确；不做这一步，路由阈值看起来精确，实际可能失真。

## Open Source

- **Olmo-core 3（TRIAL）**：Ai2 开放重写后的 MoE 训练栈，并在 512 张 B300 上跑到 1.2T 参数。专家并行把不同专家分散到 GPU；难点是路由不均和跨卡通信会吃掉稀疏计算的收益。公开峰值来自短时随机路由，团队应先测持续训练。

## Research

- **cua-speedrun（TRIAL）**：统一 VM、执行流水线与 agent 接口，比较 computer-use agent 的成功率、速度和成本。公开结果显示 reasoning effort 和环境延迟对总时间并非单调关系，代码与基础设施已公开，适合一天内做小规模复现。
- 其余 19 篇 arXiv cs.AI 新投稿因缺少公开产物、工程增量不足或偏离本项目范围而过滤或延期。

## Developer Tools

- **Claude Code 2.1.285/286（ADOPT，更新）**：新增 provider allowlist 与 WebFetch 总开关，并修复 session 恢复、Remote Control 撤权、MCP 凭据脱敏和计费统计。managed settings 因 OS 拒读时会告警后继续，部署方仍要做独立启动检查。
- **Gemini CLI 0.62.0（WATCH，更新）**：修复 OAuth refresh token 保留、PTY/ConPTY 清理和 ACP 权限事件顺序。稳定版修复值得升级；A2A server 仍无文档，不能作为生产依赖。

## Infrastructure

Olmo-core 3 是本周期最具体的基础设施变化。它把 DDP、张量并行、流水线并行与专家并行组合成开放实现，但 1.2T 结果不能直接外推到持续训练。

## Business & Policy

本窗口没有发现足以单独改变模型获取、芯片供应或开源格局的业务政策事件。OpenAI 的模型蒸馏攻击披露已阅读，当前更适合作为安全背景，而不是新的工程处置项。

## Trend Signals

- **趋势 #3：Coding agent 收敛为 multi-agent runtime**：GPT-6.1 Sol 的 beta 多 agent 委派与托管浏览器 Agents API 增加新生产控制面；维持 established / High。
- **趋势 #7：Agent runtime 把宽执行能力与后果控制拆成两层**：OpenAI 把来源审批和登录交给应用，Claude Code 在组织撤销策略后主动断开 Remote Control；维持 strengthening / Medium。
- 其余 5 个活跃趋势完成复核，状态和置信度不变。本周期没有发现证据充分的新趋势。
