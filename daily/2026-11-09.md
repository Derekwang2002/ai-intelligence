# AI Intelligence - 2026-11-09

## Daily Executive Summary

1. **Claude Code 的批准记录让真实密钥进入公开仓库。** Apiiro 在 1,994 个公开仓库中发现 2,539 个真实密钥；Anthropic 表示正在研究 auto mode 与基础密钥扫描，但本轮未核实到已发布修复。使用团队应立即检查 Claude 设置、transcript 与 Git 历史并轮换命中的密钥。
2. **Anthropic 将 agent memory 拆成上下文、笔记与离线复盘。** 厂商自测显示特定数据库、游戏与多 agent 任务受益，但样本小、任务窄且缺独立复现，暂不支持生产采用判断。
3. **Qwen Code 0.27.0 把并发子问题和仓库路由推入稳定版。** 多个子问题可并行等待且不混淆草稿；repository allowlist／blocklist 与编辑修复降低误操作面，但仍需独立恢复测试。
4. **LiteLLM 1.108.3 修复大型 MCP 结果与重复护栏。** 超过 1 MiB 的工具结果不再让 SSE 流无响应结束，post-call 护栏也不再重复调用；共享 gateway 应先做 canary。
5. **llama-modchip 的 284B CPU 推理主张暂不值得迁移。** 代码、二进制和权重已公开，但 64 GB 内存与每秒 9–11 token 的关键数字只有维护者自测，自定义格式的成本高于当前证据强度。

## Agent & AI Engineering

- **Anthropic Agent Memory**（WATCH）：研究把记忆拆成当前上下文、持久笔记和离线 dreaming。这里的 dreaming 不是模型训练，而是任务间隙重读经历、纠正旧笔记；难点是避免把错误经验写成长期事实。CL-Bench 与两个案例均为厂商自测，等待跨领域独立复现。
- **LiteLLM 1.108.3**（TRIAL）：修复 1.103.0 起超过 1 MiB 的 MCP 工具结果失败、模型级 post-call 护栏重复检查，以及 Bedrock `api_base` 为空时所有请求失败。SSE 是服务器持续向客户端推送事件的连接；大型工具结果跨越代理与流式边界后，错误容易表现成无响应，而不是明确的大小限制。
