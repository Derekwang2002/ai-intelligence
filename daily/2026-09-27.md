## Daily Executive Summary

- Microsoft 正把 Copilot 从聊天入口扩展为租户治理的执行工作区：Code 负责构建，Managed Runtime 负责沙箱与托管，Autopilot 负责持续运行。产品方向明确，但大部分能力仍在 Frontier 或 preview，采购范围与成熟度要分开看。
- GitHub 让 agentic autofix 读取并写回 Copilot Memory，把仓库特有的安全修复经验复用到 code review 与 cloud agent。记忆开始成为跨 agent 的共享状态，也带来过时经验和错误规则扩散的风险。
- Claude Code 与 Qwen Code 的更新继续把权限判断、故障恢复和执行证据下沉到 runtime。对企业团队来说，真正要验收的是 fail-closed、重启幂等与审计完整性，而不是发布说明中的功能数量。

## Agent & AI Engineering

- Microsoft Copilot 新增 Home、Code 与 Autopilot。Code 在沙箱中生成应用和自动化，Managed Runtime 可把执行放在客户租户内并由 IT 管理；Autopilot 拥有独立身份、记忆、计算机和工作区，可持续处理周期任务。
- 这些能力并未同时 GA：Managed Runtime 是 preview，Home 与 Code 先进入 Frontier，Autopilot 月底才扩到 private preview。试点应按组件分别验收，不要把整套叙事当作一个成熟产品。

## Developer Tools

- GitHub agentic autofix 现在会读取仓库已有的 Copilot Memory，并把成功修复方式写回，供后续 autofix、code review 与 cloud agent 使用。两项能力仍是 public preview，GitHub 尚未给出引入记忆后的修复接受率或误报数据。
- Claude Code 2.1.283 加入精确模型 allowlist 与 deniedModels，沙箱配置错误时默认拒绝，并阻止 Windows 命令删除根目录或 home。它还修复云会话重启后重复执行和后台 MCP 进度丢失。
- Qwen Code 0.24.6 增加 Hosted Runtime 基础、execute/status/cancel 协议、可故障转移的持久会话日志和未知执行核对。权限 hook 冲突时采用最严格结论，比“最后一个 hook 覆盖前面”更适合安全策略。
- Pydantic AI 2.51 增加 GPT-Live、realtime 上下文窗口占用，并通过缓存 agent graph 与减少 RunContext 复制降低开销。
- GitHub Copilot 周更为 JetBrains 增加 assisted approvals 与会话/文件同步回退；VS Code agent 可进入远端 Dev Container。它们属于现有 Copilot 产品线的实质更新，不重复创建事件。
