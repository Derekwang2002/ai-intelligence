# AI Intelligence - 2026-10-03

## Daily Executive Summary

本轮新增 7 个事件、更新 4 个已有事件。AstaBrief-8B、Clef 与 DeepSeek Harness 都提供可运行的公开材料；Argo-Bench 与 KaliBench 把 agent 评测推向可执行结果。工程侧，SGLang、Codex、Claude Code 与 GitHub Copilot 都在增强长期运行、可编程工作流和执行边界。

## Models

### AstaBrief-8B（TRIAL）

Ai2 开源基于 Qwen3-8B 的 AstaBrief-8B，可一次生成带引文的科研报告。模型、数据与本地 ScholarQA 流程都已公开，但质量数据主要来自作者评测，人评只有 14 个问题。建议用本地论文集做一天验证，重点看引文精确率、召回率、延迟，以及结论是否超过来源支持范围。

### PixelUMM（WATCH）

PixelUMM 公开 15.2B 参数 checkpoint 与代码，用同一个模型直接在像素空间处理图像和视频的理解与生成。所谓“像素空间统一模型”，就是不再把视觉编码器和生成用 VAE 分成两条流水线；难点在于同一个 backbone 既要准确读图，又要稳定生成。当前 checkpoint 为非商业许可，训练示例也不完整，先等待独立复现与商业许可。

### Clef（TRIAL）

Cloudflare 开源 Clef 与 Clef-flash，用有边界的类型化输出承担 agent 的路由和分类。它们兼容 Jev API，并同时提供开放权重与 Workers AI 托管。建议用真实路由样本比较延迟、校准、拒答率和成本，不要直接采信厂商榜单。

## Agent & AI Engineering

### GitHub Copilot（TRIAL，更新）

GitHub Copilot 公开预览桌面 computer use 与代码化动态工作流。前者可点击、输入、滚动和拖拽，并在接管前请求批准；后者支持串并行 agent、结构化结果、验证与 checkpoint。先在一次性 profile 中测试可逆任务，记录审批覆盖、误操作和恢复能力。

### Codex 0.160.0（ADOPT，更新）

Codex 新增可选的 Guardian 历史指令与 handoff 上下文召回，并改善 resume、reconnect、权限保留和 SQLite 卡顿恢复。启用前要专门测试错误历史是否会被重新带入，以及长任务恢复后权限边界是否保持不变。

### Claude Code 2.1.287（ADOPT，更新）

Claude Code 增加 Mods 与内置 observer side-agent，并修复危险 `rm`、symlink 写入、MCP 权限上限和协议切换后的重复调用。新 OTel `prompt_text` 字段可能带出 prompt 内容，升级前要确认遥测脱敏规则已覆盖。

### DeepSeek Harness（TRIAL）

DeepSeek Harness 以 MIT 开源并进入全球公开预览，提供桌面应用与本地 Web UI，所有能力都由插件组合。Agent teams、自动审批复核与定时任务仍是实验功能，仓库也警告会有破坏性兼容变化；只在隔离目录和一次性账户中试用。

## Open Source

本周期没有额外达到门槛的独立开源项目；AstaBrief、PixelUMM、KaliBench 与 Argo-Bench 的公开材料已分别归入模型和研究条目。

## Research

### KaliBench（TRIAL）

KaliBench 发布 8,504 组自然语言与 Kali 命令对，覆盖 1,642 个子工具，并公开 Docker 评测与训练方案。“不运行也可验证的奖励”指先把命令规范化，再对参数与组合做精确比较；难点在于别名和等价写法很多，同时又不能让模型直接接触真实攻击目标。先核对复用许可，再在隔离环境跑一天基线。

### Argo-Bench（TRIAL）

Argo-Bench 发布 210 个企业数据任务与含 75 亿行数据的合成仓库。它按最终申报和业务行动评分，而不是看 SQL 或解释是否像真的；难点在于 agent 必须从多张表还原隐藏业务状态，最后还要做对动作。建议先跑 5–10 个代表任务，比较结果正确率、成本与失败恢复。

## Developer Tools

Copilot、Codex 与 Claude Code 的更新都指向同一工程问题：agent 正在从单轮助手变成可编程、可恢复、能操作外部界面的运行时。新的能力同时扩大了审批、遥测和历史上下文污染的风险面。

## Infrastructure

### SGLang 0.5.21（TRIAL，更新）

SGLang 可在运行时切换 prefill 与 decode 角色，并默认启用 Rust 版统一 radix-tree 缓存核心。它还新增 decision 与 score API，并收紧 chat template 和反序列化边界。厂商性能数字需要在代表负载上复现，完成 breaking changes 清单后再上线。

## Business & Policy

### OpenAI API 弃用（WATCH）

OpenAI 为多组 Codex、通用与语音 API 模型设定 2027 年下线日期。现在不需要紧急迁移，但应立即盘点固定模型 ID，并在 2026 年底前排期质量、延迟、成本和语音体验回归。

## Trend Signals

本周期没有发现证据充分的新趋势。Copilot 动态工作流、Claude Mods 与 Codex Guardian 加强了既有“编码 agent 走向持久化运行时”信号；Argo-Bench 与 KaliBench 加强了结果导向评测信号，但两项同日研究还不足以单独建立趋势。
