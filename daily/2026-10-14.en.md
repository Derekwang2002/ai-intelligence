# AI Intelligence - 2026-10-14

## Daily Executive Summary

- **Named GPT-4 API snapshots now have a retirement date**: OpenAI will remove listed GPT-4o, GPT-4o mini and GPT-4.1 snapshots, including fine-tuned variants, on January 14, 2027 and recommends gpt-6-luna. The old snapshots remain callable; teams need an exact model-ID inventory rather than treating this as an immediate shutdown.
- **NVIDIA opens the full Run:ai platform**: The Apache-2.0 repository covers the control plane, scheduling, GPU fractioning, CLI and MCP server. Shared-GPU operators can inspect the whole stack, but the community build has no enterprise support and the NGC distribution carries separate NVIDIA terms.
- **LFM2.5-24B-A2B adds a local-agent option**: Liquid AI released a 24B-total MoE that activates about 2B parameters per token with broad day-one runtime support. Performance is vendor-reported, and entities earning at least $10 million annually need a separate license.
- **Claude Code 2.1.299 closes execution boundaries**: The stable release fixes sandbox writes into plugin directories, duplicate resumed execution, MCP startup before policy checks and third-party gateway-key leakage. Teams using managed policy or custom gateways should prioritize the upgrade and replay those paths.
- **Third Moment reports a 10,000-agent long-running system**: An OpenAI customer story says the firm runs up to 10,000 agents for 36 to 48 hours with outer models supervising stalled work. It is a rare architecture signal, but raw telemetry and independent validation are absent.

## Models

- **GPT-4 API snapshot retirement** (new / ADOPT): Affected snapshots remain callable; shutdown is January 14, 2027. The page gives a notification date but no reliable announcement hour, so migration must follow the exact listed model IDs and fine-tuned assets. [Official documentation](https://developers.openai.com/api/docs/deprecations)
- **LFM2.5-24B-A2B** (new / TRIAL): The 24B MoE activates about 2B parameters per token and ships base and post-trained weights. MoE calls only part of its expert network for each token; the hard part is that sparse activation does not eliminate memory, routing or license costs. [Release post](https://huggingface.co/blog/LiquidAI/lfm25-24b-a2b) · [Model card](https://huggingface.co/LiquidAI/LFM2.5-24B-A2B)
- **Gemini 4 Argon** (updated / TRIAL): The model moves from controlled preview to a paid API. The unified token budget means input and output share the one-million limit. Long runs can increase output, continuation, recovery and human-review cost together. [Official post](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon)
- **Grok 4.7** (new / TRIAL, late discovery): The public API supports text, images, tools and 500K context. Input and output rates double above 200K prompt tokens, and the US regional endpoint adds 10%. [Announcement](https://x.ai/news/grok-4-7) · [Documentation](https://docs.x.ai/developers/models/grok-4-7)
- **MiniCPM-V 4.7** (new / TRIAL, late discovery): The 35B-A3B and 1B weights use Apache-2.0. Expert lookahead preloads likely next-layer experts without changing actual routing. It reduces memory stalls but not storage, bandwidth, heat or battery cost. [Model card](https://huggingface.co/openbmb/MiniCPM-V-4.7-35B-A3B)
- **GLM-Legal** (new / WATCH): The GLM-5.3-Flash-based legal model is in an application-only beta. Harvey LAB all-pass is 19.2%, with some evaluation run by Vals. There are no public weights or generally available API, and AutoClaw support is still forthcoming. [Official post](https://z.ai/blog/glm-legal)

## Agent & AI Engineering

- **Third Moment Agent System** (new / WATCH): The customer reports up to 10,000 concurrent agents running for 36 to 48 hours. Outer supervisors terminate, retry or escalate stalled workers; concurrency is not effective throughput, and success, cost and recovery telemetry are absent. [Customer story](https://openai.com/index/third-moment-research/)
- **Claude Code 2.1.299** (updated / ADOPT): Adds idle compaction and runner drain while fixing sandbox, resumed-execution, MCP-policy and gateway-credential boundaries. [Stable release](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)
- **Gemini CLI 0.64.0** (updated / WATCH): Atomic file operations, state backup recovery, Ctrl+C cancellation, ACP usage updates and A2A settings migration reach stable; A2A still lacks a formal compatibility commitment. [Stable release](https://github.com/google-gemini/gemini-cli/releases/tag/v0.64.0)
- **ColGrep-Agent** (new / TRIAL): A local search model locates relevant code before passing smaller context to a coding agent. File F1 measures whether it found the right files; it does not show whether the final patch passes tests, so evaluation must remain end to end. [Release post](https://huggingface.co/blog/lightonai/colgrep-agent) · [Code](https://github.com/lightonai/next-plaid)

## Open Source

The complete Run:ai GPU orchestration stack is now open source; LFM2.5, DoubtLess and Hybrid Agent also ship downloadable weights or code. GitHub secret scanning now supports Anthropic service and user API keys in GA and blocks them by default with push protection. This is prevention, not evidence of a leak. [GitHub announcement](https://github.blog/changelog/2026-10-13-secret-scanning-blocks-anthropic-keys-by-default-adds-salesforce/)

ColGrep-Agent and StudentSim both provide runnable artifacts. No new stable general-purpose agent runtime cleared the bar; window candidates from Gemini CLI, Qwen Code, Codex and Ollama were nightlies, alphas or a release candidate.

The recall audit also records four high-attention but under-evidenced items as IGNORE: Janas has author-only performance comparisons; JEV-35B self-scores a public subset outside the official board; Agent37 has only a launch discussion; and the EmbeddingGemma 2 transcription demo provides no public training code or test set. Attention is recorded without turning it into a trial recommendation.

## Research

- **DoubtLess** (new / TRIAL): A small model reads the same chain of thought under brief and verbose instructions, and their logit difference steers the larger model. The authors report lower reasoning-token use, but there is no independent reproduction and the reference setup needs an 80 GB GPU. [Paper](https://arxiv.org/abs/2610.14745) · [Code](https://github.com/zhangshaowei1023/DoubtLess)
- **Hybrid Agent** (new / TRIAL): HybridLink switches between hidden latent reasoning and explicit tool interaction while carrying state across the boundary. Public 8B and 14B weights make it testable, but the 11-benchmark results are author-reported. [Paper](https://arxiv.org/abs/2610.14744) · [Code](https://github.com/togethercomputer/HybridAgent)
- **StudentSim** (new / TRIAL): The paper covers 60 learners across chess, second-language learning and mathematics. Held-out evaluation tests interactions the simulator did not see during training. Better fit on unseen records still does not mean real students learn better. [Research post](https://www.microsoft.com/en-us/research/blog/studentsim-a-framework-for-evaluating-ai-tutors-with-personalized-student-simulations/) · [Code](https://github.com/microsoft/StudentSim) · [Paper](https://arxiv.org/abs/2609.01591)
- **Encrypted capability backdoors** (new / WATCH, late discovery): The paper constructs digital lockers that encrypt hidden computation in weights and unlock it only under a secret trigger. It proves a worst-case limit for elicitation audits, but experiments use a small chemical-reaction proxy. [Paper](https://arxiv.org/abs/2610.13928)

## Developer Tools

GitHub's default Anthropic-key blocking is a low-cost ADOPT item. Claude Code and Gemini CLI stable releases respectively address execution boundaries and state integrity; upgrade testing should include real interruption, recovery and policy-failure cases.

ColGrep-Agent is the run's most actionable developer-tool signal. It searches repositories locally with read-only access and documents Codex, Claude Code and OpenCode integrations. The name says 2B while the model card reports roughly 3B parameters, so deployment should verify actual package and memory requirements.

## Infrastructure

- **NVIDIA Run:ai** (new / TRIAL, late discovery): The Apache-2.0 repository contains the control plane, cluster services, installer, CLI, MCP server and four existing components. Before replacing a supported platform, test tenant quotas, fractional-GPU isolation and upgrades in an isolated cluster. [Announcement](https://developer.nvidia.com/blog/nvidia-runai-is-now-open-source-as-part-of-nvidia-dsx-ai-factory-platform/) · [Code](https://github.com/dsx-ai-factory/run-ai)
- **Maia 300** (new / WATCH): Microsoft plans production deployments from 2027. A 96-accelerator rack has 27.6 TB HBM and 1.7 PB/s aggregate bandwidth. The 40% tokens-per-megawatt and up-to-seven-times rack-throughput figures are Microsoft claims. [Announcement](https://blogs.microsoft.com/blog/2026/10/12/microsoft-to-expand-azure-maia-system-to-multi-gigawatt-deployments/) · [Architecture](https://azure.microsoft.com/en-us/blog/deep-dive-into-azure-maia-300-architecture/)
