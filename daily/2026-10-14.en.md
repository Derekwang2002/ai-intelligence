# AI Intelligence - 2026-10-14

## Daily Executive Summary

- **Gemini 4 Argon becomes callable**: Google has opened Argon to paid-tier developers through AI Studio and the Gemini API. Input and output share a one-million-token budget. Introductory pricing of $2 per million input tokens and $10 output doubles after November 30. Long-horizon trials are now possible, but vendor benchmarks still need independent comparison.
- **MiniCPM-V 4.7 brings a 35B MoE to phones**: OpenBMB released Apache-2.0 weights and on-device deployment paths, reporting more than 13 tokens per second on an iPhone 17 Pro Max with 3 GB of memory. Speed, visual quality, thermals and battery use still need real-device validation.
- **Capability audits have a provable worst-case blind spot**: A NeurIPS paper encrypts arbitrary hidden computation in model weights and executes it only under a secret trigger. The small synthetic experiment does not show that deployed models are affected, but provenance and runtime monitoring cannot be replaced by one capability test.
- **ColGrep-Agent splits repository search into a local specialist**: LightOn released weights, code and integrations including Codex. Its study reports fewer tokens, but independent evidence for patch success, total latency or compute is absent.
- **Maia 300 remains a 2027 roadmap item**: Microsoft disclosed a 96-accelerator, 167 kW inference rack and claims 40% more tokens per megawatt than leading GPU systems. Production deployment starts in 2027, with no production telemetry or independent benchmark yet.

## Models

- **Gemini 4 Argon** (updated / TRIAL): The model moves from controlled preview to a paid API. The unified token budget means input and output share the one-million limit. Long runs can increase output, continuation, recovery and human-review cost together. [Official post](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon)
- **Grok 4.7** (new / TRIAL, late discovery): The public API supports text, images, tools and 500K context. Input and output rates double above 200K prompt tokens, and the US regional endpoint adds 10%. [Announcement](https://x.ai/news/grok-4-7) · [Documentation](https://docs.x.ai/developers/models/grok-4-7)
- **MiniCPM-V 4.7** (new / TRIAL, late discovery): The 35B-A3B and 1B weights use Apache-2.0. Expert lookahead preloads likely next-layer experts without changing actual routing. It reduces memory stalls but not storage, bandwidth, heat or battery cost. [Model card](https://huggingface.co/openbmb/MiniCPM-V-4.7-35B-A3B)
- **GLM-Legal** (new / WATCH): The GLM-5.3-Flash-based legal model is in an application-only beta. Harvey LAB all-pass is 19.2%, with some evaluation run by Vals. There are no public weights or generally available API, and AutoClaw support is still forthcoming. [Official post](https://z.ai/blog/glm-legal)

## Agent & AI Engineering

- **ColGrep-Agent** (new / TRIAL): A local search model locates relevant code before passing smaller context to a coding agent. File F1 measures whether it found the right files; it does not show whether the final patch passes tests, so evaluation must remain end to end. [Release post](https://huggingface.co/blog/lightonai/colgrep-agent) · [Code](https://github.com/lightonai/next-plaid)

## Open Source

ColGrep-Agent and StudentSim both provide runnable artifacts. No new stable general-purpose agent runtime cleared the bar; window candidates from Gemini CLI, Qwen Code, Codex and Ollama were nightlies, alphas or a release candidate.

The recall audit also records four high-attention but under-evidenced items as IGNORE: Janas has author-only performance comparisons; JEV-35B self-scores a public subset outside the official board; Agent37 has only a launch discussion; and the EmbeddingGemma 2 transcription demo provides no public training code or test set. Attention is recorded without turning it into a trial recommendation.

## Research

- **StudentSim** (new / TRIAL): The paper covers 60 learners across chess, second-language learning and mathematics. Held-out evaluation tests interactions the simulator did not see during training. Better fit on unseen records still does not mean real students learn better. [Research post](https://www.microsoft.com/en-us/research/blog/studentsim-a-framework-for-evaluating-ai-tutors-with-personalized-student-simulations/) · [Code](https://github.com/microsoft/StudentSim) · [Paper](https://arxiv.org/abs/2609.01591)
- **Encrypted capability backdoors** (new / WATCH, late discovery): The paper constructs digital lockers that encrypt hidden computation in weights and unlock it only under a secret trigger. It proves a worst-case limit for elicitation audits, but experiments use a small chemical-reaction proxy. [Paper](https://arxiv.org/abs/2610.13928)

## Developer Tools

ColGrep-Agent is the run's most actionable developer-tool signal. It searches repositories locally with read-only access and documents Codex, Claude Code and OpenCode integrations. The name says 2B while the model card reports roughly 3B parameters, so deployment should verify actual package and memory requirements.

The 40% tokens-per-megawatt and up-to-seven-times rack-throughput figures are Microsoft claims. [Announcement](https://blogs.microsoft.com/blog/2026/10/12/microsoft-to-expand-azure-maia-system-to-multi-gigawatt-deployments/) · [Architecture](https://azure.microsoft.com/en-us/blog/deep-dive-into-azure-maia-300-architecture/)
