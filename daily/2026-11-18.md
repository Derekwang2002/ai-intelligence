# AI Intelligence - 2026-11-18

## Daily Executive Summary

- **Hugging Face 将语言模型路由切换到 OpenRouter**：API 入口没变，但 provider、计费和数据路径变了；语言模型也不再支持自带 provider key，迁移前要重测边界。
- **vLLM 0.34 改变 KV 缓存与执行器默认值**：容量与恢复能力增强，但发布方提示 TPOT 可能回退 6%–18%，而且 ROCm 与 block size 兼容面发生变化。
- **TokenEconomizer 开放试用**：发布方在 277 个真实修 bug 任务上报告成本下降 18.4%–30.9%，但当前 agent 版本兼容性需要先验证。
- **Daybreak 获得 NATO 场景采用证据**：NATO CCDCOE 确认 Crossed Swords 中的 AI-agent 训练流，OpenAI 报告 NCIA 使用量最高达每月 3000 亿 token；效果仍主要由参与方报告。
- **SciResearch-Eval 暴露科研 agent 的过度自信**：多数 agent 自称 95% 的区间只有 20%–62% 包含真值，说明工具出错时仍可能给出很确定的错误答案。

## Models

Inkling 2 Small 新增 Plotly 独立测试：私有 DataAnalyticsBench 为 39/43、成本 1.81 美元，但每题约 13 次调用、5700 个输出 token。答案集不公开且经 OpenRouter 运行，建议维持 TRIAL。

## Agent & AI Engineering

TokenEconomizer 的“微技能”是从同一仓库过去会话中提炼的小段可复用经验；难点是经验一旦过期，节省 token 的同时也可能固化错误。Hugging Face 与 OpenRouter 的变化则需要重新核对路由、数据和账单边界。

## Open Source

Qwen Code 0.28 让 headless、TUI 与 subagent 共用 agent loop，并加入托管 worktree 与跨会话消息；一天内可用三个并行会话验证隔离和恢复。

Sage S2.1 Flash 也开放了 321B MIT 权重与科学 projector；发布方 benchmark 尚未独立复现，维持 TRIAL。

## Research

SciResearch-Eval 的“95% 区间覆盖”指：如果不确定性说得诚实，反复测试时真值应约有 95% 落在给出的区间里。多数 agent 远低于这个比例，说明它们在错误模拟器面前过度自信；公开代码可复跑，但 38 题规模仍小。

## Developer Tools

Claude Code 2.1.326 修复后台任务、配置写入和并行 MCP 的静默故障；Qwen Code 0.28 推进统一 agent loop 与托管 worktree。两者都应先回归无人值守流程。

## Infrastructure

vLLM 的可扩展 KV 缓存会按预热结果动态决定缓存容量；难点是“能装更多请求”不等于“每个 token 更快”，发布方明确提示 TPOT 可能回退。
