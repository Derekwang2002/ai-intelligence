# AI Intelligence - 2026-10-12

## Daily Executive Summary

当天两次增量扫描累计新增 10 条事件，更新 3 条既有事件。Open WebUI 与 OpenClaw 把 Skills、长任务、权限和恢复能力推进稳定版；Qwen Code 与 LiteLLM 继续加固多 agent 执行和 MCP 治理。第二次扫描补充了 Agent Standup、Littleguys、ESP32 iPhone Agent，并通过召回自检补录 QGIS 已生效的 AI 辅助代码贡献禁令。11 项到期复核均未出现足以改级的新证据。

## Models

- **新 · LightOnOCR-3**（TRIAL，late discovery）：LightOn 公开 0.8B、1B 和 4B 权重，覆盖 Markdown OCR、grounding、图片描述与图表表格。Grounding 是把识别结果绑定回页面坐标；难点是不只要读对字，还要保持版式和区域关系。厂商 benchmark 受分辨率和后处理影响，适合用自有版式文档验证。
- **新 · Carbon-A**（WATCH，late discovery）：Hugging Face Bio 公开 1.2B 模型、训练数据、技术报告和注释数据库。湿实验验证就是用真实生物样本检验计算预测；难点是已知物种上的初步支持不能自动外推到陌生物种。等待更广泛实验或独立复现。
- **新 · Iris-3B**（TRIAL，late discovery）：Sperid Labs 公开不经 VAE 的 3B 像素空间扩散模型，以及 depth 与 upscaler 微调权重。像素空间扩散直接生成像素，不先压进 latent；难点是保留纹理的潜力要和更高显存、延迟及作者自报评测一起衡量。

## Agent & AI Engineering

- **新 · ESP32 iPhone Agent**（WATCH）：项目通过 AirPlay 读取 iPhone 画面，再由 ESP32-S3 以 USB HID 发送点击与输入，不需要签名应用或越狱。USB HID 就是让开发板伪装成鼠标或键盘；难点是模型看到的位置必须稳定映射到真机坐标，并在误触后安全恢复。源码和安装说明已公开，但目前只有作者演示。
- **LiteLLM 1.105**（更新 / TRIAL）：稳定版加入 `litellm.agent()`、MCP protocol/capability 发现、更严格的调用者授权，并让护栏扫描检索回来的片段。Fail-closed 指授权或护栏状态不明时直接拒绝，而不是放行；难点是发现工具和允许执行是两层权限，必须分别测试。
- **Qwen Code 0.25.1**（更新 / TRIAL）：后台 Shell/Monitor、托管执行 receipt 与 checkpoint、session 化多 agent 已进稳定版，并修复 MCP server 名称冲突导致的权限串扰。发布说明仍是厂商自报，应做崩溃与重复副作用回归。

## Open Source

- **新 · Littleguys**（TRIAL，late discovery）：macOS 菜单栏应用把 OpenClaw、Claude Code、Codex、Gemini CLI 与 ACP agent 放进同一控制台，提供状态、审批和例行任务。0.1.1 已提供 Homebrew 与 DMG；它只是控制面，不会替不同 adapter 统一沙箱或凭据边界。
- **新 · Open WebUI 0.12.0**（TRIAL）：多文件 Skills 支持导入导出与版本历史，长原生工具链可在运行中压缩上下文；实验性 Tool Search 按需加载工具。稳定包已公开，但部分安全细节暂未披露。
- **新 · OpenClaw 2026.10.1**（TRIAL）：按权限搜索 Skills、可选 MCP Apps、加密外部备份和 Code Mode 状态持久化已进入稳定版。搜索可能只检查长指令前缀，旧 Workboard 数据也有中间迁移要求。
- **新 · Talorys**（TRIAL，late discovery）：项目把单用户个人 agent 部署到用户自己的 Cloudflare 账户，并公开可续跑安装器、备份导入、本地 mock 与自动测试。社区热度高，但单用户威胁模型、免费额度依赖和缺少独立审计限制了生产判断。

## Research

本次定向 gap review 补录 LightOnOCR-3 与 Carbon-A。两者都有公开 artifact，但性能或生物学有效性仍主要来自发布方，尚不足以形成新趋势。Iris-3B 的 7 天复核确认权重与代码仍公开，但没有独立 benchmark 或生产采用证据，维持 TRIAL。

## Developer Tools

- **新 · Agent Standup 1.27**（TRIAL）：VS Code、CLI 与 desktop viewer 可只读展示 Codex 和 Claude Code 会话中的命令、输出、文件改动、Web/MCP 调用与 token 记录。默认本地界面绑定 `127.0.0.1`，但部分可选功能会调用外部服务，导出视频也不能完整遮挡所有敏感内容。
- **GitHub Copilot for JetBrains**（更新 / TRIAL）：企业可为新 agent 对话设置默认模型，也可关闭 Copilot 与 Claude 的 MCP server 自动启动。最新版插件已发布；JetBrains 2025.1 不再受支持。页面只显示日期，精确发布时间来自 GitHub changelog RSS。

## Infrastructure

Open WebUI 的 Milvus 混合检索与 OpenClaw 的外部/R2 备份改善自托管运行面，但没有新的独立企业采用数据。

## Business & Policy

- **新 · QGIS AI 贡献政策**（WATCH，late discovery）：QGIS 已禁止向主仓库提交由 LLM、生成式 AI 或 coding agent 辅助产生的代码；违规代码可被回退，贡献权限也可能被暂停或撤销。该政策只适用于 QGIS 主仓库，尚无实际执行数据，也不能据此推断整个开源生态正在转向全面禁用 AI。

本周期没有达到例外门槛的重大综合新闻。

- **Qwen Code 0.25.1**（developer-tools / TRIAL）：后台任务、多 agent session 与恢复控制更完整，仍需独立故障测试。
- **LiteLLM 1.105**（ai-engineering / TRIAL）：MCP 发现、授权和检索护栏更完整，先做生产形态回归。
- **GitHub Copilot**（developer-tools / TRIAL）：JetBrains 增加默认模型与 MCP 启动控制，需验证重启和账号切换后的策略一致性。

- **新 · Agent Standup**（developer-tools / TRIAL）：Codex 会话可在本地复核；先验证 localhost 隔离、事件顺序和导出遮挡。
- **新 · QGIS AI 贡献政策**（business-policy / WATCH）：主仓库禁令已经生效；贡献者应立即遵守，行业影响则要等执行案例或其他大型项目跟进。
