## Agent & AI Engineering

### GitHub 预览 Copilot workload identity

GitHub 为 Copilot coding agent 增加 server-to-server authentication public preview，让后台服务不依赖个人 token。workload identity 是给机器工作负载的身份，不是某个开发者账号；难点在于租户隔离、撤销和审计是否能贯穿整条调用链。

### OpenHands 1.34 绑定 conversation 与 runtime

OpenHands 1.34 把 runtime 生命周期绑定到 conversation，并扩展恢复与清理路径。该版本位于 overlap，上一轮 manifest 未记录，因此按 late discovery 入库。建议在隔离仓库故障注入，确认恢复不会重复执行工具。

## Research

### Ai2 发布 Novelty Judge Bench

Novelty Judge Bench 公开代码、数据和基线，可用于研究 agent 的去重与新颖性检查。它的弱标签来自可观测关系而非完整专家标注，适合做筛查和比较，不适合单独裁决某个想法是否真正新颖。

### FeatureArc 研究演化特征中的继承缺陷

FeatureArc 研究发现，软件功能演化时会继承早期设计缺陷，单看最新版本容易漏掉根因。该论文在 overlap 内首次发现，按 late discovery 入库；它没有公开可直接采用的修复工具，因此维持 WATCH。

## Developer Tools

## Infrastructure

### Run:ai 加入显存硬约束 GPU 切分

NVIDIA 为 Run:ai 加入基于 CUDA 13.4 的显存硬约束，支持 request、limit 与 burst。故障域表示一次故障会一起影响哪些 workload；time-slicing 与 SM sharing 的故障域不同，配额正确并不自动代表隔离正确。
