- **New event: KV-cache retention breaks rollback consistency (arXiv 2608.15939, WATCH)** — "logical" rollback in agents is not a real rollback: retained KV cache in the serving session keeps the model attending to discarded content. Demonstrated on real paths (HF Transformers default cache-reuse, LangGraph time-travel) across 7 model families; 25 of 63 audited cells flipped by stale KV alone; fix is transaction-local cache rebuild at abort time. Complements yesterday's Agentic Transaction event (the storage layer silently violates atomicity/rollback semantics).

Strategic significance: the most-used AI-native editor is moving into GitHub's core territory (hosting + review + CI).
