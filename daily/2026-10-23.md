# AI Intelligence - 2026-10-23

## Daily Executive Summary

- **OpenAI 将审核直接转售模型访问的服务**：新版 Usage Policies 已公布，11 月 20 日生效；gateway、router 和模型市场要先判断自己是否属于“直接模型访问中介”。
- **Recursive 开放 Flint coding model 权重**：398 亿总参数、每 token 约激活 25 亿，Apache-2.0 权重已可通过 vLLM、SGLang 或 macOS Ollama 试跑；成绩仍是厂商自测。
- **Qwen Code 0.26.0 把故障恢复做成可测试契约**：重启后从持久 receipt 查证工具结果，无法证明时保留 UNKNOWN，不盲目重放有副作用的操作。
- **Claude Code 2.1.307 增加逐工具安全遥测**：每次工具调用都可记录审批、hook、sandbox 与安全阻断结果；MCP 断线后只重试只读或幂等工具。
- **OlmoEarth v1.3 开放全球 10 米嵌入**：权重、训练代码、数据和九年全球嵌入已公开，但采用自定义限制性许可，发布方 benchmark 尚无独立复现。

## Models

- **Recursive Flint**（新 / TRIAL）：MoE 的“每 token 激活参数”指每一步只调用总参数中的一部分，因此模型容量大但单步计算较小。固定任务试跑时仍要测 23 GB 本地包的显存、延迟和重复运行方差。[模型卡](https://huggingface.co/RecursiveSI/flint)
- **OlmoEarth v1.3**（新 / TRIAL）：提供 64D/128D、10 米分辨率的年度全球嵌入。许可限制军警监控与部分采掘用途，不能把“开放下载”直接等同于宽松开源。[发布说明](https://huggingface.co/blog/allenai/olmoearth-v1-3)
- **Kumo Relational**（新 / TRIAL）：模型用最多 1 万条历史行做上下文，对关系数据库任务直接分类或回归。开放权重采用 OpenMDW 1.1，性能仍需在自有 temporal split 上对比现有表格基线。[发布说明](https://huggingface.co/blog/nvidia/kumo-relational)

## Agent & AI Engineering

- **Claude Duet**（新 / WATCH）：主动 agent 研究预览已向美国 Pro/Max 用户开放候补名单，可在云端电脑上使用连接应用并主动发消息；与普通 Claude 共用额度，Team/Enterprise 尚不可用，官方也承认可能误读或漏看任务。[官方介绍](https://claude.com/resources/articles/claude-duet)
- **Qwen Code 0.26.0**（更新 / TRIAL）：UNKNOWN 不是失败，而是“现有证据不能证明工具到底完成没有”。保持 UNKNOWN 能避免重启后重复付款、发消息或写文件；应通过断线和 owner 转移故障注入验证。[发布说明](https://github.com/QwenLM/qwen-code/releases/tag/v0.26.0)
- **Flint 1.0**（新 / TRIAL，late discovery）：Microsoft Research 的 MIT 图表语言与 MCP server 把交互写成语义事件，再由编译器处理渲染依赖；仓库将 1.0 标为 10 月 19 日，本轮官方文章补充了交互设计。[项目仓库](https://github.com/microsoft/flint-chart)

## Open Source

## Research

- **KLS 猜想证明**（新 / WATCH，late discovery）：研究者用约 100 条 AI 搜索路径配合人工剪枝找到关键思路，同日有平行证明，随后出现 Lean 4 形式化。它证明了人机协作流程有效，不代表无人引导模型能独立完成同类证明。[研究说明](https://www.microsoft.com/en-us/research/blog/solving-a-31-year-old-grand-challenge-in-mathematics-the-kls-conjecture/)
- **Silent Cue Loss**（新 / WATCH）：76 份真实政策文档中，保留格式提示时 micro-F1 为 0.690，经 Docling 后为 0.150，纯文本为 0.075。“静默提示丢失”是文字还在，但高亮和颜色携带的政策含义在进入 RAG 前消失；论文没有公开代码。[论文](https://arxiv.org/abs/2610.30026)
- 11 项到期复核完成：3 项 30 天复核与 8 项 7 天复核均未出现足以改变处置的独立证据。
