# AI Intelligence - 2026-11-19

## Daily Executive Summary

1. **GPT-6.2 Astra and Sol are live.** OpenAI shipped both models in ChatGPT Work, Codex and the API. Astra input and output prices fall 20%, and cached input falls 60%. Both offer 1.05M-token context, but inputs above 272K enter a higher pricing tier; vendor benchmarks and high-capability safety ratings still need local validation. [Source](https://openai.com/index/introducing-gpt-6-2-astra-sol/)
2. **MAI Code 2 enters Copilot while Flash remains a limited preview.** Microsoft’s price-performance figures use maximum effort, an internal harness and a 50% promotional price. That supports a real-repository POC, not an independent equivalence claim. [Source](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)
3. **BIS is preparing to license some remote access to advanced compute.** The prepublication IFR covers significant compute supplied to Macau or Country Group D:5 entities and adds five destination controls. The PDF still has Federal Register date placeholders, so it cannot be described as effective yet. [Source](https://www.bis.gov/media/documents/rin-0694-ak50.pdf)
4. **Merged work did not clearly rise with coding benchmarks.** A natural experiment covered 297 affected developers and 8,908 controls, with intervals crossing zero. Teams should add PR cycle time, rework and defects to model selection, but the study does not prove stronger models save no time or quality. [Source](https://arxiv.org/abs/2611.23216)
5. **Agent Substrate is more mature than the prior record showed.** An earlier Google primary source confirms 1.0 was already GA on GKE, not only later accepted into CNCF Sandbox. Restore, density and throughput figures remain publisher-reported. [Source](https://cloud.google.com/blog/products/containers-kubernetes/open-infrastructure-for-autonomous-agents-comes-to-cncf)

## Models

### GPT-6.2 Astra / Sol

Both are available in ChatGPT Work, Codex and the API; Enterprise and Edu require admin enablement. Astra costs $8/$0.40/$40 per million input/cached/output tokens, while Sol costs $2/$0.10/$10. A **long-context pricing tier** means unit prices jump above a threshold rather than scaling at the original rate; here that threshold is 272K input tokens.

### MAI Code 2 / Flash

MAI Code 2 is live in GitHub Copilot, while Flash is limited to a Foundry preview. Microsoft averages several benchmarks; three were run internally with MSBench and Copilot CLI without subagents. Planned ecosystem integrations are not live yet.

### Rumble 2 Flash

Reson8 released a 0.5B Apache-2.0 multilingual ASR model with native Transformers and vLLM support. The 7,000 RTFx and error rates are publisher-reported; test real audio for WER, tail latency and domain terms. [Source](https://huggingface.co/blog/rumble-2-flash)

### Microsoft Decision 1.1

Decision 1.1 is GA with multimodal input. Microsoft reports 4,000+ customers and up to 50x speed and 79x cost advantages. Closed-choice decisions do not replace open-ended reasoning. [Source](https://commandline.microsoft.com/microsoft-decision-model-ga/)

### HY4 Flash open weights

Tencent released HY4 Flash instruction and base weights with vLLM, SGLang, quantization and fine-tuning assets, replacing the prior “weights not released” judgment. The roughly 220B-total, 12B-active model uses the custom Tencent Hy License, so license and hardware review come first. [Source](https://huggingface.co/tencent/Hy4-flash)

### Qwen3.8 pi adapter

harness-hub released an Apache-2.0 LoRA for Qwen3.8-27B and the pi coding agent. The publisher reports matching base-model xhigh accuracy with about 4.5x fewer generated tokens and thinking disabled. Checkpoint selection saw part of the evaluation, so reproduce on real repositories. [Source](https://huggingface.co/harness-hub/Qwen3.8-27B-pi-adapted)

### Apple FastFrames

FastFrames released 1.3B and 14B video-generation models with a paper. Publisher results reach 36–45 ms per frame on B200-class hardware, within its interactive range. Weights use the Apple AMLR license; hardware and independent quality remain adoption constraints. [Source](https://arxiv.org/abs/2611.23226)

## Agent & AI Engineering

### Agent Substrate 1.0

Google’s November 5 primary source confirms GKE GA and deployment on other Kubernetes environments. Checkpoint restore saves agent memory and filesystems while idle, then restores sessions; the hard part is combining speed with state consistency and tenant isolation.

### LiteLLM 1.108.11 LTS

The LTS patch fixes dropped Bedrock guardrail fields, upstream generation continuing after client aborts, and truncated Gemini tool arguments. These affect safety behavior, hidden cost and tool reliability. [Source](https://github.com/BerriAI/litellm/releases/tag/v1.108.11)

### FrontierHarness Eval v1.1

Runta and Baseten compared 22 harness configurations and five open models in 27,280 runs. Task cost differed 1.8 to 5 times across harnesses with the model fixed, and the median harness moved 11 cost ranks when the model changed. **Cost per pass** divides average task cost by pass rate so a cheap but failure-prone pairing does not automatically win. The benchmark is publisher-run and covers 62 terminal tasks. [Source](https://runta.com/blog/introducing-frontierharness-eval-v1-1/)

### KORMo-Web-11B

KAIST MLP Lab released a Korean-English multimodal web agent trained from its own foundation model, with Apache-2.0 weights, a browser harness, Chrome extension and vLLM path. It reports 30.1% Korean Online-Mind2Web success, but models used different prompts and action formats. [Source](https://huggingface.co/KORMo-VL/KORMo-Web-11B)

### PostHog decision-model gates

PostHog documents a production pipeline where two narrow checks let 98.7% of session summaries skip a Gemini rewrite, plus decision-model routing and reranking. The core practice is calibrating thresholds per error cost, task and model, with replacements first running in shadow mode. [Source](https://newsletter.posthog.com/p/decision-models)

## Research

### Higher-Scoring Coding Models Did Not Get More Work Done

A **natural experiment** uses a real-world change researchers did not assign. Because switching was not random, the paper uses controls and difference-in-differences to reduce bias. Intervals still cross zero, and merge counts omit quality and time saved.
