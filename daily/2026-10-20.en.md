## Daily Executive Summary

- **MiniMax launches the low-cost M3.1 Flash API**: Input/output cost $0.15/$0.60 per million tokens; weights are not released and performance remains vendor-reported.
- **SGLang 0.5.22 fixes recurrent-state correctness**: Speculative decoding plus structured output could resume the wrong Mamba state; the release also expands loading and disaggregated serving.
- **Qwen Code 0.25.3 isolates read-only child agents**: Frozen workspaces reduce write authority while managed sessions, persistent workspaces and recovery keep expanding.

## Models

- **MiniMax M3.1 Flash** (new / TRIAL): The API, M Plan and MiniMax Code are live at $0.15 input, $0.60 output and $0.015 cached input per million tokens. MiniMax reports median output above 170 tokens/s and 73.7% on DeepSWE v1.1; weights and independent reproduction are still missing. [Official launch](https://www.minimax.io/blog/minimax-m31f)
- **DeepSeek V4.1 Flash 1017** (updated / TRIAL): Artificial Analysis independently measures hosted Max at Intelligence Index 45, $0.26 per task, 224.7 output tokens/s and 1.12-second TTFT, while the full index produced 210M output tokens. Speed and price now have external support, but verbosity can erase the unit-price advantage and this is not a reproduction of the downloadable weights. [Independent analysis](https://artificialanalysis.ai/models/deepseek-v4-1-flash-1017)

## Agent & AI Engineering

- **Qwen Code 0.25.3** (updated / TRIAL): A hosted parent can start a read-only child that sees a frozen workspace but cannot change files or run commands. Snapshot isolation gives a subtask a fixed copy; the hard part is ensuring that copy has not become stale while the parent keeps changing, so freshness and merge boundaries still need tests. [Release notes](https://github.com/QwenLM/qwen-code/releases/tag/v0.25.3)

## Developer Tools

- **Qwen Code 0.25.3** also adds pinned Skills/MCP/Hook catalogs, SSH and native macOS runtimes, Kubernetes workspaces that keep files across sessions, bounded retries and cancellation recovery. The wider surface makes restart and disconnect fault injection more important than happy-path testing.

## Infrastructure

- **SGLang 0.5.22** (updated / TRIAL): The project claims 10× faster InstantTensor loading and up to 27% more throughput from prefill/decode disaggregation, and now requires Python 3.11. Prefill/decode disaggregation assigns long-prompt ingestion and token-by-token generation to different workers; KV and state handoff create new correctness and tail-latency risks. [Release notes](https://github.com/sgl-project/sglang/releases/tag/v0.5.22)
- **TorchNeuron** (new / WATCH): AWS announced a native PyTorch backend for Trainium2/3 and says Hugging Face tools and TorchTitan already integrate. A backend is the adapter that lets PyTorch send the same operator set to different hardware; real operator coverage and performance cannot be checked until the repository opens on October 20. [Official announcement](https://www.aboutamazon.com/news/innovation-at-amazon/torchneuron-pytorch-aws-trainium-chips-ai)

## Business & Policy

- **DeepSeek federal civilian exclusion order** (new / WATCH): The signed DHS text covers DeepSeek, affiliates and third-party products or services developed using DeepSeek implementations. The original date is July 24 and exclusion/removal was immediate on issuance; agencies may seek exceptions within 60 days. It applies to U.S. federal civilian executive agencies and is not a general ban on all U.S. users. [Government filing](https://public-inspection.federalregister.gov/2026-21447.pdf)
