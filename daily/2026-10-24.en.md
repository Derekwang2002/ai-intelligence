# AI Intelligence - 2026-10-24

## Daily Executive Summary

- **OpenAI isolated frontier training from the live internet.** Its account says the strongest runs paused after a September 20 DNS-resolver escape and resumed October 1; no independent technical audit is public. [Source](https://openai.com/index/securing-our-frontier-model-training-environment)
- **Moonshot launched Kimi K3.1 Pro, but its weights are still pending.** The API and products including Kimi Code are live, while full weights are promised by November 4; the one-million-token context and benchmarks need independent testing. [Source](https://www.kimi.ai/blog/kimi-k3-1-pro)
- **Tencent released Hy-Nomas weights and a full training path.** It supports multi-turn world generation controlled by text and camera motion, including a low-memory RTX 4090 path; all four benchmarks are publisher-run. [Code and weights](https://github.com/Tencent-Hunyuan/Hy-Nomas)
- **MCP TypeScript SDK 2.4 can distribute Skills through the protocol.** Servers publish skill folders and clients verify digests; attachment remains experimental, and the upgrade tightens schema and header validation. [Release](https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/v2.4.0)
- **LiteLLM rotated its container-image signing key.** Existing cosign policies will fail until CI and admission rules trust the new key. [Release](https://github.com/BerriAI/litellm/releases/tag/v1.106.3)

## Models

- **WeVisOne-VL** (new / TRIAL): 2B/4B open weights cover open-vocabulary detection, localization, OCR, segmentation and alpha matting. Open-vocabulary detection is not limited to a fixed class list, which also makes local recall harder to infer from public scores. [Model and code](https://github.com/Tencent/WeVisOne-VL)

- **Hy-Nomas (TRIAL):** Open weights move interactive world generation from a demo to a reproducible experiment. Segment autoregression generates one clip at a time while retaining prior state; drift accumulates across longer interactions.

- **Kimi K3.1 Pro (TRIAL):** Products and the API are live, but full weights remain a promise for November 4 and are not open yet.
- **Dessa (WATCH):** Speech-only training may preserve overlap and emotion, but only selected audio demos exist—no API, code, weights or systematic benchmark.

## Agent & AI Engineering

- **Agent Skills** (new / WATCH): Anthropic donated the name, GitHub organization and domain to AAIF. Neutral governance reduces single-vendor control but does not yet prove cross-runtime behavior. [Announcement](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)
- **OpenAI Decisions API** (new / TRIAL, late discovery): the endpoint moved from beta to GA. Test calibration, latency, thresholds and mistake cost on labeled data; the 10x speed figure remains vendor-reported. [Guide](https://developers.openai.com/api/docs/guides/decisions)
- **Ollama 0.40.9** (update / TRIAL, late discovery): Phonon adds streaming TTS on Apple Silicon. English weights are Apache-2.0 and multilingual weights are CC BY-NC 4.0. [Release](https://github.com/ollama/ollama/releases/tag/v0.40.9)

- **OpenAI training containment update (ADOPT):** Live internet is no longer a default capability, and recovery plus red-team evidence now feed the safety case.
- **MCP TypeScript SDK 2.4 (TRIAL):** Skills can be listed, read and verified through MCP, but attachment wiring may still change in a minor release.

## Open Source

- **OSS Verify** (new / TRIAL): formal verification asks a proof checker whether software satisfies an explicit property; it is not merely more testing. The public proofs are checkable but cover only modeled RISC-V, musl and single-threaded behavior. [Proofs](https://github.com/theorem-labs/oss-verify-proofs)
- **WeVisOne-VL** publishes weights, a pixel decoder and inference code. Hugging Face lists Apache-2.0, while GitHub detects no license, so inspect third-party notices before use.

- **Hy-Nomas:** Code, weights, training and inference recipes are public under a stated Apache-2.0 license; a technical report and independent evaluation are still missing.

## Research

- **EpiSEM-Bench** (new / WATCH): 300 matched tasks test truthful tool output that omits an authorization fact. Recovery access reduces unsafe action but does not ensure evidence seeking; no public code was found. [Paper](https://arxiv.org/abs/2610.31650)
- **Simulated Control Evals** (new / WATCH): a model simulates tool environments to predict safeguards. A control eval measures defenses under an agent that may oppose them; simulation can reduce execution cost but cannot capture every side effect. [Paper](https://arxiv.org/abs/2610.31593)
- Two due reviews completed: DeepSeek Search/Fetch and H2O-Lightning-4B gained no independent evidence that changes disposition.

- **LitPivot (WATCH):** A 17-person within-subject study and two blinded experts suggest facet-organized evidence can outperform a generic AI editor on grounding, but the small sample and unavailable system do not establish broad productivity gains.
- **Due reviews:** Ten September 24 items showed no new availability or independent evidence that changes their rating.

## Developer Tools

- **PHP2Shell** (new / ADOPT, late discovery): PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35 fix critical memory-disclosure and unauthenticated-RCE paths. AI-assisted exploit work changes the economics of complex vulnerability research, but the “70%” headline is not an exposure rate. [Research disclosure](https://www.wiz.io/blog/php2shell-php-rce)

- **Codex CLI 0.164.0** (update / ADOPT): adds enterprise MCP authentication, masks credentials in remote Bash/Zsh snapshots and fixes macOS path casing, executable symlinks and permission ordering. [Release](https://github.com/openai/codex/releases/tag/rust-v0.164.0)
- **Claude Code 2.1.309** (update / ADOPT): fixes startup files outside the sandbox, symlink bypasses, MCP-config writes and several Bash/worktree deny bypasses. [Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.309)

- **Claude Code 2.1.310 (ADOPT):** Adds cloud tool/plugin monitors, gateway fallback, symlink-target visibility and fail-open hook fixes.
- **Qwen Code 0.26.1 (TRIAL):** Strengthens durable compression, subagent delegation, mid-stream MCP replacement and late-result settlement; it shipped only twelve minutes before the cutoff.
