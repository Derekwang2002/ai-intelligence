## Agent & AI Engineering

### WebHarbor

WebHarbor 把 153 个常见网站做成可本地运行、可重置的 Docker 镜像，并配套 3,518 个 GUI agent 任务、训练/held-out 拆分与 WebHarbor-4B checkpoint。所谓网站镜像，是把页面、数据库和登录后流程固定在本地环境；难点不是把网页截图做得像，而是让购物车、账号、grader 和重置后的状态都一致。作者报告的跨 benchmark 成绩尚未独立复现，镜像许可与出网隔离也要单独核对。

### Qwen Code 0.26.6

Web Shell 现在展示审批、错误、运行中任务，以及按模型统计的成功率、输出速度与首 token 延迟。托管恢复会在缺少 child ledger 证据时保持未知，而不是补写一段看似完整的历史；MCP 工具重名、OAuth 锁归属和审批文本隐藏字符也得到修复。unified loop 与托管部署仍属实验功能，维持 TRIAL。

## Open Source

### Ollama 0.40.14

OpenAI-compatible endpoint 在客户端省略 temperature 或 top_p 时，不再覆盖模型内置默认值。Responses API、压缩搜索响应和 Codex/Claude 启动路径也有修复。默认采样参数会改变输出分布，升级前应用固定 prompt 回归。

## Research

### MCP Tool Poisoning

论文在 12 个框架、18 个模型和 45 种攻击场景上运行 9,720 个真实工具执行组合。作者报告 22.9% 攻击成功，255 个组合通过 canary 回执确认 secret exfiltration。Tool poisoning 是把恶意指令藏进工具描述、schema 或响应；难点在于这些内容看起来像配置，却会进入模型上下文并影响后续工具调用。研究仍缺本轮可定位的公开代码仓库和独立复现，因此不把论文数字当成所有部署的固定风险率。

## Developer Tools

### Claude Code 2.1.317

Agent SDK hook 新增失败即阻断；web 或 shell 工具准备发送账户邮箱时会先询问；云端定时任务若拿到未请求的 connector 也会警告。gateway 可按开发者、日期和 IdP group 汇总成本。磁盘写满、runner 重启、MCP 状态、压缩与代理故障的恢复路径也有修复。

## Infrastructure

### SGLang 0.5.23

稳定版新增 TPU7x、Paged Experts、量化 MoE LoRA 与文件级 L3 前缀缓存。Paged Experts 是把当前需要的专家留在 GPU，其余按需换入；难点是换入开销、命中率和真实并发会决定它是否真的比 CPU offload 快。项目报告多款 MoE 的首 token 延迟降低 30%–58%，但应以固定 trace 复现正确率、吞吐与显存。

### NVIDIA Attribution / Recovery

Attribution 把 workload 相关日志、指标与 scheduler 状态整理成可复现诊断，Recovery 再决定隔离节点、重启或停止。默认 monitor mode 只给建议并记录审计轨迹。当前支持 Slurm，Kubernetes 还在 roadmap；生产规模和平均延迟由 NVIDIA 自报，误归因可能损失健康算力，先试跑再允许自动动作。
