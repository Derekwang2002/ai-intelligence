# AI Intelligence - 2026-11-12

## Daily Executive Summary

1. **Notion says the Fireworks AI incident exposed some customer chat transcripts.** Fewer than 1% of workspaces were affected; contractual zero retention did not prevent retained data from entering incident scope.
2. **Microsoft shows that a few weight edits can plant a triggered agent backdoor.** Lazarus code is public, but attacks use recorded contexts and the detector covers the same edit family.
3. **Mirage packs description, OCR, detection and segmentation into a 22 MB local model.** Weights and source are public; edge latency and quality remain publisher-reported.
4. **BotPsy-0.8B brings tool use to an on-device model size.** Apache 2.0 weights and GGUF files are downloadable; publisher scores lack independent reproduction, and open search and memory remain weak.
5. **Sentence Transformers publishes training for 4x token pooling.** The author reports retaining 97.8% of unpooled retrieval quality; real RAG corpora still need testing.

## Models

### BotPsy-0.8B

The 0.8B tool-use model provides public BF16 and GGUF weights for quick on-device tests. Publisher scores are strong for its size, but BrowseComp-Plus is only 4.5, so tool-call syntax should not be confused with open-ended research ability.

### Qwen4-Max-Preview

A 1M context, multimodal inputs, tools and structured output are testable through Token Plan. The preview ends November 25, with no open weights or pay-as-you-go price.

## Agent & AI Engineering

### Notion / Fireworks security incident

Notion says the exposed transcripts came through its Insights analysis path and tells affected customers to treat the data as exposed. Fireworks says general Inference, Training SDK and Nexus are ZDR by default and showed no impact; that does not negate Notion's disclosure that specific endpoints retained data.

### Mirage

Mirage uses one 51.3M-parameter model to return scenes, boxes, masks, OCR, relations and structured choices. Public artifacts are directly testable, but example detection confidence is modest, so size and latency are not sufficient acceptance evidence.


### Token Pooling

Multi-vector retrieval stores many token vectors per document. Token pooling merges similar vectors to shrink the index; the hard part is preserving fine-grained matches, so pooling-aware training exposes the encoder to that information loss during training.

## Open Source

BotPsy weights, Lazarus research code and Sentence Transformers training and evaluation scripts are public. Downloads and publisher benchmarks were not treated as independent adoption evidence.

## Research

### Lazarus

Researchers tested a few neuron edits across three models and three agent scaffolds. Dormant neurons are internal channels that rarely activate; the risk is that an attacker can repurpose them to emit a payload only on a trigger while ordinary benchmarks remain normal.
