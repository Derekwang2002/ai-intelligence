## Models

- **新 · Qwen-Image-2.1-Turbo**（TRIAL）：公开 7B 权重用八个去噪步骤完成文生图和编辑，但没有给出与基础版的对比 benchmark。去噪步骤是模型逐步把噪声还原成图像的次数；难点是步数变少会提速，也可能损失文字渲染和编辑保真。应在固定样本上直接比较延迟、显存与质量。
- **新 · Youtu-Parsing-Omni**（TRIAL）：5B 模型把文档、图表、几何题、音频与视频统一解析为结构化 JSON。Omni parsing 指用同一模型处理不同模态，而不是为每类输入单独路由；难点是厂商 benchmark 的评测代码仍为 TBD，必须用自有混合样本复核。

## Agent & AI Engineering

- **新 · SciExam for ENSO**（TRIAL）：它不给 agent 一个已知答案，而是让 agent 根据真实观测构建气候模型，再用隐藏测试检查统计特征、未观测变量与留出年份。hidden grader 是 agent 看不到的验收程序；难点在于它既要防止按答案投机，又要证明留出数据没有泄漏。公开 Docker、grader 与样例足以在一天内复核一个 run。
- **新 · RunningTab**（WATCH）：它把任务要求、带来源摘录和未打开文件候选写进 runtime 维护的 tab，并在义务未完成时拦住 finish。环境侧记录就是由执行环境保存状态，而不是让模型靠上下文记忆；难点是论文尚未公开代码，暂时无法验证额外状态是否真能降低遗漏率。
- **新 · OnTrack**（WATCH）：它持续比较当前轨迹与成功轨迹的结构，作者报告约每步 1 毫秒，并减少约 18% 的失败计算。中止实验只有六次触发且没有公开代码，现阶段只适合跟踪。

## Open Source

- ExpDis 公开 Apache-2.0 代码与 checkpoint；SciExam 公开 MIT 代码、Docker 与 grader。两者都有可运行产物，但当前结果仍主要来自作者报告。
- **新 · Whistle**（TRIAL）：16.9 MB 的 Apache-2.0 模型在 CPU 上提供七语种转写、词级时间戳和语音嵌入。作者 benchmark 尚需复核，但公开 runtime 足以在目标设备测试 WER、延迟、内存和温升。
- **新 · GLM-5.3 E224**（IGNORE）：社区为双 DGX Spark 制作了 141 GiB 的非官方裁剪量化版，但准确率和吞吐只在 B200 上测过。目标硬件结论仍是估算，高热度不足以支撑投入。

## Research

- **新 · ExpDis**（TRIAL）：它用带新颖性奖励的 explorer 寻找不同解法，再把正确轨迹蒸馏给独立 student。这样做是为了避免稀疏奖励把生产策略带偏。`pass@k` 看的是采样 k 次后至少答对一次的概率；难点是它会同时受正确率和解法多样性影响，不能只看单次 accuracy。
- SciExam 把科研 agent 的验收从「贴合已知答案」推进到「通过未见过的科学测试」。RunningTab 则提出把完成度状态放到模型上下文之外。两者都是独立信号，但还不足以形成新趋势。
- **OpenAI 数学成果**（更新 / WATCH）：一个符号错误使一项构造和两篇依赖论文失效，三篇稿件被撤回；另有 14 篇修订、13 篇更新依赖引用。Lean 覆盖升至 300/719，但约 42% 的覆盖也说明形式化验证远未完成。
- **新 · Caught in the Act**（TRIAL）：白盒激活探针在 SHADE-Arena 上报告 98.8% AUC，并能发现文本本身看不出的隐藏目标。激活探针读取模型内部状态而不是只读输出；难点是它需要白盒访问，而且跨模型迁移与误报仍要复测。FIBS 数据、推理代码和探针权重已公开。
- **新 · METR 时间跨度复核**（WATCH）：统计模型显示，从 3 分钟跨到 30 分钟与从 30 分钟跨到 5 小时虽然同为十倍增长，难度并不相等。不要只用一条指数曲线外推自动化进度；等待公开复算包与 METR 回应。

## Developer Tools

- **Claude Code 2.1.294**（更新 / ADOPT）：修复以自然语言写成的 prompt 与 agent hook 可能放行本应阻止的命令，并减少 Stop/SubagentStop hook 过早结束任务。升级后应回放 allow/block 两组用例。
- **LiteLLM 1.104.2**（更新 / TRIAL）：稳定版加入 OpenAI 兼容的 `/v1/decisions`、`/v1/systemone` 与 Decisions provider。先在预生产检查 schema、认证、fallback 和成本归属。
- **新 · Docker Agent 1.149.0**（TRIAL）：Apache-2.0 runtime 用 YAML 定义多 agent，支持 MCP、RAG、evaluator 与 OCI 分发。新版本加入 GitHub skill 加载和 OpenAI Decisions evaluator；适合用现有双 agent 流程做一天对照。
- **Claude Code 2.1.295**（更新 / ADOPT）：command 与 HTTP hook 在配置 `onFailure: block` 时会默认拒绝；gateway 又增加每上游模型 allowlist、TTFB 限制与 request ID。升级后应回放 hook 失败、模型拒绝和 MCP 重连。
- **Codex 0.162.0**（更新 / ADOPT）：稳定版启用托管 worktree 创建、任务置顶和排序式工具发现，并修复跨平台沙箱与 CRLF 保留。并行 coding 团队应回归 worktree 所有权和策略边界。

## Infrastructure

- **新 · Ai2 GPU 调度**（WATCH）：Ai2 用预算加权的分层公平共享替代静态优先级队列。30 天生产数据称兑现 98% 应分配 GPU 小时、保持 98% 利用率，并把 debug 任务 P90 排队从两小时降到 30 秒。实现未公开，先复用指标和最短运行时间契约，不直接照搬 scheduler。
