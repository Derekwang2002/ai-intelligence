## Agent & AI Engineering

- **新 · SciExam for ENSO**（TRIAL）：它不给 agent 一个已知答案，而是让 agent 根据真实观测构建气候模型，再用隐藏测试检查统计特征、未观测变量与留出年份。hidden grader 是 agent 看不到的验收程序；难点在于它既要防止按答案投机，又要证明留出数据没有泄漏。公开 Docker、grader 与样例足以在一天内复核一个 run。
- **新 · RunningTab**（WATCH）：它把任务要求、带来源摘录和未打开文件候选写进 runtime 维护的 tab，并在义务未完成时拦住 finish。环境侧记录就是由执行环境保存状态，而不是让模型靠上下文记忆；难点是论文尚未公开代码，暂时无法验证额外状态是否真能降低遗漏率。

## Open Source

- ExpDis 公开 Apache-2.0 代码与 checkpoint；SciExam 公开 MIT 代码、Docker 与 grader。两者都有可运行产物，但当前结果仍主要来自作者报告。
- **新 · Whistle**（TRIAL）：16.9 MB 的 Apache-2.0 模型在 CPU 上提供七语种转写、词级时间戳和语音嵌入。作者 benchmark 尚需复核，但公开 runtime 足以在目标设备测试 WER、延迟、内存和温升。
- **新 · GLM-5.3 E224**（IGNORE）：社区为双 DGX Spark 制作了 141 GiB 的非官方裁剪量化版，但准确率和吞吐只在 B200 上测过。目标硬件结论仍是估算，高热度不足以支撑投入。

## Research

- **新 · ExpDis**（TRIAL）：它用带新颖性奖励的 explorer 寻找不同解法，再把正确轨迹蒸馏给独立 student。这样做是为了避免稀疏奖励把生产策略带偏。`pass@k` 看的是采样 k 次后至少答对一次的概率；难点是它会同时受正确率和解法多样性影响，不能只看单次 accuracy。
- SciExam 把科研 agent 的验收从「贴合已知答案」推进到「通过未见过的科学测试」。RunningTab 则提出把完成度状态放到模型上下文之外。两者都是独立信号，但还不足以形成新趋势。
- **OpenAI 数学成果**（更新 / WATCH）：一个符号错误使一项构造和两篇依赖论文失效，三篇稿件被撤回；另有 14 篇修订、13 篇更新依赖引用。Lean 覆盖升至 300/719，但约 42% 的覆盖也说明形式化验证远未完成。
