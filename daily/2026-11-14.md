# AI Intelligence - 2026-11-14

## Daily Executive Summary

1. **Google 已通过公共 API 开放 Gemini 4 Hydrogen。** `gemini-4-hydrogen` 提供 100 万 token 上下文和免费额度，付费输入与输出分别为每百万 token 1.5 美元和 7.5 美元。性能数据仍是 Google 自报，真实代码任务、长上下文成本和限流需要本地对照。
2. **llama.cpp 1.0 建立稳定 API 与 ABI 契约。** 这次主版本同时加入 FP8 KV cache、MoE cache 改进、OpenAI-compatible TTS，并加固 SSRF、CORS 与 DNS rebinding。兼容性承诺降低长期集成风险，但升级本身会移除旧 API，必须先回归。
3. **OpenAI 开始小范围开放 ChatGPT Wallet。** 首批面向部分美国 ChatGPT Pro 用户，每笔购买仍需用户核对商品、总价和卡片并完成安全检查。它把 agent 带到真实支付边界，但当前不是自主消费，也没有普遍开放。
4. **IBM 公开 LLMON 工具包与 Granite preview 权重。** LLMON 用保留标记区分指令和不可信数据，发布方自报可增强静态 prompt injection 防护。代码与权重可复跑，但自适应多轮攻击尚未被证明解决。
5. **XYBench 公开 8,115 道“真实目标”测试题。** 它检查模型会不会照着用户的错误做法执行，而不是识别背后的目标。数据和代码已公开；英语、流程题和单轮交互偏重，限制了对生产对话的外推。

## Models

### Gemini 4 Hydrogen

模型已在 AI Studio 与 Gemini API 可用，而不是 preview。100 万 token 上下文说明单次请求可以容纳大量材料，但不代表长上下文中的有效信息都能被同等利用；难点是质量、延迟和成本会随任务长度一起变化。

## Agent & AI Engineering

### ChatGPT Wallet

支付 token 让商家不必接触真实卡号，但它只解决凭据暴露的一部分风险。每笔交易仍由用户确认，说明当前产品边界是“agent 准备、用户授权”，不是 agent 自主花钱。

### LLMON 与 CapLite

LLMON 把指令和数据写成模型能识别的结构；CapLite 则把最终授权留给确定性代码。两者都在减少“模型同时理解内容并决定权限”的风险，但前者仍是 preview，后者本轮没有核实到公开实现。

## Open Source

llama.cpp 1.0、LLMON 与 Edge0-145B 都提供公开产物。Edge0 自报 145B 模型在兼容笔记本上只需 29GB 峰值内存且超过 80 token/s；这些突出数据尚无独立复现。召回自检还发现 smolmaxxing 与 LibreAGI：前者缺少稳定版和受控 benchmark，后者的再分发权、运营者与安全边界不清楚，均明确标为 IGNORE。llama.cpp 的语义化版本契约更接近生产依赖管理；LLMON 适合在隔离环境重放攻击样本，不能把发布方测试直接当作安全保证。

## Research

### XYBench

“做法”与“目标”分离是指：用户可能要求修补一个错误方案，而真正想要的是完成更上层任务。难点是模型需要识别前提错误并决定何时追问或纠正，而不是机械执行字面指令。

### CapLite

作者在 15 个开放权重模型和 13,935 个受攻击 episode 上报告零成功攻击。这个数字来自作者实验；没有公开代码或独立复现，因此处置为 WATCH。

## Developer Tools

- **Claude Code 2.1.323：** 加入实验性 Code Mode、plugin engine 版本范围与严格 TypeScript hook 校验，并修复多条失败即阻断、Bash 权限和符号链接设置问题。稳定版可升级，Code Mode 单独回归。
- **Codex 0.168.0 / 0.169.0：** side conversation 扩展为可持久化的多标签 side chat，并加入任务搜索、自定义 provider、SSH device-code 登录与诊断 ZIP。
- **Qwen Code 0.27.3：** 把共享 agent loop、ACP 后台运行、PR 绑定和持久 `/loop` 唤醒带入稳定分支；仍需测试 0.x 兼容性与恢复语义。

## Infrastructure

llama.cpp 1.0 把长期依赖风险从“每个版本都可能破坏接口”收敛为可解释的主版本边界。服务端默认值仍需验收，尤其是私有 URL 访问、CORS、DNS rebinding 与新 TTS 端点。

## Business & Policy

ChatGPT Wallet 的当前事实阶段是美国小范围 rolling launch，不是全球 GA，也不支持 delegated spending。本轮没有发现需要作为重大综合新闻例外进入摘要的事件。

Brave Search API 还增加了 x402 逐请求支付：agent 可以在 Base 上用 USDC 结算，无需账号或 API key。它把用量授权缩到单次请求，但也引入钱包、稳定币、账务和链可用性风险。

## Trend Signals

llama.cpp 1.0 为企业自托管执行面补充兼容性与安全边界证据；LLMON、CapLite 与 ChatGPT Wallet 从不同方向补充“模型提出动作、系统控制后果”的证据。它们增强既有趋势，但不足以新增趋势或提升置信度。

- **新 LLMON**（agent-security / TRIAL）：权重和工具包可复跑，但静态攻击结果不能代表自适应多轮安全性。

- **Qwen Code 0.27.3**（developer-tools / TRIAL）：后台运行与共享 loop 已进稳定分支，先排查丢任务和重复执行。
