## Agent & AI Engineering

- Holo4 把 GUI、代码、MCP 与 API 合在同一 agent/harness 中。它是可复核的工程发布，但不能把厂商单次 OSWorld 2.0 结果当作独立验证。
- Codex 0.158.0 的 MCP OAuth client secret 让需要预注册凭据的企业 server 更容易接入；但这仍是单一客户端能力，不能视为跨厂商 MCP 认证规范已经收敛。
- 高权限命令的终端输入审批默认开启。对长任务来说，关键变化不是多一个弹窗，而是 runtime 对有副作用的输入通道增加了一道独立后果检查。
