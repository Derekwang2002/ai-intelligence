- **Qwen3.8-27B 开放权重发布（Apache 2.0）**：27.8B 稠密多模态（图/视频/文本）、混合注意力（Gated DeltaNet + Gated Attention）、262K 原生上下文（YaRN 可扩至 1M）；SWE-bench Pro 61.7、OSWorld 84.3、Terminal-Bench 2.1 73.0。一天内 9.2 万下载、319 个社区量化、Ollama 当日支持——单卡级开源 agentic 基座模型的默认候选。

- **Claude Code 2.1.232/233 转向多代理运行时**：subagent forking 默认开启（继承对话+prompt cache）、跨会话 `@` 消息互通、cgroup 内存限额、网关按用户花费归因；同时移除了新模型上的 todo 工具（breaking）。
- **DeepSeek 开源 Harness（dsh，MIT）**：其基准测试背后的 TypeScript agent 运行时，"everything is a plugin"；扫描时 108k stars（社区报道首日 24k+）。开发者预览，预期破坏性变更。
- **SpaceX 600 亿美元收购 Cursor 交割**：Grok 4.6 为合作首批产物；模型-IDE 垂直整合成为竞争模板。
- **Anthropic 公开 Claude 文本水印机制**：适用于 2026-08-02 后发布的 Claude 模型，机读不可见——provenance 管道构建者需关注。

## Agent & AI Engineering

### Cloudflare MCP 流量检测与强制管控
- 检测：TLS 解密后基于 `MCP-Protocol-Version` 头（2025-11-25 规范要求；2026-07-28 无状态规范下每个 POST 携带并新增 `Mcp-Method`/`Mcp-Name`）
- `experimental.is_mcp == true` 选择器向全部 Zero Trust 客户开放；MCP 面板（请求数、唯一用户/服务器、Portal vs 直连、top shadow servers）
