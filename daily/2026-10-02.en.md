GPT-6.1 Sol is available by API at Sol pricing with near-Astra vendor-reported capability, while Gemini 4 Argon offers a 1M-token output ceiling but remains a controlled preview. Olmo-core 3 opens a trillion-parameter MoE training stack, and cua-speedrun makes computer-use speed and cost evaluation reproducible. ## Models

- **GPT-6.1 Sol (TRIAL):** Available in the API, ChatGPT Work and Codex at $2 input, $0.10 cached input and $10 output per million tokens. OpenAI reports near-Astra coding, computer-use and professional-task capability. Route by completed-task cost and factual errors.
- **Gemini 4 Argon (WATCH):** Google raises the output ceiling to 1M tokens and reports 77.9% on DeepSWE v1.1. Access is limited to trusted cyber defenders and post-introductory prices are scheduled to double; do not invest in migration before a public API.

## Agent & AI Engineering

- **OpenAI Dots (WATCH):** Each Dot has a cloud computer, connects apps and continues work between conversations. Rollout has started for some Pro and Business Premium users, but later pricing and enterprise governance remain unsettled; watch task completion, revocation and audit behavior.
- **OpenAI Agents API Browser (TRIAL):** The browser runs in an OpenAI-hosted environment while the application handles origin approval and sign-in fields, with resumable sessions after disconnects. Origin approval explicitly limits which sites the agent may reach; the hard part remains keeping credentials outside model context and gating side effects.
- **Ollama Decision Models (TRIAL, late discovery):** `/v1/systemone` returns choices, probabilities and scores. Calibration asks whether 80% confidence is actually correct about 80% of the time; without it, precise-looking routing thresholds can still be wrong.

## Open Source

- **Olmo-core 3 (TRIAL):** Ai2 opens a redesigned MoE stack and ran a 1.2T-parameter configuration on 512 B300 GPUs. Expert parallelism spreads experts across GPUs; routing imbalance and communication can erase sparse-compute gains. Published peaks use short random-routing tests, so sustained training needs validation.

## Research

- **cua-speedrun (TRIAL):** A uniform VM, execution pipeline and agent interface compare computer-use success, speed and cost. Public results show non-monotonic interactions between reasoning effort, environment latency and total time. Code and infrastructure are public for a one-day reproduction.
- The other 19 new arXiv cs.AI submissions were filtered or deferred for missing artifacts, limited engineering impact or scope mismatch.

## Developer Tools

- **Claude Code 2.1.285/286 (ADOPT, updated):** Adds provider allowlists and a WebFetch kill switch, and fixes session recovery, Remote Control policy revocation, MCP credential redaction and spend accounting. OS-denied managed settings still warn and continue, so deployments need an external startup check.
- **Gemini CLI 0.62.0 (WATCH, updated):** Fixes OAuth refresh-token retention, PTY/ConPTY cleanup and ACP permission-event ordering. Take the stable fixes; the undocumented A2A server remains unsuitable as a production dependency.

## Infrastructure
