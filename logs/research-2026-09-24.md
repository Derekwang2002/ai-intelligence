### 4. Cursor publishes production-tested agent context optimizations

- **Published:** 2026-09-23 (`date-only`, safely after checkpoint).
- **Primary:** https://cursor.com/blog/improved-token-efficiency
- **Key facts:** Cursor reports a 7% reduction in user token costs without a measured quality loss after trimming about 66% of its system prompt, loading low-frequency built-in tool definitions dynamically, improving cache boundaries, reducing cold cache misses by 20%, and numbering only every tenth source line. Earlier dynamic loading of MCP tool definitions reportedly cut total tokens by 46.9% for sessions that invoked MCP. Offloading built-in tool definitions cut static-context description tokens by 60%. The post also documents a practical trade-off: subagents can isolate context and reduce token spend, but impose a coordination tax.
- **Why keep:** The useful result is not one headline number but a production-shaped recipe for lowering long-running agent cost: smaller stable prefixes, lazy tool schemas, explicit cache boundaries, compressed file reads, and selective subagents.
- **Suggested handling:** New `ai-engineering` event; `TRIAL`. Make clear that results come from Cursor's own production traffic and A/B tests; they are not an independent benchmark.

### 6. Hugging Face Transformers runs packed GGUF models through ggml kernels

- **Published:** 2026-09-22 (`date-only`; boundary check required).

- **Key facts:** Transformers can load packed GGUF checkpoints through familiar `from_pretrained` APIs and serve them behind an OpenAI-compatible endpoint.
