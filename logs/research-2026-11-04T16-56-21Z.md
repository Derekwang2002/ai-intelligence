### 2. Ai2 releases StateBench for fine-grained long-context state tracking

- **Public time:** Hugging Face RSS published the release article at `2026-11-03T17:15:21Z`, inside the normal window. The underlying arXiv v1 was submitted earlier, at `2026-11-02T13:12:15Z`; preserve that distinction when assigning the event date.
- **Artifacts:** Public paper, GitHub code and a Hugging Face dataset with 18 subsets and 16.3k rows in the canonical subset.
- **Evidence:** The benchmark separates immutable assignment, reassignment by value, self-referential updates and assignment by reference. Ai2 reports that four tested frontier models fall to 13% or lower on the longest hardest cases. Directly trained Gated DeltaNet/hybrid variants generalize much farther on several levels, while transformers do not learn the hardest level in the reported setup.
- **Limits:** This is author-reported benchmark evidence, not independent production validation. StateBench fixes the number of variables and does not cover entities introduced over time. It complements rather than duplicates StateMemBench: StateBench probes architecture/length generalization on synthetic assignment problems, while StateMemBench evaluates evolving conversational memory and supersession.
- **Suggested disposition:** `new-event`, `WATCH`; public code/data make reproduction possible, but it is a benchmark rather than a deployable capability.
- **Primary sources:**
  - https://huggingface.co/blog/allenai/statebench
  - https://arxiv.org/abs/2611.03094
  - https://github.com/allenai/state-bench
  - https://huggingface.co/datasets/allenai/state-bench

### 3. NVIDIA study argues retrieval-backed compaction can replace much long live context

- **Public time:** arXiv v1 at `2026-11-03T18:17:23Z`, inside the normal window.
- **Evidence:** Across the paper's tested long-horizon and long-input suites, frequent compaction and selective file reads often preserve accuracy. Its hardest one-action-per-context test covers SWE-bench Verified and Terminal-Bench 2.1: the paper reports Claude Opus 4.5 roughly preserving its full-history score, while GPT-5.6 Sol loses 2.0 and 3.3 points. The authors model large serving-cost differences at long context, but those cost savings are estimates rather than task bills.
- **Limits:** No new checkpoint or dedicated implementation is released. The strongest boundary test covers two software benchmarks; open-model supplementary results are mixed, including a severe reported failure for one model. The correct takeaway is “keep compact working state plus retrievable evidence,” not “long context is never useful.”
- **Suggested disposition:** `new-event`, `WATCH` under the research category. It is especially relevant to RAG and long-running agent harness design, but lacks a public implementation specific to the paper.
- **Primary source:** https://arxiv.org/abs/2611.05306
