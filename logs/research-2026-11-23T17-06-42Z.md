### GLM-5.4 (new, WATCH)

- Z.ai published the official launch on 2026-11-23 (date precision only). GLM-5.4 is the company's first 750B-scale Loop Transformer: it runs 28 shared layers for two iterations, reuses sparse-attention indices, and combines shared global KV with an independent sliding-window cache for the second pass.
- Availability is real but narrow: all GLM Coding Plan tiers can use it now in ZCode and other compatible coding tools; Z.ai Chat is also listed. ZCode documentation says 1M context and three reasoning levels. The standard API is explicitly “Coming Soon,” and open weights are only planned after safety hardening. No API price or weight license is available yet.
- All capability, throughput (up to 200 tok/s off-peak; 70–80 tok/s peak), benchmark and architecture-effect claims are vendor-reported. The vendor also discloses a tendency toward overly long “marathon thinking” loops. Without API access, weights or independent evaluation, the highest defensible recommendation is WATCH.
- Sources: [official technical launch](https://z.ai/blog/glm-5.4), [official ZCode availability FAQ](https://zcode.z.ai/cn/docs/qa), [official ZCode agent docs](https://zcode.z.ai/en/docs/agents).

- Maintainers call it a security release and instruct every MONAI Label server deployment to upgrade. - Sources: [official GitHub release](https://github.com/Project-MONAI/MONAILabel/releases/tag/0.8.6), [maintainer advisory](https://github.com/Project-MONAI/MONAILabel/security/advisories/GHSA-qc22-rmgc-vg94), [PyPI artifact](https://pypi.org/project/monailabel/0.8.6/), [datastore fix PR](https://github.com/Project-MONAI/MONAILabel/pull/1915), [session fix commit](https://github.com/Project-MONAI/MONAILabel/commit/f824cd267f32429f518d1d0c7f699909b2dbe559).
