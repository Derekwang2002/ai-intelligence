### 3. Cohere releases Embed 5 with interchangeable Pro and Fast vectors — `new-event`, TRIAL

- Official publication date: September 30, 2026.
- `embed-v5.0-pro` targets offline indexing and quality; `embed-v5.0-fast` targets low-latency queries, agent loops, and high-volume serving. Both models share an embedding space, so teams can index with Pro and query with Fast without rebuilding the index.
- Both support text, images, and mixed PDF pages, 100+ languages, 128K context, and Matryoshka dimensions from 256 to 2,048. Output formats include float, int8, and binary embeddings.
- Available through Cohere's Embed API, Microsoft Foundry, Amazon SageMaker, and Cohere Model Vault. Cohere reports large gains on rich documents, filings, parsed PDFs, code, and multilingual retrieval, but the performance claim is vendor-reported and needs an independent corpus check.
- Source: [Cohere Embed 5 release notes](https://docs.cohere.com/changelog/embed-v5).
- Deduplication: no Embed 5 event or matching fingerprint exists.

### 4. Cohere publishes RCP-nDCG@10 for human-aligned retrieval evaluation — `new-event`, TRIAL

- Official publication date: September 30, 2026. Public code and data are available under the project repository.
- Rubric-Calibrated Preferences nDCG@10 combines per-document rubric questions, pairwise or group preferences, and cross-query calibration. In a 46-annotator study covering 273 queries, Cohere reports ROC-AUC rising from 0.65 for conventional qrels to 0.91 for the calibrated score. When RCP-nDCG and traditional nDCG chose different systems, humans preferred the RCP choice 70% of the time.
- Plain-language note for editors: a qrel is the benchmark's saved relevance label for a query-document pair. The hard part is that two useful documents can satisfy different user needs, so a single static label often disagrees with what people actually prefer.
- The study is vendor-originated, but the released code/data makes a one-day reproduction on a team's retrieval corpus feasible.
- Sources: [Cohere research article](https://cohere.com/blog/rcp-ndcg), [public code and data](https://github.com/cohere-ai/rcp-ndcg).
- Deduplication: no event covers RCP-nDCG or this study.

### 5. NVIDIA uses NeMo Relay traces to test agent-harness changes — `new-event`, TRIAL

- Official publication date: September 30, 2026. NVIDIA released a runnable Hermes/NeMo Relay example with Docker isolation and a controlled ToolPerf experiment.
- Relay emits agent lifecycle events as ATOF JSONL, trajectories in ATIF, and OpenTelemetry/OpenInference spans. The example warns that traces can contain prompts and secrets and should be treated as sensitive telemetry.
- Across 108 runs on nine tasks, the proposed verifier changes improved Qwen3 Coder 30B from 19/27 to 22/27 successful runs, while increasing average tool calls, trace volume, and duration. Claude Sonnet 4.5 moved from 24/27 to 23/27. That mixed result is useful: a harness change can help one model while adding cost or hurting another.
- Sources: [NVIDIA technical article](https://developer.nvidia.com/blog/tracing-agent-harness-behavior-with-nvidia-nemo-relay/), [runnable example](https://github.com/NVIDIA/nemoclaw-community/tree/main/examples/tools/hermes-relay-tracing).
- Deduplication: no NeMo Relay event exists. This is more than a general observability tutorial because it ships a reproducible artifact and controlled before/after evidence.
