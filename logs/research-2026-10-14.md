4. **Study finds implicit agent skill routing collapses as irrelevant skills accumulate** — **TRIAL, late discovery**
   - [Lost in Implicit Routing](https://arxiv.org/abs/2610.18522) was submitted `2026-10-13T15:12:12Z`, inside overlap. On a fixed SkillsBench setup, the authors report loaded-skill recall falling from 73.6% to 27.4% with 1,000 irrelevant skills, while explicit preselection retains 73.9%.
   - The [research repository](https://github.com/jinlinll/lost-in-implicit-routing) includes experiment scripts, manifests, source links, and hash indexes for 21,262 third-party skills. It does not redistribute the complete skill corpus, raw logs, or precomputed embeddings; 474 source entries were unresolved. Full reproduction therefore requires reconstructing data and external model/embedding services.
   - Plain-language implication: “implicit routing” asks the model to discover the right tool from the entire prompt. The hard part is not merely a longer prompt; similar descriptions interfere with one another, so adding tools can make the correct tool harder to select.
   - One-day trial: use the public scripts and an internal 100/1,000-skill catalog to compare implicit routing with explicit preselection on recall, latency, and token cost. Treat the headline as author-reported until independently reproduced.
