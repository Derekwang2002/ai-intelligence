## 使用与维护

- 本地预览：`npm --prefix site run dev`。
- 常规检查：`npm --prefix site run check`。
- 浏览器检查：`npm --prefix site run test:browser`（先安装 Playwright Chromium）。
- 复核工作单：`node scripts/review-agenda.mjs`。
- 当前趋势同步：`node scripts/render-current-trends.mjs`。
- 扫描提交：`node scripts/finalize-run.mjs --manifest=logs/run-<id>.json` 预检，通过后加 `--commit`，再重建网站。

历史迁移不等于重新验证全部来源。没有检查记录的来源、无法明确关联的旧材料和未完成的历史复核仍保留未知或待处理状态；页面明确标示。专题依据现有档案组织问题，未验证的结论保持开放。本记录描述发布前的本地验收结果；线上状态以对应提交的部署任务为准。
